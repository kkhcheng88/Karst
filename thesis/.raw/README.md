# thesis/.raw/ — raw fed sources (immutable, for citation & audit)

When you feed an analyst report / KOL post / web article, land the raw text here first
(`<slug>-<source>.md`), full-read it, THEN distil cited claims into `thesis/wiki/<slug>.md`.
This keeps the primary source traceable (a thesis claim cites back to a `.raw/` file). Never
edit a `.raw/` file after landing it — it is the immutable evidence. (Convention borrowed from
claude-obsidian's `.raw/ -> wiki/` ingest, built natively.)
