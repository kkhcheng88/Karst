# Karst

中期基本面預期差投資工作台。用產業、價值鏈與原始文件理解公司的每股價值,比較市場隱含要求,再用估值與日週月價格結構形成獨立評級和投資計劃。

研究不讀用戶持倉、成本或盈虧。系統發布自己的看法、公允價值、期間目標與行動條件;模型組合用自己的帳本選擇配置,評估器保留原判斷追蹤結果。每日以新證據和價格差異更新,不必重讀所有文件或頻繁交易。

## 現行文件

- [投資決策模型](strategy/投資決策模型.md):主策略、機會來源、論點、相位、評級與配置、圖書館取捨。
- [投資委託](strategy/投資委託.md):用戶目標與期限、分析原則、設計預設出處;不含私人帳戶。
- [六層分析紀律](strategy/specs/六層分析紀律-v1.md):市場、價值鏈、基本面、估值、TA、綜合的必答問題。
- [設計與交付計劃](strategy/specs/獨立投研工作台設計與交付計劃-v1.md):上下文隔離、資料與版本、增量、模型評估、工作包與驗收。
- [資料來源](strategy/資料來源.md):本地原料、DefeatBeta／富途／Longbridge、逐字稿與用戶報告。
- [相位與階段](strategy/specs/相位與階段清單-v1.md):不同狀態怎樣服務篩選、入場與退出。
