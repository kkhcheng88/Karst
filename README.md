## 五層結構

### `library/` 圖書館

別人的心得,經我們對照四類注之後的版本。三層由淺入深:

- `sources/`(來源層)——一個來源一檔,只記那個來源講了什麼。分 `books/` `traders/` `communities/` `social/`。每檔頭部有**來源權重四格**(時代、持有期、親身做過、資本規模),意見相左時先看四格再定信誰。
- `insights/`(結論層)——跨來源合成的主題結論,按四類注要答的問題分檔,每條列支持與反對來源。**策略工作只引結論層**,追溯才落到來源層。
- `raw/`(原文層)——原始全文,倉內自足:25 本書的抽字全文、六個社交帳號的原始抓取、皇者順 Discord 2023–2026 逐年全文。引述有疑問可以逐頁核對。

`catalog.md` 是待蒸餾名單(誰已做、誰未做、優先次序),`INDEX.md` 是已入庫來源一覽。

### `strategy/` 策略層

- `framework.md` —— 四類注框架正本,連用戶原話。
- `principles.md` —— 用戶交來的十條交易原則與我們的評估。
- `candidates.md` —— 方法論候選登記表:每個待驗證的說法五格(聲稱、服務哪類注、文獻、延遲成本、證偽條件)。
- `specs/` —— 四類注各一份規格書(KARST-178/179 起草中,現為空)。
- `cards/` —— 論點卡(每一注一張,記估值錨、死亡清單、論點失效條件;現為空)。

### `research/` 研究

- `2026-09-methodology/` —— 現期(方法論期)研究。
- `archive/YYYY-MM/` —— 按月封存的舊研究,九十多份。
- `archive/experiments/<實驗名>/` —— 已收線實驗的 md 摘要;原始程式與數據已搬出倉(見下)。

### `karst/` `tests/` `vintage/` 引擎

角色是**資料治理與回測**:宇宙定義、快照、因子合約、回測執行、成績記錄,加上 `vintage/` 的倍數版本存檔(每日抄一次,不可再生,入 git)。

**狀態:凍結(D-165)。** 引擎不再加功能,等四類注規格書寫出來、確定要量什麼,才按規格重啟。

### `data/` 資料

分原料層(`sec/` EDGAR 快取、`prices/` 日線、`universe/` 宇宙、`macro_snapshots/`)與衍生層(`panel/`、`snapshots/`、`runs/`)。整個目錄不入 git,只有說明檔與清單入。逐層的來源、重建成本、追蹤狀態見 `data/README.md`。
