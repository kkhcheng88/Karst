# inbox/ —— 報告與研究入口

把分析員報告、線上研究、截圖放這裡,可附來源與日期。連結每行一條放 links.md。這是待處理入口,不是放進來就自動成為已核事實;目前入庫程式仍待實作。

計劃流程:登記取得時間 → 隔離分類／檢查私人帳戶資料 → 保存可用的原始研究副本及 hash → 解析與來源定位 → 連接相關公司／產業 → 更新任務。

- 作者的預測、你提出的假設、引用的外部事實與系統判斷各自記錄。
- 含持倉、成本、盈虧、帳戶資訊的內容不能交正式研究模型;使用清理後副本。混合文件或無法判定的圖像先隔離,不讓研究模型讀過再當盲分析。
- 來源日期未知要明標,取得日期不等於發布日。網址在可取得且允許保存時抓原文快照,不只保存最新網頁連結。
- 移動／入庫在證據及登記成功後才確認,避免丟失原檔。詳細契約見 evidence/README.md 與設計計劃。

本目錄除 README 與 links.md 外不入 git;links.md 不放私人帳戶或含憑證的網址。
