# 投資決策模型(v1.1,2026-09-18)

> 現行策略正本,依 D-181。用戶授權把本日討論寫入 repo 並開始規劃與設計;以下策略取捨由 GPT 以投資管理者角色提出,不把設計預設冒充用戶逐項指定。偏好見[投資委託](投資委託.md),執行見[六層紀律](specs/六層分析紀律-v1.md),系統與交付見[設計計劃](specs/獨立投研工作台設計與交付計劃-v1.md)。

## 一、主策略與優勢假說

**採用中期基本面預期差投資。** 找出未來數季的每股盈利能力或現金流,可能比現價隱含要求更好的公司;用產業與價值鏈理解原因,用新證據持續驗證,再用估值與價格結構決定是否值得承擔風險。

目的是提供每日可直接消費、可以追蹤與回顧的獨立投資判斷。強 LLM 的價值假說是讀懂跨文件的機制、辨認條件與反證、更新預期;程式維持數據、計算與執行紀律。資料量、角色數量或模型智力本身不等於超額回報。本模型是按目前目標選定的起步策略,尚未證明最優或有可持續 alpha。

優先研究四種可相互重疊的機會:

1. 經營改善已出現,市場低估其持續性、品質或每股價值。
2. 商業化開始兌現,市場錯估規模、利潤或所需資本。
3. 產業正在改變,利潤流向與市場所押的公司不同。
4. 成熟生意被重新定價,現價隱含的惡化超過有證據支持的程度。

尚無兌現依據的遠期故事保留探索位置,不作主回報引擎。低估值、跌得多、創新高、恐懼指數低都可以觸發調查,各自不能獨立成立投資論點。也不要求全市場股票一律盈利、同一收入增速、站上 200 日線才准研究。

**四類注的地位(D-182,用戶 2026-09-15 定):不是強制入口,也不只是標籤,而是可啟用的情境分析模組,由本共同框架統領。** 三個模組,每個決定該情境要特別攻哪些問題:

| 模組 | 攻什麼 | 嵌入的既有資產 | 啟用條件 |
|---|---|---|---|
| 潛在錯殺 | 永久損害與價值陷阱、損害幅度與修復證據;研究方向是「市場為何沒錯」 | ①暴露差異能力卡、敘事衝擊檢查清單 v3 | 可核查的事件與假說(被迫賣家、行業衝擊、公司特定事件都可以是入口,不限前兩種);不需要先證明市場錯了才准研究市場是否錯了 |
| 改善趨勢 | 驅動能否延續、現價已反映多少 | ②改善驅動可持續性能力卡 | 已出現的經營改善或強勢反應 |
| **敘事與預期差** | 市場對「這家公司未來會發生什麼、為什麼」的解釋,與我們的差異 | framework §四 論點卡八格(敘事證據、共識度量、定價位置、推翻條件、時限)、圖書館共識尺與錢落在哪 | 敘事是投資論點的主要爭議時深入啟用;按證據選問題分支 |

敘事與預期差模組(用戶原話:「商業化太窄,不能涵蓋我們真正想分析的敘事」)至少追查五件事:敘事內容(哪個可被支持或推翻的主張)、證據狀態(說法、早期行為、訂單,還是已進入財報)、經濟傳導(怎樣改變需求、份額、價格、成本、再投資與每股現金流)、市場預期(哪些已共識、哪些仍分歧、現價要求什麼;不靠聲量)、驗證與反證(接下來看什麼、什麼出現後必須改變看法)。問題分支按敘事類型選:新產品或技術商業化(誰付錢、何時形成收入與現金流、此前要多少資金與稀釋);成熟企業受替代威脅(被取代的是產品、功能還是定價權,何時進財報);產業需求或供給轉變(需求能否持續、新增供給何時到達、利潤落在哪個環節);轉型、重組或資本配置改變(是否提高每股價值、執行條件與代價)。**敘事不只屬於③④**:成熟、盈利穩定的公司同樣會因市場對其未來的解釋改變而重新定價,所以每隻股票都要答「市場現在相信什麼、我們同意或不同意哪一部分、差異怎樣影響未來每股價值、現價值得付多少」;模組只是在敘事成為主要爭議時加深。敘事成立不等於值得投資:還要確認價值由這家公司捕獲,以及現價沒有預先付清。

啟用一個模組是一個待證假設,不是結論;三個模組不是互斥的箱子,允許重疊、逆轉及不適用;不要求每股先歸類,不等額配置,不預設④→③→②→①的遷移。舊能力卡按其有效用途嵌入,不讓單一能力考試決定整個產品能否交付。

**估值方法跟隨生意的經濟結構,情境只決定哪些假設要特別審查。** 成熟且現金流可理解的企業由經營、再投資與風險推導現金流價值;盈利受週期影響大的企業分辨當期高低點與正常化盈利,不把頂峰利潤永久延伸;尚在商業化、目前虧損的企業明列收入形成、利潤轉正、資金需求、稀釋與失敗情境,不能只用「市場很大」撐估值;金融企業採股權現金流、股息或超額收益法。同一公司由趨勢變成潛在錯殺,通常是同一估值邏輯換輸入與情境,不是換公式;真正要重判的是成長、定價權、客戶留存、再投資需求與風險有沒有改變。AI 的自由度放在理解生意、辨認機制、提出情境與選適用方法;不准自由挑一個能支持結論的估值法。每次估值必答四問(六層紀律 L4)。

## 二、研究怎樣找到機會

三個入口共同工作,不是三套互斥策略。

| 入口 | 實際工作 | 產物 |
|---|---|---|
| 產業理解 | 看終端需求、資本投入、供給、定價權、替代與利潤分配;辨認可投資公司及傳導路徑 | 產業／價值鏈假設、關係與候選 |
| 事件更新 | 追公司、客戶、供應商、競爭者的業績、逐字稿、指引、合約、政策及產業報告 | 哪個假設變了、影響誰、需重評哪些層 |
| 機械掃描 | 價量異動、相對強弱、關鍵價位、事件日曆與資料覆蓋變化 | 分配研究注意力,發現現有覆蓋盲點 |

日常以事件路由為主,已有產業理解為基礎,掃描補盲點。宏觀必須經需求、成本、融資或折現率連到公司,不用一個大市預測否決所有研究。

500+ 股票是機械監測範圍;深讀覆蓋與行動候選按研究容量調整。30–50 家持續覆蓋、5–10 個接近行動條件的論點僅為設計容量示例,不是持倉數或資金分配指示。新股票可先交資料缺口與初步問題,不能把未讀完誤寫成完整覆蓋。

觀察名單記的是「在等什麼」:入場價格、驗證事件、新來源或假設修正。每日監測不代表每日重讀全部原文或每日交易。

## 三、每個論點必須答出的因果鏈

1. **生意發生什麼變化?** 區分結構改善、週期恢復、一次性與基數。
2. **錢落到誰,最終每股得多少?** 連接鏈位、份額、價格、利潤、再投資、融資與稀釋。
3. **市場已要求什麼,我們不同在哪?** 分開管理層指引、分析員共識、個別研報與反向估值;正向情境必須獨立建立。
4. **最強反證及失敗路徑是什麼?** 包括即使產業看對但公司沒有捕獲價值的可能。
5. **何時可以知道?** 經營展望預設看未來兩至四季;列下一驗證事件與預定失效／到期處置。
6. **現價的剩餘回報值得嗎?** 同時看估值、價格結構、時間、下行情境與替代機會。

每項連到可定位的原始證據、來源版本、適用期間與假設。六層角色對這條因果鏈分工,不以六票表決或總分 82/100 代替取捨。綜合角色必須解釋重大分歧如何影響評級、價格區間或等待條件。

## 四、相位服務決策

[相位清單](specs/相位與階段清單-v1.md)管理各維度。公司可能同時處於商業化加速、供給擴張、預期上修及週線上升中的日線回調;這些不同步值得研究,不直接等於機會。

| 用途 | 決策方式 |
|---|---|
| 篩選 | 找某一投資情境的候選,如改善持續且市場預期仍落後;不符合只代表不屬這個情境 |
| 入場／加倉條件 | 相位交代背景,再結合現價、估值、驗證事件、關鍵價位和 R&R |
| 減倉／退出條件 | 必要假設被推翻、剩餘回報已反映、共同風險改變或預定條件觸發;不能只因換標籤而買賣 |

資本週期不是全產業一票否決器,指數納入不是自動離場鐘,共識擴散也不保證見頂。必要條件真正失效時應改變行動,不因稱為「相位」而降成無作用的裝飾。

## 五、分開研究評級、執行與配置

| 決策 | 要回答 | 輸入與輸出 |
|---|---|---|
| 獨立研究 | 以目前價格與指定期限,這家公司是否有吸引力? | 公開證據與研究委託 → 正面／中性／負面評級、理由、情境回報與目標 |
| 條件式計劃 | 哪些價格或證據出現,值得進入／退出這個論點? | 評級、估值與 TA → 可執行／等價格／等確認／等資料／避開,附入場與失效 |
| 模型組合 | 相比其他股票、指數曝險及現金,如何分配模型資本? | 已發布研究與模型自己的帳本及風險委託 → 買入／持有／加減／退出 |

評級指向明確評估日。下一業績優先作近期假設的檢驗節點；價格目標期限按催化劑選，不再套用六個月預設；每次發布固定目標日,到期回顧原判斷。用戶偏好的持有期仍是一月至一年,不因目標未到而默默延期。

基本面層推導未來現金流,估值層計算估值日的基準每股內在價值與悲觀／樂觀範圍;基準依經營假設決定,不是範圍的簡單中點。另列指定日期的股價情境和下一技術阻力,不把當日公允價值直接當中期必達價格。目標價需要經營／估值／時間橋接;資料不足可不報點值,列缺口與條件。沒有覆蓋或證據不足是資料狀態,不自動等於負面評級。無依據的情境機率不填,不用 LLM 的語氣自信當勝率。

股票頁首屏顯示研究評級與執行狀態、主要理由、關鍵假設、最強反證、改變行動條件、與上次相比。展開可見估值算式、日週月關鍵位置、前瞻 R&R 與驗證日曆。人的每日入口是結論與變化,後台保存完整可追查紀錄。

## 六、研究獨立與反迎合

研究引擎不接收用戶的實際持倉、成本、盈虧、現金或帳戶快照,也不讀模型組合成本與盈虧。這是用戶明確要求,以執行環境與工具權限隔離,不是一句「請忽略持倉」的提示。

開發對話已見過私人資訊,不能把這個對話稱作盲分析。正式研究以新的上下文、允許清單中的委託與證據啟動;不繼承管理文件、全倉文件樹、舊聊天或券商帳戶工具。公開的公司機構持股與內部人交易可作研究來源,與投資者私人持倉不同。

反方先讀證據提出替代解釋,再挑戰各層,不先讀綜合結論。重大新事件先根據新原文形成當期判讀,再對照舊結論;價格日沿用未變的證據及舊判斷,明示重算範圍。隔離可以減少迎合與成本錨定的輸入,不能證明 LLM 沒有其他偏誤。

用戶提供的研報與線上研究是重要來源;作者預測、用戶假設與系統判斷分開。被轉述十次的同一消息不算十個獨立證據。

## 七、風險與模型自行回顧

研究頁從現價提供每股、百分比及情境損益,不用私人帳戶才能出結論。計劃內止損距離與跳空／流動性壓力損失分開,有漂亮 R&R 仍需回答目標可達性、時間及失敗原因。

模型組合另有版本化委託,在開始計分前定好資本、單股／共同假設曝險上限、壓力預算、交易頻率與成本模型。這些由模型設計明列,不冒充用戶真實風險承受。原有 1% 仍只為示例,不是正式預算。共同需求或供給假設要合併看,不能每隻股票各領一份獨立風險。

現金可以是完整選擇;SPY 是股票市場曝險,並非現金替代或無風險退路。先定總回報比較基準,再比較同期間與相同資金流條件下的結果。

每次評級與計劃發布後保留原版,新判斷不覆蓋舊承諾。評估分四層:

- 經營判斷:驅動、幅度、期間與反證處理是否正確。
- 定價判斷:經營看對後,價格與預期是否已反映,估值橋接是否錯。
- 執行:條件是否真的到達、發布後可否成交、成本及跳空有何影響。
- 組合:與基準的總回報、回撤、集中與共同風險,是否只是較高市場／產業曝險。

保存未選、退出、撤回及負面評級;每日同一論點的多次版本不當成獨立成功樣本。84 宗歷史考試保留作品質回歸;前瞻模型組合另計,不把收入預測能力轉寫成已證實投資勝率。

## 八、圖書館如何進入現行策略

本輪已審閱九份 insights 結論;不宣稱已重新核對所有原著頁碼或證實每條經驗規則。採用其問題與機制,具體條件需在論點中說明。

| insights 文件 | 目前採納的用途 |
|---|---|
| where-the-money-lands | 從終端需求追到利潤與現金流真正落點 |
| moat-durability | 檢查定價權、競爭與護城河在持有期和更長期的差異 |
| pricing-position | 分開好公司與好價格,比較市場隱含要求 |
| consensus-gauge | 比較敘事、指引、共識與價格要求,不以聲量作充分證據 |
| category-transitions | 記錄相位轉變與機制,不用單向類別遷移或三票制自動交易 |
| event-window-price-action | 在已知事件及日週月背景中讀價格確認與失效 |
| forced-selling | 被迫賣壓作可核查的事件假說,不把所有下跌叫錯殺 |
| sizing-and-exit | 每次加倉重新成立、論點失效與資金風險分開;原筆記數值不自動成為模型／用戶風控 |
| conflicts-with-framework | 保留互相衝突的方法與適用條件,不混合成全部必過的篩選表 |

原始來源與引用定位保留在 library。未經用戶證實的個人財務推斷不進研究委託;大師、KOL 或 agent 的斷言不因存入 Wiki 或 insights 而成為事實。

## 九、版本與權限

v1 為本輪設計,實作和成果按地圖追蹤。D-181 對現行工作台的獨立研究、四類注地位與交付次序優先於舊文件衝突段落;不改寫用戶歷史原話、凍結研究與原始成績。策略變更另版並記生效時間,只對之後發布與執行適用。


v1.1（2026-09-18，本輪用戶授權配置直接提交）：按商業模式、生命階段及資本需求選主估值與可核算替代視角；內在價值、現價隱含要求及期限價格分開。執行細則以六層紀律 v1.3 的 L2–L6 為正本。TA 以實際圖像和同源數值互核，輸出背景→形態→觸發→失效→目標／不做，適配一月至一年；不預設盤中交易或 KOL 的注碼。此為研究方法配置生效，計算器／MCP／DB 的新增能力由 Claude Code 按執行指令另行實作，不能視作已部署。
