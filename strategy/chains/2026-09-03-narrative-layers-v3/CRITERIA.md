## 4. 主判數:三組配對(與 v2 一字不改)

- **G1** 同層、不同子行業(敘事分層的獨有貢獻)
- **G2** 同子行業、不同層(GICS 的獨有貢獻)
- **G3** 同層又同子行業
- **G0** 兩樣都不同(背景值,不參與判準)

## 5. 顯著性

### 5.1 以層為抽樣單位的 cluster bootstrap(與 v2 一字不改)

每次重抽對**層**做有放回抽樣(抽與原本層數相同的個數),中選層的成員組成該次樣本,
同一層被抽中兩次視為兩個獨立副本、跨副本配對不計;在該樣本上重算 G1、G2 與 `G1 − G2`。
**B = 2,000**,95% 置信區間用百分位法。單次重抽若 G1 或 G2 少於 20 對則該次棄用。

### 5.2 隨機重貼標籤運氣帶(本票新增的一項,不改上面任何一項)

在**同一批公司、同一個殘餘相關矩陣、同一個子行業向量**上,把層標籤向量隨機重排
(即保持每層的家數分佈不變,只打亂邊個公司屬邊層),重算 `G1 − G2`。
**B = 2,000**,種子 `20260903`。報三個數:運氣帶的 2.5 與 97.5 百分位、
以及實測值在這 2,000 個隨機值之中的百分位排名。

## 6. 等效獨立層數(D-131 那把尺,與 v2 一字不改)

各層的**等權日回報**(切片後 12 個月;層內至少 2 家有回報)組成相關矩陣 R,
`N_eff = N² / ΣR_ij`(元素求和法,含對角線)。同期用九隻 SPDR 板塊 ETF 算同一個數作對照。

## 7. 與 GICS 的重疊度(與 v2 一字不改)

每個 arm、每個切片報**調整互信息** `adjusted_mutual_info_score(子行業, 層標籤)`。

## 8. 配對數門檻(硬規則,與 v2 一字不改)

任何 arm × 切片,若 **G1 或 G2 的配對數 < 100**,該格判 **量不出**,
**不得用來支持「存在」**,亦不得用來支持「不存在」。

## 9. 兩版量法

### 9.1 甲版「事後表」(arm `manual_v22`)——證解析度

標籤 = v2.2 表的 `theme` 欄,按第 1 節定格。量法照第 3–8 節,**與 v2 的 `manual` 臂一字不改**
(只換表與加第 5.2 節那條運氣帶)。

甲版報兩個樣本:

- **甲版(全)**:第 1 節定格之後、有價格有子行業的全部成員。這是解析度的頭條數字。
- **甲版(對照集)**:再交叉「該切片有事前可得年報文本」那一批(見 9.2)。
  **保留率只用對照集算**——因為乙版只在對照集上分得出組,兩版要同一套配對才比得到。

### 9.2 乙版「受控表」(arm `exante_A` / `exante_B`)——證事前可得

**問題**:同一批公司,如果只准用切片日之前已經公開的資訊,分得出同一套組嗎?

**文本(只用切片日之前的)**:
- 每個切片只用 `filingDate ≤ T` 的最新一份 10-K;若該份的 `filingDate` 早於 T 超過
  **500 日**,視為過期,該公司在該切片作缺失。
- 全文只讀共用快取 `data/sec/10k_text/`(D-134)。**本票不抓 EDGAR、不寫該快取。**
- Item 1 切節規則與 v2 CRITERIA 第 3 節**逐字相同**:主文件純文字 → 起點
  `item\s*1\s*[.\-:–—]?\s*business`;終點 `item\s*1a\s*[.\-:–—]?\s*risk\s*factors`,
  失敗則退用 `item\s*2\s*[.\-:–—]?\s*propert`;取所有 (起, 終) 配對中長度 ≥ 3,000 字元的
  最短一段;切節後 < 2,000 字元作缺失,**不用全文回退**。
  已有的切節衍生物(KARST-152 / 157 的 `data/item1/`)直接讀,不重切。
- **零價格輸入**:分組那一步不准見到任何價格、回報、市值。

**對照集定義**:某切片的對照集 = 甲版(全)之中,同時有上述事前可得 Item 1 文本的公司。
甲乙兩版在該切片用**同一個對照集、同一個殘餘相關矩陣、同一個子行業向量**,
唯一分別是層標籤怎樣來。

**分組規則(跑數前寫死,兩種都跑)**:

- **乙-A 用詞重建**:TF-IDF(參數與 v2 CRITERIA 第 4(b) 節逐字相同:`lowercase=True`、
  `ngram_range=(1,2)`、`min_df=5`、`max_df=0.5`、`sublinear_tf=True`、`max_features=20000`、
  `norm="l2"`,停用詞表沿用 152 的 `BOILER` 加英文停用詞,並去掉公司自身名稱 token 與代碼)
  → `TruncatedSVD(n_components=100, random_state=20260903)` → L2 正規化 →
  `AgglomerativeClustering(n_clusters=K, metric="cosine", linkage="average")`。
- **乙-B 語意重建**:`sentence-transformers/all-MiniLM-L6-v2`,文件按空白切詞、每 200 詞一塊、
  每份最多前 40 塊、逐塊編碼後平均池化再 L2 正規化(與 v2 CRITERIA 第 4(c) 節逐字相同)
  → 同一個 `AgglomerativeClustering(n_clusters=K, metric="cosine", linkage="average")`。
- **K = 該切片對照集上甲版實際生效的鏈數**(即甲版在對照集上有幾多條鏈,乙版就分幾多層)。
  這樣兩版的層數相同、每家公司都有層,**配對集完全相同**。
- 為什麼不用 v2 的 HDBSCAN:HDBSCAN 會留下「無層」的公司,配對集就會與甲版不同,
  保留率變成兩件事相減。固定層數的凝聚式聚類是唯一保得住「同一套配對」的做法。
  代價寫在誠實聲明第 5 項。

**事前可得保留率**(本票的第四個數):

```
保留率 = 乙版 (G1 − G2) ÷ 甲版(對照集) (G1 − G2)
```

甲版(對照集)的 `G1 − G2` 若 ≤ 0,保留率不定義,該切片判詞按第 10 節第一分支處理。
**主數取乙-A 與乙-B 之中較大的一個**——這是刻意讓「事前可得」那一邊拿到最好的一次機會:
若連較好的那個都歸零,「歸零」這個結論才硬。兩個數都要報。

## 10. 判詞(跑數前寫死,之後一字不改)

分開判兩件事,每件只用三個詞。

### 判詞①「事後表上的鏈層解析度」(甲版)

沿用 v2 CRITERIA 第 11 節,只把「三個 arm 之中至少一個」換成「甲版」:

**存在** ⟺ 甲版同時滿足:
1. `G1 − G2 > 0`,且 cluster bootstrap 95% 置信區間**不含 0**;
2. 該切片 `N_eff` 減同期九隻板塊 ETF 的 `N_eff` **≥ 1.0**;
3. `G1 − G2` 的**符號在可判切片一致**(至少要有兩個切片可判,否則判量不出);
4. 該格 G1 與 G2 的配對數皆 **≥ 100**。

**不存在** ⟺ 在全部可判切片都是 `G1 − G2 < 0` 且置信區間不含 0。

**其餘一切情況 = 量不出。** 配對數 < 100 的格一律先判量不出再談。

### 判詞②「事前可得的鏈層解析度」(乙版)

- **存在** ⟺ 保留率 **≥ 50%**,且乙版 `G1 − G2 > 0`,且乙版 cluster bootstrap 95%
  置信區間不含 0,且該格配對數 ≥ 100。
- **不存在** ⟺ 乙版 `G1 − G2 ≤ 0`(即保留率 ≤ 0)。
- **其餘 = 量不出**(包括保留率在 0 與 50% 之間那一段)。

### 對應票面那四條分支

| 票面寫法 | 本檔的落地 |
|---|---|
| 甲版方向對且乙版保住甲版量級的一半以上 = 存在 | 判詞① 存在 + 判詞② 存在 |
| 甲版方向對而乙版歸零 = A-042 推翻(解析度來自事後眼光) | 判詞② 不存在 → A-042 `overturned` |
| 甲版本身方向不對 = 不存在 | 判詞① 不存在 |
| 配對不足 = 量不出 | 第 8 節,兩條判詞都先判量不出 |

### A-042 的處置(寫死)

- 保留率 **≥ 50%** 且判詞② 存在 → A-042 `status: holds`。
- 保留率 **≤ 0**(乙版歸零或轉負)→ A-042 `status: overturned`。
- 保留率在 0 與 50% 之間,或該格配對不足 → A-042 維持 `unverified`,並在假設冊寫明
  查到幾多、卡在哪裡。

**A-042 的處置一律用 Edit 工具寫 `.kira/assumptions.jsonl`,不經 shell。**

## 12. 誠實聲明(入報告首段)

1. **這仍然是一張事後編的表。** v2.2 的 65 條鏈、343 家成員,是 2026 年的人回望
   2022–2026 之後編的;哪條鏈存在、邊家屬邊條,全部帶事後眼光。甲版只證「這種分法
   有解析度」,證不到「當年分得出」。用戶已接受這個代價並立 A-042(原話
   「Approximate may twist the performance. But the overall trend should hold」),
   本票的乙版就是答 A-042 那一步。
2. **入位日仍有一半是近似。** v2.2 的 `valid_from` 約六成標「近似」;本檔的做法是
   把近似成員擋在 2023-01-01 之前的切片外,但 2023 與 2025 兩個主切片照收——
   即主切片的成員資格本身仍然帶入位日誤差。
3. **宇宙是倖存者,而且缺了四分一。** 343 家之中 **85 家沒有價格也沒有子行業**
   (它們從未進過 KARST-157 那 728 家宇宙),本票按票面不重抓,所以整批缺席;
   受影響最重的是 `ai_hpc_hosting`(CORZ 與 APLD 兩家缺席)。另外,能抓到價格的
   全部是今日仍在市的公司,除牌的一家都補不回。
4. **子行業不是官方 GICS。** 用 yfinance 的 `industry` 欄作近似;XLC 與 XLRE 不在日線檔內,
   通訊服務對 XLK、房地產對 XLF。
5. **乙版只答半條問題。** 乙版問的是:**名冊已經給定的前提下**,分組能不能只用切片日之前的
   年報文本重建出來。它**不答**「這批公司當年選不選得出」——名冊本身仍然是事後選的。
   所以乙版就算過關,也只證「分組事前可得」,不證「整張表事前可得」。
   另外乙版用固定層數的凝聚式聚類(不是 v2 的 HDBSCAN),為的是保住「同一套配對」;
   這與 v2 的機器臂不是同一個做法,兩者的數不可直接互比。
6. **語意模型的訓練語料可能含事後知識。** all-MiniLM-L6-v2 的訓練截止期在切片日之後,
   它對「哪些字講同一個故事」的認知可能已經吸收了切片日之後才成形的敘事。
   即是說乙-B 其實**偏向高估**事前可得性——這個方向對「歸零」那個結論有利、
   對「保住」那個結論不利,報告要講明。
7. **2023 切片之後的十二個月含 AI 敘事大牛市**,兩個主切片一律分開報,不合併。
