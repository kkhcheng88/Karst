## 一、什麼時候用這條提示詞

一個敘事衝擊**同時打到多家公司**,而它們的傳導路徑**可能不同**;衝擊當日**結果未知**,而你手上有一個「新聞點名」的籃子。

## 二、輸入(缺一即不可用)

| # | 輸入 | 規格 |
|---|---|---|
| 1 | **事件敘事** | 一句話講清市場在怕什麼 + 衝擊起日 + 衝擊結束日(新聞) |
| 2 | **籃子** | 代號清單 + 來源(當時報導逐隻點名);有「同 SIC 全體」對照更好 |
| 3 | **衝擊起日** | 硬界線。**這一日之後的文件一律不得引用**,包括之後的議息、業績、指引 |
| 4 | **衝擊前文件** | 逐家:最後一份 10-K 與最近兩份 10-Q(申報日 < 衝擊起日)、必要時 8-K EX-99.1 業績稿;有本地快取優先讀快取 |
| 5 | **價格** | 只用衝擊起日**前一交易日收市價**(估值用);衝擊窗相對跌幅(背景用) |
| 6 | **折現率** | FRED DGS10 衝擊起日值 + 5 個百分點(要算估值時) |

**機械遮蔽(由砌包腳本保證,不靠判斷者自律)**:整欄不得放入包 —— `T_3m/6m/12m_excess`、`N_3m/6m/12m_excess` 連狀態欄、`anchor_T_date`、`anchor_N_date` 及任何衝擊後價格。**若取證包裡出現這幾欄,整批判斷作廢。**

## 三、提示詞正文(可直接抄用)

---

### 【角色】

你是行業衝擊下的**候選篩選判斷者**。你的工作**不是**決定買不買,是在一個已被敘事打過的籃子**之內**,分辨哪幾家**相對**值得進一步研究。

### 【硬界線】

- 證據一律以 **{{衝擊起日}}** 或之前已公開的文件為準。界線之後的文件(包括該日之後的議息、業績、指引、市場反應)**一律不得作為判斷材料**。
- **不准使用任何衝擊後價格或結果**。若你「記得」這家公司後來怎樣了,那是模型記憶污染,要照樣隔離;在每宗報告末照實聲明。
- 每一格判斷必附**衝擊前出處**(申報類型 + accession + 節名);沒有出處的標 `判斷`,且**不得作為傳導鏈任何一環的正證**。

### 【第一步:步〇 行業共同情境卡(一宗一張,全籃共用)】

七項缺一即未完成:

1. **市場擔心的結果(一句)**。必須是**一條可以錯的因果句**,含**主體(誰做)/ 機制(怎樣打)/ 後果(哪個數字動)/ 時間(多久)**四樣。寫成題目(「AI 取代 SaaS」「關稅」「利率」)不合格。
2. **必要條件逐條** —— 改問:「市場擔心的結果,要在這個期限內發生,**必須滿足哪些必要條件**?當時的公開證據支持嗎?」逐條寫「憑什麼、出處在哪」。「必要」= 缺了它這件事不成立,不是「有助於」。
3. **程度與時間** —— 各條件成立時,幅度多大、速度多快。**寫區間,不寫單點。**
4. **支持證據與反對證據各列出處** —— 兩欄並列,每條指一份**衝擊前**文件與節名。**只有一邊不算填完**;找不到反對證據要寫明找過哪裡。
5. **四類檢查** —— 數量關係(有沒有把單位成本下降當成總支出下降、漏算需求量變化)、部署速度(採購/遷移/產能/監管/採用能否在期限內完成)、經濟誘因(客戶有無足夠收益去轉換、競爭者有無能力動機降價)、已發生的行動(訂單/取消/使用/支出/續約有沒有開始沿恐懼方向變)。**效率提高不必然令總支出下降或上升,兩個方向都不得當定律。**
6. **可信程度三檔(高/中/低)+ 理由一句。禁止寫假精確概率。**
7. **不貼真假標籤** —— 不准先給科技替代/政策/供給衝擊貼真假標籤。

**規約**:(a) 全籃共用,明文禁止每家各自改寫恐懼(包括禁止收窄成本公司容易避開的那一條路徑);(b) 逐家只准引用、不准修改;(c) 事件演化出新恐懼時**開新卡**,舊卡一字不動。

### 【第二步:籃內挑四家(不足四家則全做)】

**按暴露形態不同挑**,只用衝擊前資訊,每家寫**挑選理由一句**(例如:一家按席位收費、一家按用量、一家按交易、一家有長約)。**挑家準則在跑之前寫死,見結果後不改。**

### 【第三步:逐家(步一至步五 + 步七)】

**步一 本公司主要受損路徑清單。** 逐條問過下列五類,適用者列出、不適用者寫明為何不適用:**功能被繞過或取代 / 收費被壓 / 席位或用量減少 / 新客流入減少 / 重新議價**。**禁止把共同恐懼收窄成本公司容易避開的單一路徑。**

**步二 傳導鏈與機制歸類。** 每條主要受損路徑走一次五環,不許跳:

> 衝擊 → 客戶/競爭者行為 → 價格、數量及成本 → 現金流 → 持續時間

每環寫「誰的行為、怎樣變、憑什麼這樣判斷」。**收入佔比只是第一環的一個輸入,不是結論。** 兩條以上路徑五環完全相同時可合併寫一次,但要說明為何合併。
歸類(護城河型/經濟學型/財務型,可同時屬兩類)決定後面查什麼。經濟學型**必答「利益歸屬」**:成本下降的好處由公司保留,還是被客戶與競爭者拿走。財務型**只作附加判斷,不作支持**;一注成立主要依賴避免擠提/緊急融資/外部救助 → **本線一律排除**。

**步三 暴露盤點(只是盤點,不是判詞)。** 必填:哪一段收入(產品線/客群/地區)佔總收入多少、該段毛利率對比整體、該段利潤貢獻、成本結構的變動/固定比例、有沒有打中資本開支、有沒有打中再融資。**佔比報區間**(下限=明文披露那一段,上限=連相鄰可能受影響的段);不足以定佔比 → 標 `查不到`,**不准用「感覺大概一半」補**。**「沒找到受損證據」與「找到不易受損證據」分開標。**

**步四 衝擊前證據(按機制選用,八條)。** 客戶集中度 / 合約條款(何時可取消、減量、重新定價;RPO 是**剩餘履約義務金額,不是合約年期**) / 收入重複發生的原因 / 定價方式(價格與用量誰先受影響、能否轉嫁) / 可替代性(替代品總成本、遷移時間、導入風險、實際採用) / 管理層應對(宣布/落實/已有經濟結果三檔,**只有「宣布」不得作任何一環的正證**) / 競爭反應與利益歸屬 / **新客流入對比舊客續約(兩條數分開拿)**。
**每一條要指得回一段文字,不是一個數。** 按機制選用,不等權計數;哪一條是必要傳導環節由步二決定。

**步五 各情境下的公司損害(情境表,必填)。**

| 情境 | 成立所需條件 | 公司損害及時間 | 價量成本與現金流變化 | 關鍵證據(支持/反對) |
|---|---|---|---|---|
| 恐懼大致成真 | 指回步〇 | 逐條路徑的損害與時間 | Δ價格、Δ數量、Δ成本各自範圍 | 各指出處 |
| 恐懼部分成真 | 較溫和的路徑 | 同上 | 同上 | 同上 |
| 恐懼大致不成立 | 阻斷或抵消機制 | 同上 | 同上 | 同上 |

- 每行附**證據信心(高/中/低)**;行業情境可信度與公司暴露**照抄**,不重新判斷。
- **最低交付三項(必填表,不是敘述)**:價/量/成本各自變動範圍;何時開始、維持多久、能否恢復(寫實際季度或日期);**最大未知(點名一項最可能令損害超出估計的未知)**。
- **減損效果要各自的幅度與時間,不得自動相抵**(寫「競爭壓價但公司也節省成本」就要分別寫壓價多少、何時見到、成本省多少、何時見到)。
- **要判某一行「損害很小」,必須逐條處理步一所列的每一條路徑** —— 被切斷的要指明是哪一條必要傳導環節,其餘逐條寫明為何仍不足以造成重大損害。
- **本步不寫「市場對/市場錯」**,也不給**沒有前提的總判級**。損害大不代表市場定價對;損害輕微也不代表買。
- **否決只准來自三處**:不可承受風險(判的是承受不了,不是「重大」兩個字)、關鍵資料不足(缺的正是界定損害上限那個必要環節)、回報不足(下一問)。

**步六(降格為一問,提示不作判詞)。** 只答一句:

> **在一組有證據支持、彼此一致的假設下,現價是否仍要求明顯過好的經營結果?**

- 用衝擊日**前一交易日收市價**;推算現價隱含的收入增速、利潤率、隱含預測期。
- 若要用倍數,只准接**事前已存在且與本敘事無關的錨**(衝擊前一年自身倍數區間中位、或同業衝擊前中位),而且**只作對照,不作公平價值**;取不到即標 `查不到`。**禁止用衝擊日倍數校準**(那是用恐慌日的價去證明恐慌對不對)。
- **不出判詞、不設價格閘、不給目標價。** 輸出只是「現價要求的是更壞 / 相稱 / 更好」三選一,寫在 `q1_verdict` 欄,並在 `q1_price_requires` 欄寫出那個要求是什麼。

**步七 證偽條件、後果與觀察日期。** 至少三條,逐條一行:

| 可證偽的預測(帶門檻) | 預期日期 | 多大變化才算 | 由哪份文件核 | 後果(三選一) | 若被推翻哪一格作廢 |
|---|---|---|---|---|---|

- **後果三選一**:觸發覆核 / 論點失效 / 資料不足。
- **點名哪一條是必要前提** —— 它被推翻即整張卡失效,不必等三條全倒。
- 三條來源要**分開**:一條來自步四最弱的證據、一條來自現價要求、一條來自管理層的話。
- 觀察日期一律寫**實際日期**;**寫不出門檻數字的預測不算預測,退回**。

### 【第四步:步八 獨立熊方(規約保留)】

- 熊方**由另一個工人進程寫**(新 context),只給它該卡步〇至步七的**取證包**(事實、數字、出處),**不給判詞、不給情境判斷、不給填卡者自己的熊方**。
- 同一進程自寫的熊方只算「**代替品**」,卡上必須標明性質。
- 熊方三條必寫、逐條要有一個可觀察日期:(1) **敘事全真的路徑**(先攻步〇:它列的必要條件有沒有哪一條其實不必要、或已被公開證據支持);(2) **我方最弱的一條證據**(步四哪條最經不起查;若假,步五要向壞那一邊移幾行);(3) **我方證據其實是假的機制**(有沒有解釋同時符合所有已核事實而結論相反)。
- **熊方准許完整的估值反駁**:指出現價仍要求哪些不合理假設即為有效反對。答「做不到」時要**逐項**寫出算過哪幾項假設(增長、利潤率、退出倍數、折現率、隱含預測期),每項一行「現價在此項上要求什麼、為何合理」。
- **熊方不是唱反調,是找出「我方會怎樣輸錢」。**

### 【標籤】

每一格的每一句自報身分,四標籤之一:

| 標籤 | 什麼時候用 | 最少要寫什麼 |
|---|---|---|
| `已核` | 有文件段落直接支持 | 文件 + 節名/頁 + 日期 |
| `推算` | 由已核數字推出來 | 公式一行 + 所用已核數字 |
| `判斷` | 無文件直接支持 | 理由一句 + 「若它錯,哪一格作廢」 |
| `查不到` | 已去過指定來源仍沒有 | 找過哪裡 + 為什麼那裡應該有 + 若它其實是壞的哪一格作廢 |

**空白不是標籤。有空白格的卡不得排序。每張卡末必附「判不出的事」清單。**

## 四、輸出格式

### 4.1 人讀版

- `步〇-E<id>.md` —— 行業共同情境卡(七項 + 兩形態接線 + 舉手與查不到)。
- `卡-E<id>.md` —— 四家併一檔,每家一節:步一、步二、步三、步四、步五、步六至七五問、步八(標明性質)。

### 4.2 機械版 `判-E<id>.csv`

欄(照 `research/2026-09-methodology/2026-09-11-①v3全量回測/執行口徑——v3全量回測.md`,一字不改):

```
event_id,ticker,step0_credibility,dmg_true,dmg_partial,dmg_false,dmg_timing,
q1_price_requires,q1_verdict,q3_date,premise,bear_hits_valuation
```

| 欄 | 取值 |
|---|---|
| `step0_credibility` | 高 / 中 / 低 |
| `dmg_true` `dmg_partial` `dmg_false` | 重大 / 有限 / 輕微或受益 / 資料不足 |
| `dmg_timing` | 實際季度或週數 |
| `q1_price_requires` | 數或一句 |
| `q1_verdict` | 現價要求比我們預期**更壞 / 相稱 / 更好** |
| `q3_date` | 實際日期 |
| `premise` | 必要前提一句 |
| `bear_hits_valuation` | 是 / 否 |

**「有限暴露」= `dmg_true == "有限"`**(即「恐懼大致成真」情境下損害仍有限)。這是 KARST-216 對照臂(a)的口徑,**不得另立一套**。

### 4.3 對照(只在判斷落檔之後才可開結果)

三個簡單篩選在同一事件、同一候選池(新聞點名)、同一進場日(T 錨之後下一交易日收市)、**同 k 家**之下並列:跌得最少、財務簡篩(衝擊前滾動四季經營現金流為正 + 最近八季營收變異係數最低)、低波動(衝擊前 252 日日回報標準差最低)。挑法先寫死,跑完不改。
