# 六層分析紀律(v1,2026-09-14;KARST-239)

> 工作台對任何股票都跑同一套六層;每層有負責角色、必答問題、必用證據、輸出欄位、與上下層的接線、時間框架約束。開工前先讀 `strategy/投資委託.md`。大師原則的適用條件另檔 `大師原則——適用條件與取捨-v1.md`(由 `library/insights/` 抽出,附出處)。本檔是 D-179 第 2 條的落實;第六輪外評的修訂(每層有負責者、技術層規則、論點各有期限與退出)已納入。

## 零、五個角色與六層的對應

| 角色 | 負責層 | 模型 | 讀什麼 |
|---|---|---|---|
| 產業、價值鏈與宏觀 | L1 市場與宏觀、L2 產業與價值鏈 | Opus,直讀原文 | 產業卡、市場卡、同業與客戶供應商申報、產業報告、宏觀序列 |
| 公司與財務 | L3 公司基本面 | Opus,直讀原文 | 最新業績稿、年報季報、逐字稿、八季數列、收入拆分 |
| 估值與預期 | L4 估值與預期 | Opus | 共識、評級與目標價歷史、估值百分位、Morningstar、① 計算器輸出 |
| 技術與市場行為 | L5 技術與市場行為 | 程式算結構,Opus 判影響 | 日線、量、沽空、資金流、異動 |
| 反方 | 橫跨六層 | Opus,獨立進程,只看取證包與各層輸出 | 全部 |
| 綜合 | L6 投資綜合 | Opus | 上五層輸出、反方、投資委託、持倉 |

程式(不經模型)負責:取證包、數列、指標與結構計算、估值算式、風險回報算式、頁面生成。便宜模型(DeepSeek)負責:去重、格式、抽取、初稿整理。

## 一、六層

每層四項:必答問題、必用證據、輸出欄位、接線。每格輸出都附「所用證據編號」與「資料截至時間」;答不到就寫「缺哪項資料、影響哪個結論、建議怎樣調整」,不留白、不寫籠統的「未量度」。

### L1 市場與宏觀

- **必答**:利率、流動性、政策、匯率、終端需求對這項投資有何實質影響?哪些是這家公司真正敏感的變數?市場現時對這些變數的預期是什麼?
- **必用**:宏觀指標序列、經濟日曆、市場卡(按主題)。
- **輸出**:`sensitivities`(公司敏感的宏觀變數與方向)、`macro_view`(每個變數一句目前判讀與依據)、`macro_risks`(可能推翻論點的宏觀情境)。
- **接線**:輸出的變數編號供 L4 折現率與情境使用;市場卡版本改變時觸發依賴它的 L1 與 L4。

### L2 產業與價值鏈

- **必答**:利潤流向鏈上哪個環節?誰掌握瓶頸與定價權?新增供給與競爭會怎樣改變它?這家公司在鏈上的位置、角色(買方、供應商、設備商、替代品)與暴露程度?行業資本週期在哪一段(Chancellor 四段)?
- **必用**:產業卡與假設清單、成員與關係表(方向、類型、依據)、同業與客戶供應商的申報、**用戶放進 inbox 的分析員報告與線上研究(帶來源、日期與適用期間;誰說的與本系統採納的分開記)**、產業報告、行業估值與排名。
- **輸出**:`chain_position`、`industry_assumptions`(引用產業卡假設編號與版本)、`exposure`(對共同假設的暴露:重大 / 有限 / 輕微或受益 / 資料不足,附機制)、`capital_cycle_phase`、`supply_side`(有效供給會不會在持有期追上需求;必答,可答不適用加理由)。
- **接線**:產業卡假設更新 → 經關係表傳到所有依賴的公司 L2 → 逐家重評暴露(① 暴露差異判斷能力卡的方法);L2 的暴露判級供 L3 情境與 L4 情境權重使用。

### L3 公司基本面

- **必答**:公司怎樣把產業機會轉成收入、利潤與現金流?最新經營變化是什麼,由什麼驅動(需求、價格、份額、併購、匯率、低基期、一次性、供需擠壓)?改善的品質與持續性(其後兩至四季)?財務風險(債務、再融資、燒錢速度)?管理層講了什麼、兌現紀錄如何?
- **必用**:當日業績稿全文、最近年報與兩份季報、**業績電話會逐字稿(DefeatBeta;必讀,問答部分優先;缺即在卡上標「無逐字稿」)**、截止前八季四欄加十項數列(首報值用於歷史,日常用最新修正值並保留舊版)、收入拆分、上一稿指引、**用戶放進 inbox 的分析員報告(其預測與本系統的判斷分開記,作 L4 預期差的輸入)**。
- **輸出**:照 ② 提示詞 v1.1 的機械版欄位(驅動拆分與份額、供給側、其後兩季與四季收入增速點值與區間、延續機率與判級、失效條件、最大未知、資料缺陷自報),加 `financial_risk`、`management_track_record`、`improvement_where`(改善在收入、毛利、營業利潤、現金流哪一項)。
- **接線**:L3 的增速與利潤率路徑是 L4 估值的輸入;L2 的暴露判級決定 L3 情境的權重;L3 的失效條件進入論點卡與計劃。

### L4 估值與預期

- **必答**:現價已反映什麼(反向:在其餘假設固定下,現價要求多高的成長或利潤率才成立)?我們的判斷與市場預期差在哪裡(共識、評級與目標價的近期修訂方向)?正向估值下公司值多少(三情境)?實現需要多久?哪些假設最能改變結果?
- **必用**:① 隱含預期計算器(由 tag 還原:自由現金流估值、逐家折現率、終值、情境、敏感度)、共識與預期歷史、評級與目標價月度歷史、估值百分位與同業分佈、Morningstar 公允價值(只作對照)。
- **輸出**:`implied_requirements`(現價要求的成長、利潤率、期限)、`scenarios`(悲觀 / 基準 / 樂觀:假設、每股價值、機率由 L3 延續機率與 L2 暴露推出)、`expectation_gap`(我們對市場的差異與方向)、`sensitivity`(最敏感的三個假設)、`time_to_realise`。
- **接線**:方法按公司類型選(自由現金流、股權剩餘收益、分部估值);由現價解出的隱含條件不得回頭當作現價合理的獨立證據(① 教訓);L4 輸出供 L6 定「現價值不值得」與計劃目標。

### L5 技術與市場行為

- **必答**:在上述判斷下,目前價格位置、成交、趨勢對入場、加減倉有何含義?多週期(週線、日線、需要時較短)是否一致?最近的價格行為(突破、回踩、假突破、拒絕、收縮或擴張)有沒有量能配合?動能加速還是減速、相對大市與同業強弱、有沒有背離?波動與失效位置的距離是否容許合理的止損?
- **必用**:日線與週線、量、ATR、相對強弱、沽空(分清未平倉與每日成交量)、資金流、異動警示。
- **程式算的結構(固定定義,寫在 `karst/ta/` 並版本化)**:支持阻力區(以區域不以線;形成依據、最近測試、突破或失守後的下一區);突破與回踩(收市為準,量能相對二十日均量);ATR(14)與止損距離;相對強弱(對 SPY 與同業籃,20 / 60 / 120 日);SMC 結構——BOS、CHoCH(以收市確認 swing,swing 定義為左右各 N 根)、order block(最後一根反向 K 線,失效條件為收市穿越)、FVG(三根 K 線缺口,填補即失效)、流動性集中區(等高低點);每項標所在週期與成立條件。
- **輸出**:`structure`(上述結構清單)、`momentum`(加速 / 減速、相對強弱、背離)、`ta_reading`(角色判讀:對入場、加減倉的含義;短週期轉弱是否推翻長期論點要另外論證)、`entry_zone`、`invalidation_level`、`resistance_zones`。
- **接線**:L5 只影響進出場與風險回報,不作為論點成立與否的證據(D-166:技術面只在事件窗);SMC 名詞只描述結構,不寫「機構吸貨」一類意圖。

### L6 投資綜合

- **必答**:按投資委託的期限與風險方式,現在應採取什麼行動,為什麼?機會在哪裡、為什麼是現在?風險回報如何?什麼會推翻判斷?與上次相比改變了什麼?哪些資料缺失,怎樣影響結論?
- **必用**:L1 至 L5 輸出、反方報告、投資委託、持倉與組合曝險。
- **輸出**:股票頁六行(第二節)、投資計劃(第三節)、`open_questions`、`next_check`(下次驗證事件與日期)、`changed_since_last`。
- **接線**:綜合不由「幾個角色同意」推算信心;採納了什麼、駁回了什麼、依據在哪裡要寫出;反方的最強一條必須正面回答。

### 反方(橫跨六層)

- 獨立進程,只讀取證包與各層輸出,不讀綜合;必攻:最脆弱假設、替代解釋(提前拉貨、低基期、一次性、口徑改變)、與論點衝突的證據、任何「不適用」的供給側答案、估值假設中無來源的倍數;准估值反駁。輸出 `strongest_counter`(一條)、`counters`(全部)、`unverifiable`(查不到的)。

## 二、股票頁六行

| 行 | 定義 | 缺資料時的寫法 |
|---|---|---|
| 目前建議 | 值得考慮 / 等待條件 / 現價不吸引 / 維持持倉 / 減倉;附持有期限與類別(①②③④) | 「資料不足以建議:缺 X,待 Y 後再評」 |
| 主要理由 | 一句:論點成立與否,加現價付了多少 | 同上 |
| 判斷的關鍵假設 | 一至兩條,引用假設編號 | 寫哪條假設無法核 |
| 最強反證 | 反方的最強一條與綜合的回應 | 反方查不到時寫「反方未找到可核反證」 |
| 改變行動的條件 | 價格條件與證據條件各一 | — |
| 與上次相比 | 基本面看法、價格與預期回報、計劃各改了什麼 | 首版寫「首版」 |

## 三、投資計劃欄位

| 欄位 | 定義 |
|---|---|
| 持有期限 | 預計實現時間,與哪個催化劑或經營變化掛鈎 |
| 建議行動 | 現價進場 / 等回調 / 等突破確認 / 維持 / 減倉 |
| 入場方式 | 價格區域、確認條件、是否分段 |
| 失效與退出 | 技術失效位、基本面論點失效條件、到期未發展的處理 |
| 目標與減倉 | 各階段目標的依據(L4 情境價值、L5 阻力區分開標)、預計時間、減倉安排 |
| 部位大小 | 由投資委託的每注風險預算、止損距離、集中度與其他持倉曝險推出;暫定參數明標 |
| 風險回報 | 單一目標:(目標價 − 入場價)÷(入場價 − 止損價);分批按整體方案含成本與滑價;另列業績跳空等壓力情境;不准用拉遠目標或收窄止損做出漂亮比率;目標可達性與所需時間要講 |
| 更新條件 | 哪些價格、公告、產業事件觸發重評;覆核到期日 |

內在價值、持有期目標價、技術阻力三者分開標,不混用。

## 四、時間框架約束

每張論點寫期限;短週期技術轉弱可影響執行,是否推翻長期論點要另外論證;公司長期前景好不自動支持現價買入。同一公司可有多個論點(例如兩季盈利復甦與三星期突破交易),各有期限、假設、反證、失效與退出規則,不共用。

## 五、嵌入的既有能力

- ② 改善驅動可持續性判斷(提示詞 v1.1)嵌入 L3;其在開發樣本的初步支持與未證項見能力卡 v1 證據與權限紀錄。
- ① 暴露差異判斷(能力卡 v1)嵌入 L2「產業更新 → 逐家重評」。
- 論點卡與敘事衝擊檢查清單 v3 的步〇(行業共同情境卡)與步五(情境表)供 L2 與 L3 用;步六(現價對衝擊後價值)供 L4。
