# 六層分析紀律(v1.2,2026-09-14;KARST-239)

> 工作台對任何股票都跑同一套六層;每層有負責角色、必答問題、必用證據、輸出欄位、與上下層的接線、時間框架約束。開工前先讀清理後的 `strategy/投資委託.md` 與 `strategy/投資決策模型.md`。現行策略與隔離依 D-181;研究不讀實際或模型組合帳本,執行設計見 `獨立投研工作台設計與交付計劃-v1.md`。大師原則的適用條件另檔 `大師原則——適用條件與取捨-v1.md`(由 `library/insights/` 抽出,附出處;原負責者已於本輪期間提交,本次未逐條覆核其來源)。依實際讀取及核過的版本使用原則或 insights,逐條注明適用期限、生意與資金／執行前提;互相衝突時說明取捨,不拼成全部必須通過的篩選器。本檔是 D-179 第 2 條的落實;第六輪外評的修訂(每層有負責者、技術層規則、論點各有期限與退出)已納入。

## 零、六個角色與六層的對應

| 角色 | 負責層 | 模型 | 讀什麼 |
|---|---|---|---|
| 產業、價值鏈與宏觀 | L1 市場與宏觀、L2 產業與價值鏈 | Opus,直讀原文 | 產業卡、市場卡、同業與客戶供應商申報、產業報告、宏觀序列 |
| 公司與財務 | L3 公司基本面 | Opus,直讀原文 | 最新業績稿、年報季報、逐字稿、八季數列、收入拆分 |
| 估值與預期 | L4 估值與預期 | Opus,可直讀原文補查 | L2/L3 情境、原始財報與報告、共識、評級與目標價歷史、Morningstar、估值計算器輸出 |
| 技術與市場行為 | L5 技術與市場行為 | 程式算結構,Opus 判影響 | 日線、量、沽空、資金流、異動 |
| 反方 | 橫跨六層 | Opus,獨立上下文,可補查 | 先讀原始證據形成替代解釋,再讀各層輸出審查;不讀綜合 |
| 綜合 | L6 投資綜合 | Opus,可回讀原文與要求重評 | 上五層輸出、反方、清理後研究委託、關鍵依據的原始證據 |

程式(不經模型)負責:取證包、數列、指標與結構計算、估值算式、風險回報算式、頁面生成。便宜模型(DeepSeek)負責:去重、格式、抽取、初稿整理。抽取與摘要須保留原文定位、單位、期間、否定與條件語句;不能成為強模型唯一可見的證據。模型名稱與推理設定由執行配置選擇,每次保存實際版本,不由文件中的簡稱猜測。

**角色的取證權與必讀紀律**:

- 研究角色以新上下文與工具允許清單運行,不繼承整個開發對話、CLAUDE／HANDOFF／.kira 或私人帳戶資料。只准公開市場工具,補查仍經來源登記;模型組合帳本在另一個執行邊界。公司公開機構持股／內部人交易可以取用。

- 取證包是起點,各判斷角色均可讀完整來源、搜尋及要求補抓;反方與綜合也有此權。實作把這些操作映射到本地快取及已接的資料工具,不能只給摘要而把關鍵資料擋在上游。
- 首次分析與新業績事件,L3 必讀最新業績稿與已取得的完整逐字稿(含 prepared remarks 與 Q&A),並比較上一次指引;Q&A 優先不等於可以省略管理層正式陳述。價格日若來源版本相同則沿用已讀紀錄,不重新讀全文。
- 缺逐字稿時先依 `strategy/資料來源.md` 查主源、公司 IR 或其他可取得的文字來源;區分未發布、來源未覆蓋、抓取失敗及只有部分文本。仍可出卡,寫清楚缺什麼及影響;新逐字稿到達必觸發 L3 重評。
- 任一角色發現會改變結論的新證據,先入庫再引用,記錄本次輸入更新並重評受影響的下游層;同一份來源被多份報告轉述只算同一條證據來源。用戶筆記中的推論保留為用戶假設,不能因入庫而升格成外部已核事實。

## 一、六層

每層四項:必答問題、必用證據、輸出欄位、接線。每格輸出都附「所用證據版本與原文定位」;每層記 `assessed_at`、輸入來源各自的 `data_as_of`、`pending_updates` 與 `next_review_at`。文件公開／取得時間與所述事實／預測期間依資料來源正本分開;答不到就寫「缺哪項資料、影響哪個結論、建議怎樣調整」,不留白、不寫籠統的「未量度」。

### L1 市場與宏觀

- **必答**:利率、流動性、政策、匯率、終端需求對這項投資有何實質影響?哪些是這家公司真正敏感的變數?市場現時對這些變數的預期是什麼?
- **必用**:宏觀指標序列、經濟日曆、市場卡(按主題)。
- **輸出**:`sensitivities`(公司敏感的宏觀變數與方向)、`macro_view`(每個變數一句目前判讀與依據)、`macro_risks`(可能推翻論點的宏觀情境)。
- **接線**:敏感變數按機制連到 L2 供需、L3 收入／成本／融資與 L4 現金流及折現率;市場卡更新只觸發有依賴的部分。同一宏觀衝擊在現金流與折現率的處理要說明,不能無依據重複加罰。

### L2 產業與價值鏈

- **必答**:利潤流向鏈上哪個環節?誰掌握瓶頸與定價權?新增供給與競爭會怎樣改變它?這家公司在鏈上的位置、角色(買方、供應商、設備商、替代品)與暴露程度?行業資本週期在哪一段(Chancellor 四段)?
- **必用**:產業卡與假設清單、成員與關係表(方向、類型、依據)、同業與客戶供應商的申報、**用戶放進 inbox 的分析員報告與線上研究(帶來源、日期與適用期間;誰說的與本系統採納的分開記)**、產業報告、行業估值與排名。
- **輸出**:`chain_position`、`industry_assumptions`(引用產業卡假設編號與版本)、`exposure`(分開記方向:受益 / 受損 / 混合 / 未知;程度:重大 / 有限 / 輕微 / 未知,附機制、期間與可取得的經濟量)、`capital_cycle_phase`、`supply_side`(有效供給會不會在持有期追上需求;必答,可答不適用加理由)。
- **接線**:產業卡假設更新 → 經關係表傳到所有依賴的公司 L2 → 逐家重評暴露(① 暴露差異判斷能力卡的方法);L2 的暴露機制與經濟量供 L3/L4 建立情境,不把重大／輕微的等級機械轉為機率。關係表的公司與鏈位標記未覆蓋新關係時,先列待確認關係,不當作沒有暴露。

### L3 公司基本面

- **必答**:公司怎樣把產業機會轉成收入、利潤與現金流?最新經營變化是什麼,由什麼驅動(需求、價格、份額、併購、匯率、低基期、一次性、供需擠壓)?改善的品質與持續性(其後兩至四季)?財務風險(債務、再融資、燒錢速度)?管理層講了什麼、兌現紀錄如何?
- **申報讀法(用戶 2026-09-15 對齊)**:每季三份文件按公開次序——業績公告(8-K 第 2.02 項附業績稿,全文)→ 電話會逐字稿(全文含問答)→ 季報或年報(抽節)。年報只讀四節:業務描述(客戶集中、供應商依賴、產能、產品線、競爭者)、風險因素(年與年之間新增或刪除的條目是最強訊號)、管理層討論(收入歸因、毛利率、資本開支、流動性與到期債務)、附註中的分部與地區收入、股權薪酬、可轉債與稀釋、承諾與或有事項;法律程序、董事薪酬、控制與程序、會計政策樣板不讀。首次建卡讀四節,之後只在新年報或新季報出來時重讀有變的節;價格日不讀。年報遲出不阻出卡:用新業績稿與逐字稿加舊年報四節,卡上寫明「年報為上一財年版本」。訊號季數字不在業績稿內的,標記並等季報。
- **必用**:最新已發布業績稿全文及其後更新、最近年報與兩份可取得的季報(按公司適用申報形式;按上一條抽節)、**業績電話會逐字稿(DefeatBeta 為主;全文必讀,問答可優先;缺則依前述必讀紀律查備援並說明影響)**、截止前八季四欄加十項數列(②凍結考試保留首報值,其他歷史按各自協議;日常用最新適用修正值並保留舊版)、收入拆分、上一稿指引、**用戶放進 inbox 的分析員報告(其預測與本系統的判斷分開記,作 L4 預期差的輸入)**。
- **輸出**:共用 `business_drivers`、`financial_risk`、`management_track_record`、`improvement_where`、`cash_flow_bridge`、`key_metrics`(定義、單位、基期、未來期間、依據)、失效條件及最大未知。`cash_flow_bridge` 對照收入、利潤、現金流、再投資、股權薪酬、融資與每股稀釋;資料不足不硬填點值。
- **每股必答的共同敘事問題**:市場現在相信什麼?我們同意或不同意哪一部分?這個差異怎樣影響未來每股價值,以及現價值得付多少?
- **按情境模組加問(D-182,用戶 2026-09-15 定)**:四類注是可啟用的情境分析模組,啟用是待證假設,啟用理由要寫明並有可核查的事件與假說(不需要先證明市場錯了才准研究)。潛在錯殺模組攻永久損害與價值陷阱、損害幅度與修復證據,研究方向是「市場為何沒錯」;改善趨勢模組攻驅動能否延續與現價已反映多少;**敘事與預期差模組**在敘事成為主要爭議時啟用,追查五件事(敘事內容、證據狀態、經濟傳導、市場預期、驗證與反證),問題分支按敘事類型選——商業化(誰付錢、何時形成收入與現金流、此前要多少資金與稀釋)、替代威脅(被取代的是產品、功能還是定價權,何時進財報)、供需轉變(需求能否持續、新增供給何時到達、利潤落在哪個環節)、轉型與資本配置(是否提高每股價值、執行條件與代價)。可重疊,不強制歸類,不以②的正收入／強反應入口篩掉其他公司。
- **②欄位的適用性**:有可定義的改善基期與目標時,沿用其後兩／四季收入增速、驅動拆分、`p_continue` 的明確事件定義;不適用或資料不足時允許空值並寫理由。另按生意選 1–3 項重要指標(如利潤、現金轉換、訂單或商業化進度),不把收入增速當所有公司的唯一品質尺。
- **接線**:L3 提供各情境的經營、再投資、融資與每股路徑到 L4;共同假設使用同一編號與版本。`p_continue` 是指定經營事件的機率,不是股價上升、到達目標或估值樂觀情境的機率;L3 的失效條件進入論點卡與計劃。

### L4 估值與預期

- **必答**:現價已反映什麼(反向:在其餘假設固定下,現價要求多高的成長或利潤率才成立)?我們的判斷與市場預期差在哪裡(共識、評級與目標價的近期修訂方向)?正向估值下公司值多少(三情境)?實現需要多久?哪些假設最能改變結果?
- **必用**:按公司類型選擇的估值計算器(①計算器由 tag 還原後先核輸入與算式,不視為已完成)、L3 現金流與稀釋路徑、共識與預期歷史、評級與目標價月度歷史、估值百分位與同業分佈、Morningstar 公允價值(只作對照)。
- **輸出**:`implied_requirements`(現價要求的成長、利潤率、期限)、`scenarios`(悲觀 / 基準 / 樂觀:相同估值日的經營、再投資、融資、稀釋、終值與每股價值;機率另說依據,無法合理量化可不填,不能由 L3 延續機率或 L2 暴露等級直接換算)、`expectation_gap`(我們對市場的差異與方向)、`sensitivity`(最敏感的三個假設)、`time_to_realise`。
- **公允價值與中期目標**:L3 提供基本面情境,L4 必須嘗試計算估值日的基準每股內在價值及悲觀／樂觀範圍,附方法、來源輸入、敏感度與現價折讓。基準由經營假設推導,不是兩端簡單中點。另記 `target_date`、`target_scenarios` 與預期分派;解釋持有期內經營／估值／催化劑如何支持該價格,不能把今天的 DCF 公允價值直接當六個月股價。資料不能支持點值時報條件估值或範圍及缺口。方法依據:[Damodaran 估值導論](https://pages.stern.nyu.edu/~adamodar/pdfiles/eqnotes/ValIntroSpr22.pdf);具體中期橋接屬本系統設計。
- **計算紀律**:FCFF 配 WACC、FCFE 配股權成本;資產價值到普通股價值的現金／債務／其他請求權橋接及稀釋股數要可核,同一項不重複計算。股權薪酬／稀釋、資本開支與營運資金、終值佔比與穩態假設不可漏。早期或尚無穩定現金流的生意保留失敗、融資與稀釋情境,不得靠單一遠期倍數補出精確公允價。
- **預期口徑**:管理層指引、單一分析員／Morningstar 觀點、聚合分析員共識、現價反推要求四者分開,各記形成／截至時間、預測期間及 GAAP／調整口徑。同一報告不當成全市場共識;有歷史值也需先核預測版本與覆蓋,才比較修訂方向。正向情境權重不足時報範圍與敏感度,不用任意機率製造期望回報。
- **每次估值必答四問(D-182,用戶 2026-09-15 定)**:(1) 為什麼這個方法適合這家公司,哪些經濟特徵支持選擇;(2) 結果主要依賴哪三個假設,各有什麼證據,改變後價值差多少;(3) 另一種合理視角會得到什麼,差異來自經營、風險、期間還是市場給的倍數,不同結果不准隨便平均;(4) 與上次相比為什麼變了,分清新資料、假設改變與方法改變,不准為保住原評級悄悄換方法。方法跟隨生意的經濟結構(成熟現金流 / 週期正常化 / 商業化前虧損 / 金融企業),情境模組只決定哪些假設要特別審查。輸出欄位加 `method_rationale`、`top3_assumptions`、`alternative_view`、`change_attribution`。
- **接線**:方法按公司類型選(自由現金流、股權剩餘收益、分部估值);由現價解出的隱含條件不得回頭當作現價合理的獨立證據(① 教訓);L4 輸出供 L6 定「現價值不值得」與計劃目標。

### L5 技術與市場行為

> 用戶 2026-09-14 本輪澄清:關心 key pivot points、支撐／阻力與 200MA;提 SMC 是希望有較好的價量閱讀,不是要求一套 SMC 名詞清單。此處 pivot 指結構轉折點與決策價位,不是預設使用前一日 OHLC 算術 Pivot Points。同輪用戶要求規劃日／週／月線、上下行通道、突破回測與圖表形態;「回測突破」按突破後回踩／回抽確認理解,不等同歷史策略回測。

- **必答**:現價距主要支撐、阻力與 200 日均線多遠?哪個價位是下一個要觀察的轉折?價格在該處是守住、突破、回踩、假突破還是失守?量能、動能與相對強弱是否支持這個判讀?突破／失守後下一區在哪,會如何改變進場、加減倉、退出與 R&R?
- **必用**:有一致價格口徑的日線 OHLCV 與由同一交易日曆聚合的週／月線、200 日 SMA、已確認主要高低點、平台及重大事件缺口。ATR 與相對強弱作輔助;沽空、資金流、異動只在有資料且相關時加讀,不因缺一個輔助來源而阻止核心圖表。
- **核心輸出**:

| 欄位 | 必須呈現 |
|---|---|
| `key_levels` | 主要支撐／阻力區的上下界、類型(前高低／平台／事件缺口等)、形成依據與日期、所屬週期、最近測試、現價距離、突破或失守後下一區;避免把每個小 swing 都畫成主價位 |
| `ma200` | 200 日簡單均線數值、現價在上／下、百分比距離、方向(與前 20 個交易日的均線值比較);不足 200 根完整日線時不捏造 |
| `price_volume_action` | 在關鍵區的突破、回踩、拒絕或假突破,附事件起止、收市確認與成交量相對前 20 根完整同週期 K 線的比率;未收市資料只作暫態 |
| `momentum` | 推進加速／減速的價格依據,對 SPY 及合適同業籃的 20／60／120 日相對回報;背離須指出比較的兩個已確認轉折與指標,沒有則不硬填 |
| `execution_implications` | 守住、突破、失守三種條件對進出場的影響,技術失效與計劃執行價分開,連到 L6 |

- **程式與模型分工**:程式算 MA、候選轉折、區域、距離、量能、ATR 與相對回報;模型回看價量及事件背景,挑出對持有期重要的區域並解釋原因。模型補列價位須附可定位的 K 線／事件依據,不得為提高 R&R 移動區界。圖表首版至少同時呈現日線 K 線、成交量、200 日 SMA 與主支撐阻力,可切週／月線。200 日 SMA 以日線計算,週／月視圖可映射該日線值作參考,須標「200 日 SMA」;不得自動變成 200 週或 200 月 MA。
- **日／週／月線分工**:

| 週期 | 要回答 | 對計劃的作用 |
|---|---|---|
| 月線 | 長期上升／下降／盤整、歷史高低與大型供需區、現價是否逼近多年阻力 | 決定背景與長期上方空間;讀歷史可長於持有期,不因此把一月至一年的投資延長數年 |
| 週線 | 主要高低點序列、平台、上下行通道／收斂、與大區域的交會 | 提出主要情境與關鍵確認／失效區;主趨勢不以單根日線轉弱就宣布反轉 |
| 日線 | 200 日 SMA、接近週／月關鍵區時的突破、回踩、假突破及量能 | 定入場、分批、加減倉與可執行退出條件,並重算現價 R&R |

- **跨週期分歧**:例如月線仍在大區間、週線上升、日線回調,應解釋成有條件的回調機會或等待確認;日線突破但上方緊接月線阻力,須減少所估可用空間或等待。三個週期同向只是同一價格序列的不同尺度,不算三份獨立證據;不要求它們全部同向才允許判斷。
- **通道與突破回踩的首版範圍**:水平平台、上升／下降通道、突破與回踩／回抽、假突破／假跌破列為首版。通道用已確認同側轉折定主邊,以對側轉折定平行邊,保存錨點日期、斜率、區間、接觸次數與容差;模型說明為何選它,未有足夠錨點則只列趨勢線候選。重畫另建版本,不得移線抹去舊失敗。價格只在通道內上移不等於已突破,向上突破下降通道亦不自動證明新上升趨勢。
- **可重播狀態**:形態分候選、收市確認、回踩中、回踩守住、失敗／到期。突破看收市越過既有區界,回踩看之後觸及原區域及再次守住的價量;確認時間、觀察窗、容差與失效規則皆在形態版本保存。無回踩也是可能路徑,不得回看時假定一定給第二次入場;高量屬支持因素,不保證成功。
- **形態擴展**:三角收斂、旗形、雙頂／雙底等在首版價位及通道流程可用後按實際股票需要加入;每個形態須有可定位錨點、確認及失效條件。不追求辨識全部形態,不由外觀直接給勝率。形態量度目標如使用,另標「技術量度情境」,與途中阻力、L4 估值及持有期共同評估,不得當內在價值。
- **確認與時間口徑**:結構規則與參數寫入 `karst/ta/` 並版本化。若 swing 使用左右各 N 根,第 t 根的轉折最早於 t+N 根收市才確認;候選、確認、失效時間分開,不得在重播時倒填到 t 根當成已知。第一版可用 N=2 作候選轉折的實作預設,不是用戶投資偏好;同高／同低依明定容差聚為區域。月線未收月、週線未收週、日線未收市均不作該週期的已確認信號。
- **計算口徑**:200MA 預設為最近 200 個完整交易日收市價的算術平均;上／下只是位置,不是獨立買賣規則。支撐阻力、均線與圖表採同一公司行動調整口徑,記 `price_basis`、來源、交易時段、時區與 `bars_as_of`;執行價轉回實際報價口徑。ATR(14)記平滑算法;相對回報使用一致的回報／股息口徑。缺段先補抓或標影響,不把缺根當連續歷史。
- **SMC 選用**:BOS／CHoCH、掃過前高低、order block／FVG 只有能解釋某個關鍵區及計劃時才加。啟用前須有可重播的形成、確認、填補與失效規則;不用未定義名詞補判斷。SMC 是結構描述,不等於直接觀察機構意圖,也不宣稱因較新而優於一般價量分析。第一版不以全套 SMC 掃描作交付條件。
- **接線**:L5 影響進出場、剩餘回報與風險;異常價格反應可觸發 L1–L4 補查,本身不證明基本面改變。短週期轉弱是否推翻長期論點須另有證據。事件窗口約束判讀與覆核期限,不把支撐／均線的歷史回看長度限制為一季。
- **方法參考**:[CME 支撐與阻力](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)(前高低、均線與區域)、[Fidelity SMA](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/sma)(計算與趨勢位置)。形態參考 [CME 趨勢延續與反轉](https://www.cmegroup.com/education/courses/technical-analysis/trend-and-continuation-patterns)。這些來源支持方法定義,不是本系統有投資優勢的證明。

### L6 投資綜合

- **必答**:按研究委託的期限,現價的研究評級是什麼,為什麼?機會在哪裡、為什麼是現在?今天公允價值與期間目標如何連接?什麼條件才值得執行?風險回報如何?什麼推翻判斷,較上次改了什麼,資料缺口有何影響?
- **必用**:L1 至 L5 輸出、反方報告、清理後研究委託及原始依據;不讀私人或模型帳本。
- **輸出**:股票頁六行(第二節)、`research_rating`、`coverage_status`、`target_date`、條件式計劃(第三節)、`open_questions`、`next_check`、`changed_since_last`。評級正面／中性／負面與資料是否充分分開。
- **接線**:綜合不由「幾個角色同意」推算信心;採納了什麼、駁回了什麼、依據在哪裡要寫出;反方的最強一條必須正面回答。研究只按證據、現價與期限發布評級及執行條件;模型組合另用自己的帳本決定配置,不回流成本或盈虧。

### 反方(橫跨六層)

- 獨立上下文分兩步:先從原始證據列替代解釋與待查問題,再讀各層輸出逐項挑戰;不讀綜合。可以自行搜尋及補證,發現新來源先入庫;獨立進程不等於資訊與推理完全獨立。必攻:最脆弱假設、替代解釋(提前拉貨、低基期、一次性、口徑改變)、與論點衝突的證據、任何「不適用」的供給側答案、估值假設中無來源的倍數;准估值反駁。輸出 `strongest_counter`(一條)、`counters`(全部)、`unverifiable`(查不到的)。

## 三、投資計劃欄位

| 欄位 | 定義 |
|---|---|
| 持有期限 | 預計實現時間,與哪個催化劑或經營變化掛鈎 |
| 執行狀態 | 可執行／等價格／等確認／等資料／避開;附進入、增加曝險與退出這個論點的條件。模型實際買／持有／加減／退出另由組合層決定 |
| 入場方式 | 價格區域、確認條件、是否分段 |
| 失效與退出 | 技術失效位、基本面失效條件、到期未發展的處理;另記盤中或收市確認、下一可成交時點、跳空處理及是否跨業績持有 |
| 目標與減倉 | 各階段目標的依據(L4 情境價值、L5 阻力區分開標)、預計時間、減倉安排 |
| 風險尺度 | 研究報每股／百分比計劃內及壓力損益,不讀私人淨值或推建議股數。模型組合另按其委託、帳本及共同假設曝險定部位;1% 仍只示例 |
| 風險回報 | 單一多頭目標:(目標價 − 參考價)÷(參考價 − 計劃退出價),分母須為正且有可執行退出依據;條件式新計劃參考入場價,現價比較使用現價的剩餘 R&R;研究不使用實際或模型成本價。分批以各成交／退出路徑的總損益含成本與滑價計,不平均各腿比率;未進場條件不符時不假設已成交;另列業績跳空等壓力情境;不准用拉遠目標或收窄止損做出漂亮比率;目標可達性與所需時間要講 |
| 更新條件 | 哪些價格、公告、產業事件觸發重評;覆核到期日 |

內在價值、持有期目標價、技術阻力三者分開標,不混用。R&R 是條件賠率,不是期望回報;只有情境及機率有可說明依據時才另算期望值。資金停手線未設定不阻止行動建議,也不代表計劃內止損就是最大可能損失。

## 四、時間框架約束

每張論點寫期限;短週期技術轉弱可影響執行,是否推翻長期論點要另外論證;公司長期前景好不自動支持現價買入。同一公司可有多個基本面論點,各有期限、假設與失效;日線突破等是執行條件,不默默另開短線策略。研究評級预設六個月屬設計參數,每次發布固定目標日;長期公允價值与中期價格情境分開。

## 五、嵌入的既有能力

- ② 改善驅動可持續性判斷的問題結構嵌入 L3,不原封調用凍結考試提示詞 v1.1。該提示詞限定既有事件入口、禁止補查、共識一律查不到、收入單一評分與歷史污染自報,是考試條件;生產提示詞按本檔另版,允許補查與當前共識,按論點決定適用欄位。84 宗、其提示詞與原評分不改;歷史對照另記版本,不混稱同一方法績效。
- ① 暴露差異判斷(能力卡 v1)嵌入 L2「產業更新 → 逐家重評」。
- 論點卡與敘事衝擊檢查清單 v3 的步〇(行業共同情境卡)與步五(情境表)供 L2 與 L3 用;步六(現價對衝擊後價值)供 L4。

## 六、增量執行、發布與首批驗收

1. **分析版本**:每次記 `run_id`、研究委託／策略／角色提示詞／模型與計算版本、證據清單、所用產業／市場假設版本及各層讀取紀錄;不帶私人或模型帳本。初次分析涵蓋六層,無關項可有理由地簡答;不為湊篇幅全市場重讀。
2. **只重評受影響部分**:新文件／修訂／撤回先入庫,再按訂閱與證據依賴路由。價格日更新 L5、L4 現價折讓與反推要求、L6 計劃;不把所有資料日期改成今天。業績從 L3 起、產業／宏觀按訂閱與依賴、研究委託改變按影響路由;模型帳本更新只到配置層;假設到期或事件未發生也觸發,來源失敗與沒有更新分開。
3. **發布一致性**:確認所用卡、產業假設、來源與研究委託版本;分析中出現會改結論的更新則先重整合。只有完成驗證的發布版本進股票頁,原文與輸入快照可定位;未完成更新顯示具體待更新項,不把混合新舊結論叫完整更新。
4. **第一批驗收**:AXTI、TTD、BE、INTU、ORCL 共用流程各出股票頁,換股不改提示詞;具六行、估值依據、關鍵價位／200 日 SMA 圖表、日週月切換、適用的通道／突破回踩判讀與前瞻計劃。逐字稿及用戶報告可回讀原文;價格日沿用未變的逐字稿讀取紀錄,新逐字稿能觸發重評。未有新業績的公司也能分析,不要求通過②事件入口。
5. **實作前核對的反例**:未知日期文件不能倒填進歷史證據;收入延續而估值下修的情境不能被同一機率消除;尚未確認的 swing 不能提前觸發;1% 示例不能變成正式部位;研究不能讀取私人帳戶;模型組合可依已發布計劃作全部退出。這些是相應取證／估值／TA／計劃實作的驗收要求,本文件修訂不代表已運行程式。
