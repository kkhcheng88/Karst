## 一、現行權限(2026-09-12,主 agent 依外評第 3、5 題定)

**正式用途**:在共同敘事衝擊下,整理各公司的收入、成本與資本傳導路徑,指出可能的暴露差異、關鍵未知及可核查預測,供後續研究使用。**目前不據此單獨排名、淘汰候選、判定錯價或分配倉位。** v1 卡格六「縮小候選池或排序」與「否決器」的講法,自本日起**暫停**;下游看得到全部候選,本能力的輸出只作附註。

「研究輔助」本身未被證明有效;後續順帶記錄它有沒有節省核實時間、找出漏問、造成多少錯誤,不再開大型考試。

**結論措詞(可支持的)**:開發樣本內能力臂勝主要對照;兩輪歷史樣本外測未提供穩健的選股增量證據。**不寫**「股價答不出」「市場已反映」「讀得對」。

**經營結果核(KARST-218 第三部)的可支持表述**:開發樣本十一家被選公司,九家其後經營結果被評為與原判斷吻合、兩家部分吻合;**只核了被選者,未核「重大損害」組;吻合定義非事前寫明;共同恐懼未成真的宗,韌性分支未受檢驗**——故不足以估計一般判斷能力。

**刪去的一句**:v1 卡「本能力挑不出相對大市的便宜——這一條是能力的邊界,不是可以改進的參數」——相對大市回報不是便宜程度;目前無優勢不等於證明永遠不可能;保留功能邊界(不判便宜),不寫成不可證偽的結論。

## 三、對 v1 八格的已知偏差(不改 v1,前瞻方案另寫)

| 格 | 偏差 | 前瞻方案怎樣處理 |
|---|---|---|
| 一 | 「股價本身答不出」「跌幅完全分不開」被對照削弱 | 改成研究問題:價格反應是否已反映暴露差異 |
| 二 | 條件損害判斷與「現價是否反映」混寫 | 前者為核心;後者交交易吸引力層 |
| 三 | 文件截止於衝擊起日、價格用衝擊前,答不到衝擊後現價 | 分開衝擊時間、分析截止時間、可成交時間 |
| 四 | 禁止機械版本、證據須是文字,限制過強 | 允許數表與簡單對照;禁止的是偷換規則沿用舊成績 |
| 五 | 只選「有限」,排除「輕微或受益」——不是「損害愈小愈優先」 | 前瞻若改挑法標新版,不與 v1 混算 |
| 六 | 准縮池、排序、否決 | 暫停(本檔第一節) |
| 七 | 新聞點名籃子;事後低點進場;經營評分事後定 | 前瞻方案六項(另檔) |
| 八 | 事實、未完成工作、待驗證解釋混寫 | 本檔第二節分開 |
