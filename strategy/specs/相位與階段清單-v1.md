> 現行用途為[投資決策模型](../投資決策模型.md)的狀態輸入。v1 的討論清單在 git 保留;本版把篩選、入場及退出接到具體假設與條件,不把未驗證的換類規則當成自動買賣器。

## 一、股票是一組不同步的狀態

| 維度 | 描述的狀態 | 證據與典型更新 | 決策用途 |
|---|---|---|---|
| 市場與宏觀環境 | 需求、利率、信用、流動性與政策的方向及約束 | 公開宏觀數列、政策、融資條件;按發布更新 | 經公司敏感度改現金流、資本成本與壓力情境 |
| 行業資本週期 | 高回報吸引資本 → 擴張 → 競爭／整固 → 收縮與修復;不要求整行業同步 | 有效產能、利用率、資本開支、新進入者、定價與交付 | 篩選供需情境、檢查利潤可持續性;新增供給非全行業一票否決 |
| 公司生命期與經營階段 | 商業化、擴張、成熟、轉型;另記盈利／現金轉換改善或惡化 | 業績、逐字稿、單位經濟、份額、再投資與融資 | 決定應看哪些指標、估值法及驗證事件;虧損不直接剔除 |
| 替代／採用 S 曲線 | 試點、規模化、滲透加速、飽和;可停滯或倒退 | 出貨、付費採用、客戶回報、留存與替代成本 | 區分敘事熱度和商業兌現,定位價值捕獲者 |
| 預期修訂與定價 | 預期上修／下修／分歧;現價對未來要求寬鬆或苛刻 | 指引、同期間分析員預測版本、反向估值、情境範圍 | 評級、價格等待條件、剩餘回報;估值可改是否入場 |
| 敘事與共識擴散 | 辯論由可行性走向回報與成長上限;不保證單向擴散 | 逐字稿問題、研報與原始新聞;同源去重 | 判斷市場在爭什麼;大帳號點名或聲量不能單獨判頂 |
| 價格結構 | 築底、上升、盤整／可能轉弱、下跌;日週月各記 | 完成的 OHLCV、確認 pivot、200 日 SMA、RS、通道與價量 | 篩選某種入場情境,確認、失效、風險距離;不是基本面證明 |
| 資金與事件結構 | 指數／ETF 調整、被迫賣壓、解禁、融資、業績前後 | 公告、時間表、成交與可取得的公開持股 | 估流量、跳空和供需風險;機械買盤結束非自動賣出 |
| 論點健康 | 初建、支持、受挑戰、關鍵假設失效、到期待評 | 新證據對原假設與驗證條件 | 必要假設失效必改評級或計劃,不只貼標籤 |
| 營運狀態 | 待覆蓋、等資料、等價格、等確認、有有效計劃、撤回／到期 | 工作流與發布紀錄 | 管觀察名單與任務;模型持倉狀態另外存,不回流研究 |

舊四格(資本週期、價格階段、公司生命期、預期與定價)仍可作精簡面板;新增維度按重要性展開,不強迫每格選一個確定標籤。①②③④是可選的歷史描述,不代表一條必然生命週期。

## 二、怎樣用於 filter、entry、exit

- **篩選**:挑某種有因果理由的組合,例如經營改善、預期上修、週線上升中的日線回調。未符合不表示永久不值得研究。
- **入場／加倉**:相位提供機會背景;現價、獨立估值、下一事件、關鍵價位與剩餘 R&R 決定條件。可以等證據,也可以等價格。
- **減倉／退出**:檢查必要假設是否被推翻、回報是否已反映、風險是否改變及原定退出是否觸發。同一相位轉變對不同論點可以相反。
- **分歧**:例如需求加速但產能擴張更快,要說明何時影響價格與利潤;不用幾個相位投票決勝。價格強但現價要求過高,可以研究正面而計劃等價格,亦可因回報不足下調評級。

例:瓶頸環節的擴產公告先改「未來有效供給」假設;長建設期與客戶需求可能令一年內利潤仍受支持。必須拆日期、暴露與情境,不能看到「資本流入」即一律離場。

## 三、狀態與時間資料契約

每項記 phase_id、entity_id／security_id、dimension、timeframe、state、previous_state、status(候選／確認／未知)、effective_period、observed_at、confirmed_at、evidence_refs、rule_or_method_version、decision_implication、next_review_at。

- 狀態未知、來源未更新、取數失敗與證據相互矛盾分開。
- 確認 pivot 的可用日是右側 N 根已完成後的 confirmed_at,不能回填成轉折當日已知。未收週／月 bar 的狀態是暫定。
- 價格日主要更新 L5,並重算 L4 現價隱含要求／回報及 L6 計劃;不自動改營運事實。
- 新業績更新公司階段與預期,必要時追到產業假設;新產業報告按成員、訂閱與依賴查影響,不把各公司當同樣暴露。
- 定期到期檢查補事件遺漏;異常價格可以發起補查,但不能單憑價格生成確定的因果故事。
- 同一論點的新版本保留舊狀態與當時可見來源;回顧只能按原來 confirmed_at 與發布時間計分。
