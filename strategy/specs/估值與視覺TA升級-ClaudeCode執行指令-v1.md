## 1. V：估值能力，優先交付

沿用 calculations、service.calculate、收件及發布，做方法分派而非新引擎。

**V1 最小實作**
- 新契約版本支援有 method 判別的輸入／結果；保留 0.2／0.3 舊發布讀取，不偷換舊 fcff_dcf 意義。版本號按當時倉規由本地定，schema、驗證、保存、MCP、發布同步。
- 首批：日期化多階段 FCFF DCF、前瞻 P/E、EV/EBIT 或 EV/EBITDA（完整股權橋接）；SOTP 先組合可用方法。金融／NAV／FCFE 按覆蓋加入，不讓全方法庫阻塞首版。
- 估值日、現金流期間／付款日期、期中／期末、幣別及金額／股數尺度明確。拆出剩餘 stub，過去現金流不算未來；擴張末期 FCFF 與首個正常化終值 FCFF 分開。
- 經營 driver 有期間、單位與來源：量價／客戶或收入→利潤→現金稅→capex／折舊／營運資金→FCFF／盈利；選適用驅動，不建所有行業必填巨大表。
- 現金、負債、非營運資產、少數股東、贖回權、可轉債／認股權及股數保持同一範圍；SBC 不漏也不雙扣；複雜權益未支持明列缺口，不以單季淨利比例代全部未來權益。
- 主模型、替代、敏感度及反推共用計算器並保留輸入／輸出／版本回執；反推列固定假設、求解變數、邊界及無解／多解情況。
- 研究能保存主模型與替代視角、選法及分歧。驅動先引用 evidence_id／locator，有 claim 版本時才接，不等 G 完成。
- 頁面分內在值、期限價格、TA 目標，可展開計算依據；能力不足只限制相應數字，不抹掉有依據的經營判斷。
- API adapter 加可調用的計算工具，重用 service.calculate 或同一領域函式的任務 facade；不寫第二份算式。

## 2. T：真正看圖，可與 V 分開實作

**T1 繪圖及衍生數字**
- 改現有 charts._draw 為 OHLC 蠟燭＋成交量＋歷史 200 日 SMA 曲線。50MA／20EMA 按實際用途加，最新 SMA 水平線不可冒充歷史。
- 月／週背景、日線全貌、近期日線放大；均線由完整歷史先計再裁窗。週月若映射日 MA，圖例明標 200 日，不變成 200 週／月。
- 日期／價格軸、線性或對數座標、來源、價格基準、截止、未完整 bar 顯示清晰。近期圖足以看 K 棒及影線，避免全歷史擠成一條線。
- 支撐阻力為具錨點區域；pivot 形成與確認時點分開；通道保存錨點、容差及版本。候選與已確認分清，先映射 reading／phases，需要專用欄位才隨契約升級；不先建全套 SMC。
- derived 保留相同來源的精確 MA／距離、MA200 對前20交易日方向、重要 pivot、可用量比；ATR／相對強弱按紀律及資料可得性提供，算法、參數及期間明列。
- 永久保存圖像、必要衍生物、來源版本／參數／hash，沿現有按需行情政策，不另造第二個行情庫。未存完整陣列時，承諾的是當時所見圖像可取回，不宣稱供應商修改歷史後仍能完全重算。

**T2 圖像送入模型**
- render_charts 回 artifact 清單；服務端本機路徑只作內部定位。
- MCP 加按該版本 chart/artifact ID 讀圖，回 ImageContent 或兩端真能讀的已驗證 resource；文字 URL／內網路徑不算。沿用 OAuth 與研究範圍，不提供任意檔案讀取。
- OpenAI／Anthropic adapter 各用真正 image input／tool-result content，重用同一圖檔；另可讀 derived JSON。工具表／context 誠實反映能力。
- 交互式 Claude Code 用本地圖像工具，ChatGPT 用 MCP 圖像讀口，API worker 用 image block。記送入的圖像身份／版本及週期範圍，不能以目錄有 PNG 推定看過。
- 現行 schema 先在 reading.text 記實讀圖，正式 receipt／圖像欄位隨契約升級。失敗／無 vision 只限制相應視覺判斷，繼續數字可支持的部分。

**T3 驗收**
1. 有非水平 SMA、長影線及跳空的參數化數列，人工／模型檢視圖與原始數值一致，不只測檔案存在。
2. 假突破、週線趨勢中的日線回調、未收週／月棒：模型列錨點、觸發與失效，可說無法判斷，不從外觀捏勝率。
3. GPT／Claude 實際讀同版本圖片；API payload 真有 image content，只有檔名不得通過。
4. 形成首選 setup→觸發→取消／失效→目標／不做；數字核 R&R，不預設 1H、TP1 平半倉、固定R或風險預算。
5. 換 security／as_of 不改程式，BE／AXTI／INTU 只作配置或 fixture。
