# 能力卡——改善驅動可持續性判斷 v0(草稿,待用戶與外評;主 agent 親寫,D-175)

> 交付品 D06(②趨勢注)· 2026-09-12 · 版本 **v0 草稿,未凍結、未測**。八格格式照第八輪外評第二節;②研究問題照②第一輪外評修改一;能力定義照其修改三。與 `能力卡——暴露差異判斷-v1.md` 同形:都是把一個市場已見的價格現象,拆到公司經濟層面分真假。
>
> **本卡不是買賣規則。** 它答「這家公司已出現的改善,由什麼推動、哪一截能在持有期內延續」;買不買由交易吸引力層與進出場層另答。

---

## 〇、一頁看懂

| | |
|---|---|
| **一句話** | 一家公司的盈利或現金流已經改善、股價已經強勢:把改善拆成幾條驅動,逐條判「持有期內延不延續」,分開真延續與低基期、一次性、短期供需擠壓。 |
| **它做什麼** | 對已入觀察名單的強勢公司,交付一張「驅動 × 持續性」表,加一條必答的供給側問題,加「什麼會令上調停止」。 |
| **它不做什麼** | 不判買入;不判價格已反映多少(那是「預期及定價狀態」格與交易吸引力層);不預測業績日反應。 |
| **目前證據** | **無。** 未在任何樣本上考過。第一次考試設計見格七。 |
| **主要風險** | 改善的驅動在申報裡常只露一半(價量拆分、分部利潤、訂單)——查不到時要標,不准補;模型知結局的污染與①同。 |

## 一、八格

### 格一 適用情境

- **啟用條件**(任一入口觸發後):
  - **入口甲,新資訊後重估**:公開經營資料改善(業績、指引、訂單、單價、留存之一或多項),而價格作出強勢反應(相對大市與同業,以事件窗口報酬量);不限於業績日。
  - **入口乙,既有改善的延續**:原有經營論點仍成立(本卡上一版判斷未失效),價格整理後再出現預先定義的延續訊號(訊號規格由進出場層定,本卡只接收「已觸發」)。
- **與相位面板的關係**:本卡在「公司生命期」與「行業資本週期」兩格填值;「預期及定價狀態」格由交易吸引力層填;「價格階段與相對強度」格由掃描層填。
- **可重疊情境標籤**(不互斥,可同時貼):快速增長型、景氣循環型、樽頸型。標籤只決定要多問哪幾條(見格四),不決定買賣方向。
- **什麼時候不用**:改善只在股價、沒有任何經營資料改善(那是純價格動能,另立交易假說);公司屬財務困境型。

### 格二 具體問題

> **這家公司已出現的改善,由哪幾條驅動推動?每一條在預定持有期(數週至數季)內延續的機會有多大、憑什麼?什麼會令上調停止?**

三句要逐家答清:
1. 改善是價、量、組合、成本、一次性、還是低基期?各佔多少?
2. 每一條驅動的「延續條件」是什麼、衝擊前證據支持嗎、什麼日期可核?
3. **供給側必問**(不作規則,作必答):在持有期及其後市場定價的期間,有效供給會不會追上需求,削弱定價或利潤?

### 格三 必要資料

| 類 | 要拿什麼 | 主要文件 |
|---|---|---|
| 改善的拆分 | 分部收入、價量拆分(單價 × 銷量)、產品組合、毛利率與營業利潤率變化、一次性項目、上年同期基數 | 10-Q/10-K 分部附註與 MD&A、業績稿 8-K EX-99.1、電話會逐字稿 |
| 需求側 | 訂單、積壓(RPO/backlog)、留存、客戶數與每客收入、指引與指引修訂史(同一財年口徑) | 業績稿、逐字稿、8-K 指引 |
| 供給側 | 本公司與主要對手的資本開支、在建工程、擴產與新進入者公告;投產、認證、良率、交付時間;產能利用率、交期、庫存、售價 | 10-K 資本開支節、對手公告、行業報告(標來源等級) |
| 成本結構 | 變動與固定比例、經營槓桿、原料與人工價格 | 10-K 成本構成、MD&A |
| 公司生命期 | 收入規模、增速趨勢、市場滲透率、擴張是否已進入新市場或只在複製 | 10-K「Business」、分部地區拆分 |
| 市場共識(參考) | 分析員收入/盈利預期與修訂(同財年、分收入與盈利與每股、覆蓋人數、更新日;「沒更新」與「看完維持」分開)——**證據之一,不作分類開關** | 賣方摘要;取不到即標 |
| 價格狀態(由掃描層供) | 母體內指定回看期回報排名(非 RSI)、事件窗口報酬、相對同業 | 價格庫 |

四標籤(已核/推算/判斷/查不到)照清單 v3 第五節;空白不是標籤。

### 格四 分析要求

1. **驅動拆分表**(必填):每行一條驅動——類型(價/量/組合/成本/一次性/低基期)、佔改善的比例(區間)、證據與出處、**持續性判斷(高/中/低)附理由**、延續條件與可核日期。
2. **供給側一問**(必答,不作規則):有效供給何時可能追上;用三組警示資料(投資、生效時間、市場結果)答;資本開支對折舊只作投資強度代理,不設跨行業門檻。
3. **標籤加問**:
   - 快速增長型:增長來自滲透、份額、價格還是收購?需要多少再投資?處於 Lynch 三階段哪一段?
   - 景氣循環型:現在盈利處於週期哪一段?低市盈率是否因為盈利在頂?產能利用率與售價的方向?
   - 樽頸型:客戶是否必經此環?稀缺能否轉成價量利潤?利益會否被合約、競爭、成本拿走?樽頸何時因擴產、替代、技術改變而消失?
4. **什麼會令上調停止**:列出一至三件可觀察事件(對手投產、客戶庫存見頂、指引口徑改變、基數效應消失),各附日期。
5. **證偽三條**(照清單 v3 步七):帶門檻數、實際日期、核的文件、後果三選一;點名必要前提。
6. **反對票**:由另一進程寫,只給取證包;熊方必攻「改善是否只是低基期或供需擠壓」與「供給側何時追上」。
7. **不寫**「市場對/市場錯」、不給買賣判詞、不填價格已反映多少(交給交易吸引力層)。

### 格五 輸出

- 人讀版 `卡-<代號>-<日期>.md`:驅動拆分表、供給側答案、標籤加問、上調停止清單、證偽三條、熊方。
- 機械版 `判-②.csv` 欄(草案):`ticker, entry_type(甲/乙), signal_date, driver_1..n(type, share_lo, share_hi, persistence), supply_catchup(高/中/低/查不到), lifecycle_stage, capital_cycle_phase, stop_revision_event_1..3(date), premise, bear_hits`。

### 格六 決策用途

- **排序與升級**:持續性判「高」且供給側判「不會在持有期內追上」者,升到交易吸引力層;判「低」或供給側「會追上」者降回觀察名單;「查不到」照標。
- **不直接判定買入**;交易吸引力層必須容許「候選很好但這次不值得下注」。
- 多家共同依賴同一個需求或資本開支假設時,視為同一注。

### 格七 驗證對照(第一次考試的設計,未跑)

- **先核經營結果,後核交易效果**(第八輪外評)。
- 樣本:由入口甲取——歷史上「業績或指引改善 + 事件窗口強勢反應」的公司(可由價格庫與申報日機械找出),每宗判斷只用訊號日前文件;結果對照其後二至四季的經營結果(改善延續了沒有)與十二個月相對大市與相對同業超額。
- **簡單對照臂**(同一候選池、同一訊號日、同數家):(b) 最近兩季增速加速最快者;(c) 事件窗口反應最強者;(d) 母體內回看期回報排名最高者;有共識資料時加 (e) 修訂廣度最高者。
- **兩種入口各自比**:「純價格規則」對「加本卡判斷」,同一候選、同一可成交日、同一等待期限、同一退出。
- 污染聲明照①。

### 格八 證據狀態

**無。** 本卡為 v0 草稿;②材料中沒有任何一條是本能力的基準率(②對帳單第七節:全部是 P(特徵|大贏家))。第一次考試後才有第一行。
