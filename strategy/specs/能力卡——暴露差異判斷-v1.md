## 一、八格

### 格一 適用情境

- **什麼時候啟用**:一個敘事衝擊**同時打到多家公司**,而這些公司**傳導路徑可能不同**。
- **必要條件(全部要中)**:
  1. 有一個**共同敘事**(一個事件、一個恐懼),不是幾家公司各自的壞消息;
  2. 受影響的公司在同一個**籃子**裡(共同經濟暴露 + 同一段事件窗口;價格共同波動只作交叉檢查,不作界定);
  3. 衝擊當日**結果未知** —— 這正是這個能力存在的理由:股價本身答不出哪家傷得輕(跌幅完全分不開贏輸,方向若有是反的)。
- **什麼時候不要用**:
  - 只有一家公司被這件事打(沒有「籃內排序」可言);
  - 市場的恐懼**不是**來自一個共同事件(那是個股問題,入①個股觸發或②);
  - 事件屬**財務困境型**(一注成立主要依賴避免擠提、緊急融資或外部救助)——本線一律排除(清單 v3 步二「財務型的邊界」)。
- **與四類注的關係**:本能力的形狀就是①B(行業殺錯/敘事重估)的核心;②的「上升趨勢中回調」可用同一個比較動作,但入口與判詞方向不同。

### 格二 具體問題

> **在共同情境成立的前提下,哪家公司的經濟損害較小?它憑什麼受損較小?**

收窄後的問法(第八輪外評第二節的表,逐字):

> 在共同情境成立時,哪家公司的經濟損害較小?

三句要逐家答清(清單 v3 第六節 ①B 的優勢假說):

1. 如果市場的恐懼正確,**哪一家應該先在什麼指標上受損**?
2. **哪一家有明確理由受損較少**?
3. 兩者現價**是否已反映**這個差別?

**「受損較小」不是「跌得較少」。** 跌幅是背景,不是判準(清單 v3 步六硬規矩第 1 條)。

### 格三 必要資料

按**公司對照**,每宗事件逐家取。**硬界線 = 該宗衝擊起日**;界線之後的文件一律不得引用。

| 類 | 要拿什麼 | 主要文件 |
|---|---|---|
| **收費方式** | 按席位/用量/交易/訂閱/一次性?單價與量的關係 | 10-K 收入確認附註、產品定價頁(公開牌價) |
| **客群** | 集中度、是否正好是受衝擊那一批、議價能力 | 10-K「Business」與「Risk Factors」重大客戶披露(逾一成須披露) |
| **合約** | 何時可取消/減量/重新定價、到期後怎樣、RPO 履約時間分布 | 10-K「Business — Customers/Contracts」、遞延收入與 RPO 附註 |
| **成本與相關分部** | 受影響那一段佔收入/毛利/營業利潤多少、變動與固定成本比例 | 10-K 分部附註、成本構成、營業槓桿說明 |
| **收入單位本身的資料** | 席位數、用量、存戶、交易費、每用戶收入、新客/舊客分開 | 收入確認附註、遞延收入滾動、業績稿的淨新增指標(10-Q/8-K EX-99.1) |
| **價格與成本** | 有沒有讓價、能否轉嫁、替代品總成本與遷移時間 | 業績電話會問答、10-K「Competition」節 |
| **市場共識(參考)** | 分析員收入/盈利增速(家數、最後更新日)、公司指引、敘事在賣方與電話會出現密度 | 逐字稿、賣方報告標題、8-K 指引 |
| **價格與估值輸入** | 衝擊日前一交易日收市價、事前一年自身倍數區間或同業中位倍數 | 價格庫;`strategy/tools/implied_expectations.py` 口徑 |

**資料等級**:每格自報 `已核` / `推算` / `判斷` / `查不到` 四標籤之一(清單 v3 第五節)。**空白不是標籤**;`查不到` 要寫夠「找過哪裡、為什麼那裡應該有、若它其實是壞的哪一格作廢」。

### 格四 分析要求

逐家要走完清單 v3 步〇至步五 + 步七證偽與時限(**提示詞 v1 就是這一格的落地**):

1. **步〇 行業共同情境卡(一宗一張,全籃共用)**:市場擔心的結果一句(主體/機制/後果/時間四樣齊);必要條件逐條附衝擊前出處;程度與時間(寫區間);支持與反對證據**各列出處**;四類檢查(數量關係、部署速度、經濟誘因、已發生的行動);**可信程度三檔(高/中/低)附理由,禁止寫概率數字**。**禁止逐家改寫恐懼。**
2. **步一 本公司主要受損路徑清單**:至少逐條問過——功能被繞過或取代、收費被壓、席位或用量減少、新客流入減少、重新議價;適用者列出、不適用者寫明為何不適用。**禁止把共同恐懼收窄成本公司容易避開的單一路徑。**
3. **步二 傳導鏈與機制歸類**:每條主要路徑走一次五環「衝擊 → 客戶/競爭者行為 → 價格數量成本 → 現金流 → 持續時間」;歸類(護城河型/經濟學型/財務型)決定後面查什麼。
4. **步三 暴露盤點**:被打中的是收入/成本/資本哪一段、佔多少(報**區間**,下限=明文披露那一段、上限=連相鄰可能受影響的段)、該段毛利率與利潤貢獻、變動與固定成本比例、有沒有打中資本開支與再融資。**這一節只是盤點,不是判詞。**
5. **步四 衝擊前證據(按機制選用,八條)**:客戶集中度、合約條款、收入重複發生的原因、定價方式、可替代性、管理層應對(宣布/落實/已有經濟結果三檔)、競爭反應與利益歸屬、新客流入對比舊客續約。**每一條要指得回一段文字,不是一個數。**
6. **步五 各情境下的公司損害(情境表)**:三行(恐懼大致成真/部分成真/大致不成立)× 四欄(成立所需條件/公司損害及時間/價量成本與現金流變化/關鍵證據支持或反對);每行附時間、區間、證據信心;**最低交付三項**(價量成本各自變動範圍、何時開始維持多久能否恢復、最大未知)。
7. **步六 估值降格為一問(提示,不作判詞)**:只答「**在一組有證據支持、彼此一致的假設下,現價是否仍要求明顯過好的經營結果?**」**不給買賣判詞、不設價格閘**。
8. **步七 證偽與時限**:至少三條「可證偽預測 + 門檻數 + 核的日期 + 核的文件 + 後果三選一(觸發覆核/論點失效/資料不足)」,三條來源要分開;**點名哪一條是必要前提**(倒即整卡失效);觀察日期寫實際日期,不寫「下季」。
9. **步八 獨立熊方**:規約保留 —— 熊方由**另一個工人進程**寫(新 context,只給該卡步〇至七的取證包:事實、數字、出處,不給判詞、不給情境判斷、不給填卡者的熊方);同一進程自寫的熊方只算「**代替品**」,卡上必須標明性質。

**明確不能規則化的一步**:步〇、步二、步四、步五、步八**不設機械版本**,不准日後偷偷加一條比率代替(清單 v3 第三節 3.4)。

### 格六 決策用途

- **縮小候選池或排序**;**不直接判定買入**(第八輪外評第二節的表,逐字:「縮小候選池或排序;不直接判定買入」)。
- 它答「如果考慮這個受衝擊的行業,哪些公司可能較值得選」,**不答**「這個行業現在是否比指數、其他候選或暫不交易更值得投入」(第八輪外評第四節)。後者是**交易吸引力層**,必須容許「候選很好,但這次不值得下注」。
- 落注另需獨立買入理由 —— 「清單定位為否決器/篩選器,落注另需獨立買入理由(待用戶裁)」(地圖 ①B 暫定)。
- **共用注碼**:多家公司共同依賴同一個行業判斷時,**視為同一注**(清單 v3 格八、步七第五問、第六節三處同一件事)。買五家高暴露公司可能只是放大同一注。

### 格七 驗證對照

任何一次套用,都要在同一事件、同一候選池、同一進場日、同一家數之下,並列**三個簡單篩選**(挑法先寫死,跑完不改):

| 臂 | 挑法 |
|---|---|
| **(a) 本能力** | `dmg_true == "有限"` 那幾家 |
| **(b) 跌得最少** | 衝擊窗相對跌幅最小的 k 家 |
| **(c) 財務簡篩** | 衝擊前滾動四季經營現金流為正,且最近八季營收變異係數最低的 k 家 |
| **(d) 低波動** | 衝擊前 252 個交易日日回報標準差最低的 k 家 |

- **k** = (a) 在該宗挑了 k 家;k = 0 則四臂一齊記空,**不補位**。
- **候選池** = 該宗「新聞點名」籃子(亦是「籃子中位」的分母)。
- **進場** = 衝擊低點(T 錨)之後下一個交易日收市,四臂相同。
- **成績口徑**:相對籃子 = 十二個月相對大市超額 − 該宗籃子中位;相對大市超額 = 個股 ÷ SPY − 1。**全部是相對數。**
- 另要對**後續經營結果**:收入、定價、留存是否真的未受傷(用衝擊後四季 10-Q/10-K 與業績稿核)。
- **對照的判讀三條**(第八輪外評第二節的「驗證對照」欄原意):(1) 若兩臂挑到大量重疊,**優勢可能就是同一件事**;(2) 兩臂各自有效也可能只是**互相代替**;(3) 每一個對照都要**同一時點的簡單篩選**,不是事後挑一個跑得最差的來比。

### 格八 證據狀態

**照實寫,不准寫高(第八輪外評第一節「只是名稱應暫定為『有初步歷史支持的能力』」)。**

| 項 | 狀態 |
|---|---|

| 對三個簡單篩選 | 清單 (a) **+15.5%** 對 (b) 跌得最少 **+3.7%**、**(c) 財務簡篩 −32.4%**、**(d) 低波動 −2.7%**。三臂之中只有 (a) 相對大市超額為正。 |
| 逐宗剔走 | 剔走任何一宗仍 +14% 以上;三個簡單規則剔走任何一宗都仍不過 +5% 或為負。 |

| **未核 2** | **股價結果只支持選擇效果**(第八輪外評第一節第二個界限)。若要稱為「準確判斷收入不會受傷」,**仍需核後續收入、定價或留存等經營結果** —— 見本票第三部(十一家經營結果核)。 |
| **污染** | 做判斷的模型**知道結局**;挑家可能受結局影響;樣本是十四宗歷史事件、每宗四至五家,**不是隨機樣本**;數字只作方法診斷,不作成績宣稱。 |
| **樣本外測的界限** | 任何新事件測試是**樣本外於「規則修改」,但不是樣本外於「模型記憶」** —— 模型在訓練時可能已見過該事件的結局。此句必須在每次測試的落檔明寫。 |
