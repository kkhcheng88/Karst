## 〇、一頁看懂

| | |
|---|---|
| **一句話** | 一家公司公開經營資料已改善、股價已強勢反應:把改善拆成幾條驅動,逐條判其後兩季(主)與四季(次)延不延續,寫出可評分的未來指標與範圍、失效條件與最大未知。 |
| **兩句假說(分開)** | **能力假說**:模型能否比簡單方法(公司當時指引、事前固定的趨勢延續預測)更準確判斷經營改善是否延續兩至四季。**投資假說**:這項更準確的判斷能否在訊號後的價格上產生額外回報。第一句成立不保證第二句;第一次考試只考第一句,第二句只作描述。 |
| **它做什麼** | 對入口甲觸發的公司事件,交付「驅動 × 持續性」表、未來指標點值與範圍(兩季、四季)、供給側答案、上調停止事件、證偽三條、最大未知、獨立熊方。 |
| **它不做什麼** | 不判買入;不判價格已反映多少;不預測業績日反應;不稱「業績意外」(倉內無歷史共識資料)。 |
| **「延續」的意思** | 改善維持在接近訊號季的水平,**不是每季繼續加速**;收入增速由 30% 回落至 25% 仍可算延續(門檻在執行口徑寫死:其後兩季平均按年增速 ≥ 訊號季的八成,且無指引下修)。 |
| **目前證據** | **無。** 未在任何樣本上考過。第一次考試設計見格七與執行口徑 v1。 |
| **主要風險** | 「指引上調加收入加速」這條簡單規則可能已捕捉全部資訊,判斷層無事可做;驅動在申報裡常只露一半,查不到時要標,不准補;模型知結局的污染與①同。 |

## 一、八格

### 格一 適用情境

- **啟用條件,入口甲「公開改善加強勢價格反應」**(舊名「新資訊後重估」):公開經營資料改善(業績、指引、訂單、單價、留存之一或多項)**且**反應日(公布後第一個完整交易日)價格相對大市達當年母體前十分位、相對同業為正。機械規格與預設值見執行口徑 v1 第二節。
- **入口乙「既有改善的延續」**:本卡上一版判斷未失效,價格整理後出現預先定義的延續訊號。**第一版不測,規格未定。**
- **三個時間點**(②第二輪外評):**T0** 公布時間;**T1 分析截止** = 反應日收市,判斷在此鎖定,**截止前已公開的一切可用,包括觸發本次訊號的業績稿、指引與已公開的電話會內容**;**T2 可成交** = 次一交易日開市。不得一面用反應日的資訊、一面假設在較早價格成交。
- **與相位面板的關係**:本卡填「公司生命期」與「行業資本週期」兩格;「預期及定價狀態」由交易吸引力層填;「價格階段與相對強度」由掃描層填。
- **可重疊情境標籤**:快速增長型、景氣循環型、樽頸型;只決定多問哪幾條。
- **什麼時候不用**:只有股價改善、沒有經營資料改善(純價格動能,另立假說);財務困境型(最近年報或季報有持續經營疑慮);同日有併購公告主導反應。

### 格二 具體問題

> **這家公司已出現的改善由哪幾條驅動推動?每一條在其後兩季(主要期限)與四季(次要期限)延續的機會有多大、憑什麼?什麼會令上調停止?哪一項是最大未知?**

五項必答(②第二輪外評第 3 題):
1. **驅動**:改善是價、量、組合、成本、一次性、還是低基期?各佔多少(區間)?
2. **未來指標及範圍**:其後兩季平均按年收入增速的點值與八成信賴區間;四季同。指標固定為收入增速,不由模型自選。
3. **主要與次要期限**:兩季為主、四季為次,事前固定,不得事後挑較好的。
4. **失效條件**:什麼結果會推翻判斷(帶門檻與日期)。
5. **最大未知**:分開「持續性低」與「無法判斷」。
6. **供給側**(必答欄):在其後四季內有效供給會不會追上需求,削弱定價或利潤?受產能影響的行業必須分析;其他行業准答「不適用 + 理由」,熊方必攻任何「不適用」。

### 格三 必要資料

| 類 | 要拿什麼 | 主要文件(截止 T1) |
|---|---|---|
| 觸發資料 | 那份業績稿(8-K EX-99.1)、指引段落、同日 8-K 其他項目、已公開的電話會逐字稿(有則入,無則標查不到) | 8-K |
| 改善的拆分 | 分部收入、價量拆分、產品組合、毛利率與營業利潤率、一次性項目、上年同期基數 | 最近 10-K、最近兩份 10-Q 的分部附註與 MD&A |
| 需求側 | 訂單、積壓、留存、客戶數、指引與指引修訂史(同財年口徑) | 業績稿、逐字稿、8-K |
| 供給側 | 本公司與主要對手的資本開支、在建工程、擴產與新進入者公告;投產、認證、良率、交付;利用率、交期、庫存、售價 | 10-K 資本開支節、同業最近年報、行業報告(標來源等級) |
| 成本結構 | 變動與固定比例、經營槓桿、原料與人工 | 10-K 成本構成、MD&A |
| 公司生命期 | 收入規模、增速趨勢、滲透率、擴張是否進入新市場 | 10-K「Business」、分部地區拆分 |
| 市場共識 | 倉內無歷史共識;一律標「查不到」,不由模型憑記憶補 | — |
| 價格狀態(掃描層供) | 母體內六個月與十二個月回報排名、反應日報酬(相對大市、相對同業)、距 52 週高 | 價格庫 |

四標籤(已核/推算/判斷/查不到)照清單 v3 第五節;空白不是標籤。**T1 之後的價格、經營結果、任何後續公告整欄不入包;出現即整批作廢。**

### 格四 分析要求

1. **驅動拆分表**(必填):每行一條驅動——類型(價/量/組合/成本/一次性/低基期)、佔改善比例(區間)、證據與出處、持續性(高/中/低/無法判斷)附理由、延續條件與可核日期。
2. **未來指標**:其後兩季平均按年收入增速的點值與區間;四季同;附推導(哪條驅動貢獻多少)。
3. **供給側一欄**(必答;准「不適用 + 理由」):用三組警示資料(投資、生效時間、市場結果)答;資本開支對折舊只作投資強度代理,不設跨行業門檻。
4. **標籤加問**:快速增長型(來源、再投資、Lynch 三階段);景氣循環型(週期位置、低市盈率是否盈利在頂、利用率與售價方向);樽頸型(必經、稀缺轉價量利潤、利益被拿走、樽頸何時消失)。
5. **什麼會令上調停止**:一至三件可觀察事件,各附日期。
6. **證偽三條**(照清單 v3 步七):帶門檻、實際日期、核的文件、後果三選一;點名必要前提。
7. **最大未知**一句;「判不出的事」清單。
8. **獨立熊方**:另一進程,只給取證包;必攻「改善是否只是低基期或供需擠壓」「供給何時追上」「任何『不適用』」;准估值反駁。
9. **不寫**「市場對/市場錯」、不給買賣判詞、不填價格已反映多少。
10. **不禁止機械對照**(①第九輪外評):若簡單規則日後做到相同工作,照記;禁的是偷換規則沿用舊成績。

### 格五 輸出

- 人讀版 `卡-<代號>-<訊號日>.md`。
- 機械版 `判-②.csv` 一行:`event_id, ticker, cik, signal_date, improvement_text, n_drivers, top_driver_type, top_driver_share_lo, top_driver_share_hi, persistence_overall(高/中/低/無法判斷), pred_g2_point, pred_g2_lo, pred_g2_hi, pred_g4_point, pred_g4_lo, pred_g4_hi, supply_catchup(會/不會/不適用/查不到), supply_timing, tags, lifecycle_stage, stop_event_1_date, stop_event_2_date, premise, falsify_1, biggest_unknown, unknowns_count, contamination_note`。
- **評分只讀機械版與其後財報**,不讀人讀版(②第二輪外評第 4 點)。

### 格六 決策用途

- **未驗證前不授予任何篩選權限**(①的教訓):第一次考試期間本卡輸出不進任何交易流程。
- 考試若顯示能力假說成立,候選用途為「排序與升級」:持續性高且供給側不會在四季內追上者升到交易吸引力層;判低或會追上者降回觀察名單;「無法判斷」照標。下游仍看得到全部候選,不否決。
- 多家共同依賴同一需求或資本開支假設時視為同一注。

### 格七 驗證對照(第一次考試,設計凍結於執行口徑 v1)

- **先核經營結果,後看交易效果**;經營考試的主要對照是**公司當時指引所隱含的增速**與**事前固定的趨勢延續預測**;價格排名(反應最強、加速最快、相對強度最高、指引上調且加速)只作選股對照。
- 抽樣單位為**公司—事件**;固定入口建全母體(2015-01 至 2025-06),分年、分行業分層隨機,種子與清單事前鎖定,保留公司重複與同業同期識別欄;2020 年三至六月保留並標記分開報。
- 評分規則事前寫死(指標、期限、容許區間、未披露/收購/退市處理);評分者只看鎖定的機械版與其後財報;保留預測誤差與全池分佈;不強切高低組。
- 鎖定模型版本、提示詞 v1、取證包規格、每事件一次執行;第一場評分前不改提示詞。
- 對「否定」決定性:判斷層若贏不了公司指引與趨勢延續預測,本能力在入口甲不再投入;對「肯定」只是第一個觀察。
- 污染聲明照①。

### 格八 證據狀態

**無。** ②材料中沒有任何一條是本能力的基準率(②對帳單第七節全部是 P(特徵|大贏家))。第一次考試後在 `...-v1-證據與權限紀錄.md` 記第一行。
