# 投資委託(v1,2026-09-14;KARST-239)

> 工作台每個分析角色開工前讀這一頁。它答四件事:這位投資者要什麼、能承受什麼、手上有什麼、按什麼原則買賣。每格註明出處;暫定參數明標「暫定」,由用戶一句話改。改本檔即改所有角色的前提,要記版本。

## 一、目的與期限

| 項 | 內容 | 出處 |
|---|---|---|
| 目的 | 以基本面與敘事為核心,選擇值得承擔的風險,取得跑贏大市的回報;不追求平滑曲線,最大化長期總盈利,但由複合增長率與停手線約束 | D-166;原則十與主 agent 評估(principles §二) |
| 不做的事 | 即日交易、剝頭皮;純資金推動的狂熱股(GME/AMC 類)整條線不做 | D-166;D-147 |
| 持有期 | 數週至數季;用戶偏好一個月至一年;每張論點各有自己的期限,不共用 | D-166;D-169 出處欄(用戶原話「my perference is actually on 1 month to 1 year」) |
| 技術分析的位置 | 只在關鍵事件披露之間讀價格行為,最長一個業績週期;用於進出場與風險回報,不作長期訊號 | D-166;framework §二 信念二 |
| 回報目標 | 不作把關;每條策略報四數(複合年化、最大跌幅、命中率、優勢來源),由用戶按四數揀 | D-148;D-149 |

## 二、偏好與風險

| 項 | 內容 | 出處 |
|---|---|---|
| 機會類型 | 四類注,風險回報遞增:①錯殺注(基本面強、被拋棄,10–20%)②趨勢注(基本面好、敘事已知、已高但仍上調)③熱敘事注(敘事已知、基本面差、已高)④未共識敘事注(我們認為敘事好、市場爭論中、基本面差、未高,500–1000%+);四類都在範圍,每張論點標類別 | D-166;framework §二 |
| 分散方式 | 跨注分散、注內集中(相信一個敘事押一兩隻,不押五至十隻) | framework §二 |
| 每注風險預算 | **暫定:單一論點最大損失佔組合 1%**(入場價到失效價的距離乘部位);用戶未定;注碼三數(單筆損失預算、單股上限、同一故事共用上限)待四類齊備後在組合層一次過定 | D-170;主 agent 暫定 |
| 停手線 | 用戶 2026-09-11 答「no need」,不設;每注只用風險回報相對比較 | principles §三 第 2 條 |
| 集中火力 | 平常不必活躍,真正非凡的機會才集中;極高安全邊際的不對稱注優先 | 原則一、八 |
| 規則的地位 | 不神聖化;環境變則方法變;但每次分析的判準在開始前寫定,不在看到結果後改 | 原則三;主 agent 評估 |

## 四、買入、等待、加倉、退出的原則

| 情境 | 原則 | 出處 |
|---|---|---|
| 買入 | 論點成立不等於現價值得買;要分開答「公司改善是否可持續」與「現價付了多少」;現價要求的假設要寫出來 | D-179 第 1 條;論點卡清單 v3 步六 |
| 等待 | 論點成立但價格無吸引力、機制未明、證據不足等業績,都是完整結論;不強迫買賣 | ② 對帳單 §十二 第 17 條(TradingAgents 提示詞偏向買賣的反例) |
| 加倉 | 每次加倉重新成立,價跌不自動加;按證據狀態分觀察、小額初始、加倉、價已反映不買 | D-169 第 4 條 |
| 退出 | 三問:關鍵預測被推翻?剩餘回報值不值?預定證據按期出現?到期未兌現按規則退出;技術失效與基本面失效分開寫 | D-169 第 5 條;第六輪外評 |
| 風險回報 | 按實際方案算(單一目標、分批、壓力情境);目標拉遠或止損收窄做出的漂亮比率不算;目標可達性與所需時間要講 | 第六輪外評 |
| 敘事三件 | 護城河、經濟學(供需、技術商業化)、財務(債務與破產風險);敘事成真時錢落在主角還是瓶頸環節要答 | framework §二;D-167 第 5 條 |
| 換類 | 同一公司會沿四類光譜移動,換類是最重要事件之一,卡上要標 | framework §三 第 3 條 |
