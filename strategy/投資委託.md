# 投資委託(v1.1,2026-09-14;KARST-239)

> 工作台每個分析角色開工前讀這一頁。它答四件事:這位投資者要什麼、能承受什麼、手上有什麼、按什麼原則買賣。每格註明出處;用戶偏好、模型分析規則與示例參數分開。改本檔即改所有角色的前提,要記版本。
>
> **現行執行口徑**:持有期一個月至一年已有 D-169 的用戶原話,不用重問。每注 1% 只供計算展示,未成為用戶的實際風險預算;資金停手線未設定,不沿用 A-043 的舊預設。資料與注碼缺口不阻止股票頁給出有條件的看法、入場／退出條件與 R&R。

## 一、目的與期限

| 項 | 內容 | 出處 |
|---|---|---|
| 目的 | 以基本面與敘事為核心,選擇值得承擔的風險,爭取跑贏大市並提高長期資本回報;不以平滑曲線為首要目標。報告回報、損失與共同曝險;資金停手線按第二節的用戶決定,目前未設定 | D-166;原則十與主 agent 評估(principles §二) |
| 不做的事 | 即日交易、剝頭皮;純資金推動的狂熱股(GME/AMC 類)整條線不做 | D-166;D-147 |
| 持有期 | 通常一個月至一年(用戶已表明的偏好);每張論點另記預期持有期、下一個驗證事件與較長的生意兌現期。短期執行訊號不等於縮短投資期限,不得為遷就遠期估值而默默延長持有期 | D-166;D-169 出處欄(用戶原話「my perference is actually on 1 month to 1 year」) |

| 回報目標 | 不以固定回報目標把關;策略回顧有實際結果才報複合年化、最大跌幅、命中率與優勢來源。股票頁報持有期情境回報、下行情境、時間與依據,不把預測當已實現績效 | D-148;D-149 |

## 四、買入、等待、加倉、退出的原則

| 情境 | 原則 | 出處 |
|---|---|---|
| 買入 | 論點成立不等於現價值得買;要分開答「公司改善是否可持續」與「現價付了多少」;現價要求的假設要寫出來 | D-179 第 1 條;論點卡清單 v3 步六 |
| 等待 | 論點成立但價格無吸引力、機制未明、證據不足等業績,都是完整結論;不強迫買賣 | ② 對帳單 §十二 第 17 條(TradingAgents 提示詞偏向買賣的反例) |
| 加倉 | 每次加倉重新成立,價跌不自動加;按證據狀態分觀察、小額初始、加倉、價已反映不買 | D-169 第 4 條 |
| 退出 | 三問:關鍵預測被推翻?剩餘回報值不值?預定證據按期出現?到期未兌現按該論點預定規則處理;任何延期另建版本、記新依據,不重寫原期限。技術失效、基本面失效與實際執行方式分開寫;可建議全部退出,不只減倉 | D-169 第 5 條;第六輪外評 |
| 風險回報 | 按實際方案算(單一目標、分批、壓力情境);目標拉遠或止損收窄做出的漂亮比率不算;目標可達性與所需時間要講。以止損距離算的是計劃內損失,另算跳空／流動性壓力;已有持倉用現價的剩餘回報與風險作決策,成本價另列記帳 | 第六輪外評 |
| 敘事三件 | 護城河、經濟學(供需、技術商業化)、財務(債務與破產風險);敘事成真時錢落在主角還是瓶頸環節要答 | framework §二;D-167 第 5 條 |
| 換類 | 同一公司會沿四類光譜移動,換類是最重要事件之一,卡上要標 | framework §三 第 3 條 |

## 五、執行與參數來源

- 每次輸出分開記 `mandate_version`、`portfolio_snapshot_id`、`risk_budget_source`(用戶設定 / 示例 / 未設定)與 `portfolio_scope`。示例參數可改而不重寫用戶偏好。
- 正式注碼計算需有相同範圍的組合淨值、用戶設定的預算與集中度限制,並同時考慮正常退出及壓力損失。缺時給出公式、每單位資金的損益或示例敏感度,不偽造完整組合的可用風險額度。
- 同一公司多個論點、分批進場與跨股共同敘事要合併看實際持倉,不能各自領一份預算。沒有可執行的價格退出規則時,不以任意收窄的價差反推大部位。
- 停損價不是保證成交價;收市確認退出亦須把確認至實際成交的時間差納入計劃。依據:[SEC Investor.gov：Types of Orders](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/types-orders)。
