# strategy/tools —— 即時判斷用的小工具

這個目錄放**看一家公司當下值不值得研究下去**的計算工具。它不是策略引擎的一部分:不碰 `karst/`(D-165 引擎凍結),不做回測,不掃參數,不產生訊號。

目前只有一支:

## implied_expectations.py —— 隱含預期計算器(KARST-183)

### 它答什麼問題

不是「這家公司值多少」,而是**「現價要求公司做到什麼,才剛剛好對得住這個價」**。方向反過來:把股價當已知,把經營路徑當未知,解出未知那一項。

輸出兩件**分開**的東西,第二件不由第一件推導:

- **(甲)長期價值範圍**——在一組明寫的經營假設下,公司每股值多少。用現金流折現。
- **(乙)一年持有回報情境**——一年後市場若只給某個市銷率,持有一年的回報是多少。用公司自己過去幾年的市銷率分佈當退出倍數,**與(甲)的折現值無關**。

分開的理由:一年期限如果只是把十年折現值除以時間,那個期限根本沒有進入投資判斷。一年內能不能賺錢,靠的是市場肯給什麼倍數,不是靠內在價值最終會不會兌現。

### 用法

```
python strategy/tools/implied_expectations.py SNOW AXTI                 # 只印帳目與市場快照
python strategy/tools/implied_expectations.py SNOW AXTI --full          # 反推表 + 敏感度 + 兩個輸出
python strategy/tools/implied_expectations.py AXTI --full --base annualized_q --json out.json
```

`--base annualized_q` 把最近一季 ×4 當起步年,用於剛剛轉折、TTM 明顯落後的公司。

新增一家公司要在檔內 `CASES` 加一格固定假設(折現率、銷售資本比、正常化利潤率、一年情境的收入增速格)。這些是判斷,不是資料;每次改動都要在結果檔的假設清單寫明理由。

### 輸入

| 項目 | 來源 | 說明 |
|---|---|---|
| 收入、營業利潤、股權薪酬、折舊攤銷、資本開支、稅、稀釋股數 | `data/sec/companyfacts/CIK##########.json.gz` | SEC XBRL 申報帳目。累計期會自動拆成單季再合成 TTM(同一期間有多次申報時取最後一份) |
| 現金、投資、有息負債、租賃負債、少數股東權益 | 同上(最近一季資產負債表) | |
| 代號→CIK | `data/sec/company_tickers.json` | |
| 現價、歷史價格、現時股數 | yfinance | 歷史市銷率用「當日收市價 × 稀釋股數 ÷ 當時已公開的 TTM 收入」,假設帳目在季末後 40 日才公開 |

### 三組假設(一組都不能省)

1. **經營路徑**——第一階段的收入年增率、這一階段維持幾年、之後的增長率、第 N 年的正常化營業利潤率、利潤率由今日走到目標要幾年。
2. **現金流轉換**——稅率;增長所需的再投資 = 收入增加額 ÷ 銷售資本比(增長不能免費,高增長必然吃現金);股權薪酬的處理。
3. **長期估值**——折現率、終值增長率、終值期投入資本回報率(決定終值再投資率)。每次輸出都印**終值佔企業價值的比重**。

### 兩個口徑,寫死在這裡

**股權薪酬與稀釋。** 股權薪酬在 GAAP 營業利潤裡**已經是費用**,計算器直接用 GAAP 營業利潤,**不加回**;股數用**稀釋後**股數。這一套在(甲)裡就是完整的處理——不再另外扣未來稀釋,否則同一件事扣兩次。(乙)那一邊因為要算一年後的每股價格,才另計一年淨稀釋,取「股權薪酬 ÷ 市值」(授出價值佔市值的比例約等於新增股數佔總股數的比例),下限 0.5%。兩家公司用同一套。

**企業價值轉每股價值。** 每股價值 =(企業價值 − 淨負債)÷ 稀釋後股數。
淨負債 = 有息負債 + 經營租賃負債 + 少數股東權益帳面值 − 現金 − 短期及長期投資。
少數股東權益放進淨負債那一邊,是因為企業價值屬於全體資本提供者,不只母公司股東。

### 淨負債取數規則(KARST-186 釘死)

**現金與投資:有序後備清單,不是「第一個有資料就用」。** 公司會換 XBRL 標籤(例如
lululemon 的 `CashAndCashEquivalentsAtCarryingValue` 停在 2019 財年,之後改用
`CashCashEquivalentsRestrictedCashAndRestrictedCashEquivalents`)。取數依序試每個候選標籤,
取**第一個覆蓋到最近一季(asof)前後 200 日內**的標籤,不是第一個「曾經有資料」的標籤——
舊寫法卡在舊標籤的過期資料上,現金被容差濾成 0,曾令 lululemon 淨負債誇大 15.15 億美元
(A-048,已修)。若全部候選標籤都缺近期資料,退回「合併全部標籤取最後一筆」的盡力結果,
並在輸出印 `[注意]` 警告——不再靜默當 0。完全沒有標籤資料(多數代表公司真的沒有這一項,
例如沒有租賃負債)不印警告,以免洗版。

**LongTermInvestments 要不要計入淨現金,不能只憑標籤名字放行。** 這一格理論上該放
可變現的證券(國債、公司債、存款證),但有重資產或合營/聯營的公司,個別申報也可能把
非證券的策略性股權投資塞進同一格。判斷規則:格內金額出現大幅跳動,或者公司本身有已知的
合營/聯營持股時,要讀最近一期 10-Q/10-K 的投資附註(Investments / Fair Value Measurements
那一節),核金額組成——是市場可交易的證券就計入淨現金,是策略性股權投資(通常另外報在
「Other assets」或用權益法核算的附註)就不計入。核過的例子:AXTI 的 LongTermInvestments
在 2026-06-30 跳到 2.986 億美元,10-Q Note 2 核實全部是國債、公司債、存款證;AXTI 對原材料
公司的股權投資(1,410 萬)另外報在 Other assets,不在這一格內(A-047,已核實成立,見假設冊)。
本規則只在 AXTI 這一個樣本驗證過,不代表全部公司都乾淨——大額波動的長期投資格仍應逐家核附註。

### 限制(先看清楚再用結果)

1. **沒有共識預估。** 手上只有申報帳目,沒有分析員的收入與盈利預測。所以「市場預期」一詞在這裡只能解作「用這套假設反推出來的數字」,不是任何人真的講過的預測。換一組固定假設,反推值就變。
2. **反推值不是唯一解。** 現價一條方程,未知數十幾個。工具做的是固定其餘、解出一項;每張表都要連同它固定了什麼一起讀。單獨一個數字沒有意義。
3. **敏感度只做 ±10%。** 只答「這個假設錯一成,結論偏多少」,不答「這個假設會不會錯」。
4. **折現率是輸入,不是市場觀察。** 折現率是全套裡最強的槓桿(見結果檔的敏感度表),而它由人手指定。任何「貴 / 平」的結論都建基於這個手填的數字。
5. **終值佔比往往超過 100%。** 明確預測期現金流為負(仍在燒錢或大量再投資)時,終值會超過企業價值全部。這不是錯,但代表結論幾乎全部押在十年後那一個假設上。終值佔比越高,結論越不可靠。
6. **線性利潤率爬升是簡化。** 由今日利潤率直線走到目標利潤率,現實不是這樣。虧損公司在早年不給稅盾,也不計淨營業虧損結轉的未來稅務利益——會低估。
7. **收入是唯一驅動。** 沒有分部拆解、沒有毛利率與經營開支分開建模、沒有營運資金。
8. **XBRL 標籤覆蓋不齊。** 缺股權薪酬標籤的公司會當 0 處理(會高估自由現金流),缺標籤時腳本會在輸出印 `[注意]`。長期投資一格用的是資產負債表標籤,可能混入非流動的非證券投資——要逐家核。
9. **一年情境用歷史市銷率當退出倍數。** 生意性質剛剛改變的公司(例如產品組合換代),歷史倍數的參考價值很低。腳本因此同時印近一年與四年兩套分位數,並按現價站在區間哪一邊自動換情境標籤。
