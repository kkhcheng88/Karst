# 用戶十條交易原則與主 agent 評估(2026-09-03)

> 來源:用戶 2026-09-03 交來的十條原則(原文照錄於第一節),問「What do you think」。
> 性質:判準文件。這十條連同 D-148(目標數字不作把關)一起,決定日後每條策略怎樣被評。

## 一、原文(用戶交來,照錄)

一、平常不必非常活躍;真正非凡的機會出現時,才集中火力。
交易不是每天都要做很多事。更重要的是把注意力和資本保留下來,留給真正重要、真正值得下注的機會。
二、找出真正有優勢,而且符合自己性格的方法。
市場上有很多可以賺錢的方法,但不是每一種都適合自己。真正重要的,是清楚自己的優勢在哪裡,並建立一套自己能夠長期執行的方法。
三、永遠保持進化,不要把任何規則神聖化。
所有規則都有其適用的市場環境。當環境改變,策略也要進化;不能因為某套方法過去有效,便把它當成永遠不能質疑的教條。
四、清楚自己究竟在玩甚麼遊戲。
你的Game Plan是甚麼?優勢來自哪裡?策略是否Scalable?資金規模增加之後,回報是否仍能維持?
這些問題,必須想得非常清楚。
五、即使策略不具備很高的Scalability,也不代表現在不應該全力去做。
只要策略仍然有效,而你距離真正的容量樽頸還很遠,便應該繼續把握自己的優勢,而不是因為擔心遙遠將來可能出現的限制,過早放棄現在能夠賺取的回報。
六、資金越大,回報率無可避免會下降;但不要過早限制自己。
你的資本規模,可能距離策略真正的盡頭仍然非常遙遠。
在到達彼岸之前,不要因為限制性信念,過早追求穩定的低雙位數回報,因而錯失中間大量的回報、成長,以及交易的樂趣。
七、即使資本變大,仍然可以把資金分拆成很多小份。
不同部分的資金可以運用不同策略,繼續盡量提高整體資本回報,從而減慢資金規模增加後,回報率遞減的速度。
八、集中精力發掘Margin of Safety極高的交易。
例如他在書中提及的日本公司交易:真正值得集中下注的機會,往往不是單純預測價格會升,而是下行風險有限、潛在上行空間卻非常大的不對稱機會。
九、用正確的時間尺度管理自己的情緒。
過度自信時,重看自己過往的回撤,提醒自己並非不可戰勝。
感到絕望時,則把鏡頭拉遠,重新看看自己的長期資產曲線,不要讓短期低潮扭曲對自己的判斷。
十、放棄追求低回撤、完美曲線,轉向最大化長期總盈利。
一條看起來非常平滑、幾乎沒有回撤的資產曲線,不一定代表最好的結果。
如果為了追求表面的穩定,而犧牲大量原本具有正期望值的機會,最終可能只是令長期總盈利大幅降低。

## 二、主 agent 立場(D-110:每條講信不信、對本倉的後果)

| 條 | 立場 | 對本倉的後果 |
|---|---|---|
| 一 集中火力於非凡機會 | 同意 | 這正是候選一(集中長賠率注)的形;也解釋為什麼十一條「每月換倉」系統線全部輸給指數——它們每天在做事。 |
| 二 優勢要合性格 | 同意 | 兩人公司、散戶規模、人手讀鏈:優勢只能在「機構做不到的細處」。這條已經是本倉的容量尺。 |
| 三 不神聖化規則 | 同意,但要分開兩件事 | 「每張票判準先凍結」不是神聖化,是防止跑數後改尺;神聖化是指策略層面。兩者不衝突。 |
| 四 玩什麼遊戲 | 同意 | 本倉的遊戲已經寫明:市況 > 價值鏈 > 個股 > 觸發,優勢來自人手鏈層解析度。 |
| 五、六 不因容量過早放棄 | 同意,並改本倉做法 | 我一直把「容量」列為策略四把尺之一,對兩人公司這把尺現在無用;降為資料欄,不作排序。 |
| 七 資金分拆多份 | 同意 | 把「主線對副線」由「二選一」改為「同時跑、按份額分」:回購過濾器一類淺跌幅零件與長賠率注不是競爭關係。 |
| 八 極高安全邊際的不對稱注 | 同意,而且與本倉數據有一個要解開的矛盾 | 十倍股盤點量到十倍股起步時細、燒錢、營業額在跌——上行極大但下行**不**有限。品質過濾器已證會誤殺十倍股;資產負債表式安全邊際(公司死不了)會不會?已開存在性測試(KARST-166)。 |
| 九 情緒的時間尺度 | 同意 | agent 不代管情緒;本倉的對應物是每張票報最大跌幅與運氣帶,讓覆核時看得到「這條線本來就會這樣跌」。 |
| 十 放棄低回撤、最大化長期總盈利 | 同意方向,不同意字面 | 「最大化長期總盈利」在數學上等於最大化複合增長率,而複合增長率**自動**懲罰深跌幅(跌一半要升一倍才回本);過度下注會令長期總盈利下降而不是上升。所以尺不是「不管跌幅」,是「複合增長率 + 一條停手線」——停手線只有用戶知道。A-043 我預設的 25% 主線很可能太緊,待用戶一句話改。 |

## 三、由此改動的判準(D-149)

1. 策略四數改為:**複合年化、最大跌幅、命中率(長賠率注)或月勝率(橫截面)、優勢來源**;容量降為資料欄。
2. 排序的尺:複合增長率;唯一硬線是用戶的停手線(跌到多少會停整個計劃),用戶未講之前沿用 A-043。
   **2026-09-11 補(第四輪外評,主 agent 採納,用戶未答):停手線拆兩條。(a)資金停手線:即使仍信策略也不願再承受的損失——先定實際金額,再換算為計劃資金百分比;要寫清楚範圍(①單獨還是四類整個組合)、起算點(相對最初投入的累計損失,還是相對淨值高點的回撤)、停手動作(停止新增風險、覆核持倉、怎樣減倉);碰線前另設覆核點。(b)方法停手線:核心假設被推翻、資料不可靠、或必須不斷放寬規則才找到交易——未虧錢也可停。第一條要答的問題:「假設這個計劃最終失敗,你最多願意為它損失多少實際金額,而不影響生活安排及其他重要目標?」**不代填 10% 或 20%。**
3. 主線與副線不再是二選一,是資金份額問題;份額由用戶按四數決定。
4. 第八條與十倍股畫像的矛盾交 KARST-166 量。

## 四、我不同意或要提防的地方

- 第十條最容易被誤用成「跌幅不重要」。對兩人公司,真正的風險不是曲線不好看,是跌到一個令人停手的深度;一停手,長期複利就斷了。所以我要用戶親口講停手線,不由我猜。
- 第五、六條講的是「距離容量樽頸很遠」;這對本倉成立(散戶規模),但十倍股線的容量樽頸不在資金,在**人手讀鏈的頻寬**——一次只能認真跟三至五條鏈。這條樽頸現在就在,不在遙遠將來。
