## 3. MU 2023 校準錨(ex-ante only)

**紀律**:以下全部用「截至 2023 年底,一個當時嘅觀察者可以知道嘅資訊」打分。唔用「MU 之後升到
$1,154」呢類後見之明。財務數字一手驗證(defeatbeta quarterly_income_statement,2026-07-12 拉)。

### 3a. 真.財務底喺邊——比想像遲

| 財季(defeatbeta 財報日) | 收入 | 毛利 | 毛利率 | 淨利 |
|---|---|---|---|---|
| FQ3 2022(2022-05-31)| $8.642B | $4.035B | 46.7% | $2.626B |
| FQ4 2023(2023-08-31)| $4.010B | **−$435M** | **−10.8%** | **−$1.430B** |
| FQ1 2024(2023-11-30,財報日≈2023-12-20)| $4.726B | −$35M | −0.7%(近打平) | −$1.234B |
| FQ2 2024(2024-02-29)| $5.824B | $1.079B | 18.5%(轉正) | $793M |

**真.毛利率底 = FQ4 2023(2023-08-31 財報),唔係 2022 尾。** 由 FY22 高峰 46.7% 毛利率插水到
−10.8%,一年半內大約 57 個百分點嘅擺動——**feature 1(營運槓桿)ex-ante 已經清晰可見,唔使等
後見之明**。

### 3b. 股價比財務底走得快——重要發現

| 日期 | MU 收盤價 | 相對 2022-12 低位($49.12) |
|---|---|---|
| 2022-12(全期低位)| $49.12 | — |
| 2023 全年低位 | $50.37 | 幾乎重試低位,但未破 |
| **2023-08~09(FQ4 財報,毛利率−10.8%嗰陣)** | **$67.59(均)** | **已經 +38%** |
| 2023-12-20(constraint-language 首次轉正,score=1.005)| $78.69 | +60% |
| 2024-03-20(score 飆到 1.741)| $96.25 | +96% |

**誠實發現**:市場喺財務數字最差(2023-08 毛利率−10.8%)嗰陣,股價已經由 2022-12 低位彈咗
**38%**;去到 constraint-language 訊號首次轉正(2023-12-20),股價已經彈咗 **60%**;去到訊號
最強(2024-03-20,score 1.741),已經彈咗接近 **一倍**。即係話**股價本身跑贏咗 constraint-language
訊號**——17個月早過分析員敘事係真,但**唔係「早過股價本身」**,股價喺 constraint-language 都未
轉正之前就已經開始重新定價。

### 3c. 逐個 feature 打分(截至 2023 年底,ex-ante)

| Feature | 分 | 依據 |
|---|---|---|
| 1. 營運槓桿 | **高** | 毛利率一年半內擺動 57 個百分點(46.7%→−10.8%),ex-ante 由每季財報直接讀到,唔使等未來數據 |
| 2. 供給受限+定價權 | **低→剛轉中(2023年底先)** | 三寡頭結構係已知恆常事實(高分應得),但 MU 自己電話會 constraint-language 全 2023 年 ≈0 或負,**直到 2023-12-20 先首次轉正**——即係話呢個 feature 喺真.財務底(2023-08)嗰陣仲未確認,落後財務底大約 4 個月 |
| 3. 距底部幾遠 | **遠(好)** | FY22 正常化盈利力(~46.7%毛利率、$8.6B/季收入)vs FQ4 2023(−10.8%、$4.0B)——遠低於正常化基準,ex-ante 可直接計 |
| 4. 樽頸位置 | **高** | DRAM/NAND fab 資本密度($10B+/世代)+ 全球得 3 個玩家,結構性、多十年事實,唔需要 2023 特定數據先知道 |
| 5. 情緒/擁擠 | **中低(好,但證據最弱)** | 「死週期股」敘事(用戶原話)質性成立,但冇 2023 年當時嘅分析員評級分佈/put-call ratio 呢類量化證據做支持——**呢個 feature 係全部5個入面證據最弱嘅一個,誠實標低** |

**P1(護城河獨立於商品價格)**:PASS——DRAM 三寡頭結構唔靠任何單一價格點存在。
**P2(供給紀律逆轉=死亡訊號)**:PASS(冇觸發)——2023 年 MU 及對手正在**削減** capex,唔係擴張,呢個係 bullish 配置,唔係 kill signal。

## 4. 校準結論

**4/5 features(1,3,4,同兩個pattern)截至真.財務底(2023-08)已經明確favourable,ex-ante 可
打高分,唔使等任何後見之明。** 淨係 feature 2(constraint-language)落後真.財務底大約4個月,
直到 2023 年尾先轉正。

**呢個發現嘅意義**:
1. **Rubric 通過測試**——喺已知答案嘅 MU 案例,套用 ex-ante 打分,4/5 features 都會俾高分,**證明
   rubric 有分辨力,唔係靠後見之明先睇到「乜都啱」**。
2. **股價比 constraint-language 更早**——呢個係§3b嘅重要發現。如果 rubric 淨係靠 feature 2
   (constraint-language)做觸發器,你會喺股價已經彈咗38-60%先入場。但 feature 1/3/4 全部**唔需要
   等公司自己講嘢確認**——毛利率/距底部/樽頸結構呢啲喺財報一出(2023-08)就已經讀到。
3. **對 scorecard 設計嘅實際建議**:唔應該將 constraint-language 當做唯一觸發器(現行做法);
   應該將 feature 1/3/4(財務+結構,唔靠管理層口徑)做**早期候選篩選**,constraint-language 做
   **確認層**(feature 2 轉正 = 額外信心,唔係入場必要條件)。呢個係 rubric 設計上一個實質、
   可執行嘅修正,唔係抽象結論。

## 5. 誠實 caveat

- Feature 5(情緒/擁擠)冇量化 ex-ante 證據,純質性判斷,係全 rubric 最弱一環,需要搵歷史
  analyst rating distribution / put-call ratio 呢類數據先可以升級(未做)。
- 呢個係**單一案例校準**(n=1)。下一步(§6 待做)要用案例庫其餘幾隻(贏家 FSLR、輸家做對照)
  cross-validate,先可以話 rubric 有真.分辨力(唔淨係喺 MU 一個度啱)。
- MU 2016-18 歷史先例(週期7a)有獨立驗證嘅可能——同一隻股、同一套邏輯,8年前已經跑過一次,
  可以做第二個校準點(未做,留待 §6)。
