# Core v2 操作手冊(standalone runbook)—— 唔使睇其他檔都執行到

> 配套:策略原理/證據見 `docs/2026-07-06_core_strategy_v2.md`;本檔淨係「點做」。
> 適用:E-旗艦格(月度 top-up / b=15% / Δ0.50 / SPY+QQQ 對半)。E-穩版只係 Δ 改 0.70,其餘一樣。
> 帳戶假設:US$500k-1M、可買美股期權(Level 2 long options 已夠)、HK 稅務身份。

## 1. 每日(收市後,1 分鐘)

1. 攞數:SPY 同 QQQ 嘅今日收市價、各自 200SMA(來源任一:`python backtest/scan.py` / dashboard / broker 圖表加 SMA(200,close))。
2. 判定:

| SPY vs 200SMA | QQQ vs 200SMA | 聽日動作 |
|---|---|---|
| 上 | 上 | 無(最常見)|
| 啱啱跌穿(今日收市首次 <)| — | **聽日收市前沽晒 SPY leg 全部 LEAP**;所得現金留 sleeve 池;底倉一股都唔郁 |
| — | 啱啱跌穿 | 同上,QQQ leg |
| 啱啱升返上(今日收市首次 >)| — | **聽日收市前買 SPY leg LEAP**(用 sleeve 池現有現金,買到幾多買幾多,見 §2)|
| 持續喺下 | 持續喺下 | 無(等)|

規則:淨係「今日狀態同尋日唔同」先有動作;開市 gap 穿咗唔理,**一律等收市判定**;漏咗一日就下個交易日照判定做,唔追溯。

## 2. 開倉 SOP(每 leg)

1. **預算**:該 leg 目標 = 7.5% × 而家 NAV。例:NAV $600k → $45k。
2. **揀到期**:330-420 日內最近嘅標準月度到期(通常係下年同月或後一個月嘅第三個星期五;LEAPS 一月系列都得)。
3. **揀 strike**:開期權鏈,揀 **delta 最接近 0.50** 嗰個 call(broker 有 delta 欄;E-穩揀 0.70)。
4. **張數** = floor(預算 ÷ (mid 價 × 100))。例:SPY 1 年 0.50Δ call mid $70 → floor(45000/7000)=6 張。
5. **落單**:limit @ mid;10 分鐘唔成交,改 mid + ¼ spread;再唔得,聽日再嚟(**唔准 chase 過 mid + ½ spread**)。>5 張可以分兩日入。
6. 買唔晒(現金唔夠一張)→ 剩錢留 sleeve 池,月度 top-up 會補(呢個係設計內,唔係錯)。

## 3. 每月首個交易日:Top-up(5 分鐘)—— **成個策略嘅命脈,唔准懶**

1. 計 sleeve 現值 = 兩 leg LEAP 市值 + sleeve 池現金。
2. 若 sleeve 現值 < 15% × NAV:**沽底倉 SPY 股票**補差額入 sleeve 池(差額 = 15%×NAV − sleeve 現值)。
3. 若該 leg 而家喺閘上(>200SMA)而池有錢 → 照 §2 買到目標;若閘下 → 現金留池收息,唔買。
4. 若 sleeve 現值 ≥ 15%×NAV:**乜都唔做**(唔強制沽;超額由 roll 掃走,見 §4)。

> 點解重要:回測證明冇呢步,LEAP 有 40-60% 合資格日子冇錢開倉,alpha 冧一半以上
> (`core_topup`:cash-starved 53%→10%,保守 model t 1.8→3.1)。

## 4. Roll(每季左右一次/leg)

觸發:任一 leg LEAP 剩 **63 個交易日**(broker 顯示 DTE ~88 個日曆日左右;每月 top-up 嗰日順手檢查 DTE 就夠)。
1. 賣舊(limit @ mid,同 §2 落單紀律)。
2. 即日/翌日買新:同 leg、1 年期、delta 0.50,張數按 §2 用該 leg 目標預算重計。
3. **掃盈利**:賣舊所得 > 該 leg 目標預算嘅部分 → 買 SPY 股票入底倉(beta 維護,唔係 alpha,唔好覺得自己勁)。

## 5. 每年首個交易日:再平衡(10 分鐘)

全組合調返 70(SPY 股)/ 15(sleeve)/ 15(現金)。買賣用收市前 market-on-close 或 limit。誤差 ±2pp 內可以唔郁(慳成本)。

## 7. 邊界情況

- **帳戶 <$200k**:轉「每 leg 固定 1-2 張」制,百分比目標冇意義。
- **NAV 大跌後預算縮水**:一律用「而家 NAV」計,唔用歷史高位。
- **兩 leg 同日都有動作**:先做沽(釋放現金)後做買。
- **除息/公司行動**:SPY/QQQ ETF 唔使處理;deep-ITM(E-穩 0.70Δ)喺大額除息前 broker 或有 early-assignment 提示 —— long call 冇 assignment 風險,唔使理。
- **VIX 攞唔到**:M1 跳過,核心規則(§1-5)完全唔靠 VIX。
- **連續 whipsaw(一個月 cross 幾次)**:照規則做。回測含晒呢啲成本;2004/2010/2015 型年份預咗輸 2-7pp,唔好中途改規則。

## 8. 監控(每月尾,5 分鐘)

記低:NAV、YTD 對 SPY 總回報超額、兩 leg LEAP 市值、本月有冇 top-up/roll/閘動作。
**預期管理**:保守估計超額 +4.6~6.5pp/年(damped model)、好年可以雙位數(base model)、
趨勢反覆年**會輸**;最差滾動月可以 −40%(2020 型,閘切走之前)。三年計先好評卷。
