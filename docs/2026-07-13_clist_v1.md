## 1. 入選標準【寫死 — 唔准事後搬龍門】

呢四條係揀 20 隻嘅**機械規則**,任何人照跑都出同一張單(反 cherry-pick):

**閘 A — 硬性排除(違反即出局,零酌情)**
1. **E_norm > 0**:正常化盈利力必須為正。E_norm ≤ 0 = binary / pre-profit / 燒錢,
   估值只能 option-framing,**一律唔准入**(呢類名歸 A-sleeve 閃縮或量子彩票判死區,唔屬 C-list)。
2. **Solvency 閘(L1 可達性)**:P_base@14x=1.0 對應價必須 > 0(即 `14×NOPAT_norm/1.0 − net_debt > 0`)。
   若淨債本身已 ≥ 目標 EV → 任何正價都到唔到 P_base=1.0 → 股權係薄槓桿切片 → **危機專殺,排除**
   (呢個就係 spec 講嘅 USAC「槓桿假象」,由公式機械捉,唔靠肉眼)。

**閘 B — 質素閘(複利機器定義)**
3. 必須係**高 ROIC / 寬護城河 / 盈利耐用**嘅生意(software / payments / ratings-duopoly /
   醫療 / 工業寡頭 / 有定價力嘅品牌與半導體)。**商品週期股(冇定價力、price-taker)同低質分銷商
   一律唔算複利機器,即使 P_base 高**——P_base 高但無護城河 = 平因為抵買唔起,係 value trap,唔係折讓。
   (被此閘剔走嘅高 P_base 名見 §4a,呢個閘就係篩選嘅證據。)

**閘 C — 排序取 20(唔靠名氣,靠計)**
4. 通過閘 A+B 嘅複利機器,按 **P_base@14x 現值由高到低排**,取頭 20 隻。
   **P_base 越高 = 現價離「真折讓線」越近 = L1 觸發越淺 = 危機時越可能真兌現。** 呢個排序原則直接
   對應 admission 規則(收「可達 P_base>1.0」嘅名),自動將「貴到危機都難平」嘅名推落落選區(§4b)。

> **每隻 P_base 都係 `thesis/valuation.py` 真計出嚟嘅**(季度 Operating Income/Revenue 中位 margin ×
> min(TTM, 3年中位) revenue,詳見估值 v1 底稿),**唔准估、唔准靠名氣**。呢份用戶已拍板嘅入選門檻
> = P_base>1.0 極端錯價(D8 / P1-8),本清單忠實執行。

## 2. 觸發價設計【公式寫死,可追溯】

P_base 同價格**成反比**:`P_base = 14 × NOPAT_norm / EV`,`EV = market_cap + net_debt`。
價跌 → market_cap 跌 → EV 跌 → **P_base 升**。反推某目標 P_base(=T)對應價:

```
EV_T    = 14 × NOPAT_norm / T
mcap_T  = EV_T − net_debt
price_T = price_now × (mcap_T / market_cap_now)      # 股數在比值中對消
```

- **L1 觸發價 = 真折讓線(P_base@14x = 1.0)**:supercycle-free 正常生意已 100% cover 現 EV,
  個「超級週期夢」白送。呢個係 opportunity_ladder 嘅 admission 門檻——**危機初段第一注**。
- **L2 觸發價 = 深度折讓線(P_base@14x = 1.3)**:正常生意價值冚過 EV 30%(安全邊際)。
  **危機深化加注**。

**⚠ 為何兩條線都係深水位(多數名 −50% 以上)**:因為 admission bar(P_base>1.0)本身**高**。
C-list 定義上就係「十年一遇危機」嘅配角,**唔係調整市清單**。一般回調 / 調整市(−10~−20%)由
**C-core(SPY/QQQ LEAP)+ A-sleeve(優質股閃縮事件)**負責——嗰兩個先係「調整市檔」;C-list
係佢哋之後、危機更深時先上場。所以下表用**可觸發性分帶**呈現,唔扮 20 隻一樣易中。

**執行閘(清單 ≠ 自動買)**:本清單係**雷達層**。真金落注要**同時**滿足:①WS2 危機狀態機
ARM→ENTER(VIX>40 後回落<30,右側);②該月機會預算未爆(危機月上限 20% NAV,C-list 佔其 20-30%);
③逐隻現場 solvency 覆核(危機會急速惡化資產負債表)。表達:deep-ITM LEAP(0.7-0.8Δ)或正股。

## 5. 誠實邊界(信任呢張單前必讀)

1. **模擬環境價位**:本次現價由行情源讀取,若干名(KLAC/ACN)現價已達 P_base>1.0——
   呢個係**雷達層讀數**,係咪即刻執行由 C-core/現金部署紀律 + 當時 VIX 狀態決定,**本清單唔自動買**。
2. **P_base 係 SNAPSHOT,唔係擇時**:佢答「而家個價 embed 咗幾多夢」,唔答「幾時 re-rate」。
   擇時繼續由 cycle_stage + constraint-language + VIX 狀態機負責。清單須**每次危機前 re-run**
   (`python thesis/valuation.py --run` 更新 universe;`exp_clist_v1.py` 更新提名)。
3. **14× 係 baseline 假設非真理**;margin 非平穩;defeatbeta 深度僅 12-17 可用季;NVO 用 spot FX——
   全部繼承估值 v1 十條 caveat(見底稿)。**觸發價係一條線,唔係精確價**,危機時照現場覆核。
4. **事件 n 細**:危機 n≈4(2008/2020/2022/2025),清單**永遠唔會統計顯著**——
   本文件用「事先寫死 + 每次事後覆盤」管理,唔用 t-stat 管理(opportunity_ladder 定案)。
5. **提名集非窮盡**:v1 提名咗 ~26 隻經典複利機器 + 現有 universe;未覆蓋全市場。
   帶二尾段(WM/TMO/CSCO 等 L1 −70%+)觸發近乎不可達,保留係因為佢哋**係**複利機器、值得預先定價,
   但**預期極少 fire**;下版可加候選、可調帶界。
