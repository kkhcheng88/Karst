## 多重檢定陳述(2026-07-06 fresh-eyes 驗證後定稿)

Trial registry:loop2 = 10 configs(5 arch × 2 閘;舊記「11」係 off-by-one,已正)+ loop3 16 + loop4 4
≈ **30 個 trial**。alpha 喺**每一格**都 +3.4~5.9pp(唔係 max-of-many)。
**獨立覆核結果(用真實肥尾分佈計,非正態近似)**:
- **E1(t=3.7):Bonferroni ×31 後 p ≈ 0.003-0.007 → 清閘**;DSR(Bailey-López de Prado,skew +0.32/
  kurt 10.6/n=7657)= **0.9834 @ N_eff=31**、0.9959 @ 10、0.9988 @ 5 → **全部過 0.95**。
- **E2(t=3.4):Bonferroni 後 p ≈ 0.01-0.02 → 邊緣**,唔好講「<0.01」;E2 嘅地位 = 風險胃納選擇,
  統計上企得最穩嗰個係 E1。
E1/E2 之間嘅選擇(Δ Sharpe 0.02)唔宣稱統計意義。

**執行時序披露(升格自 code comment)**:全系統「T 日訊號 → T+1 執行」,**唯一例外 = R1 年度再平衡**
喺年首交易日當日收市執行(日曆事先已知,無資訊 look-ahead,但係時序紀律嘅正式例外)。

## 收貨結論(誠實版)

1. **贏 SPY B&H 嘅 Jensen alpha 存在**:+3.4pp(最保守:S4-off、raw 閘、cash 0%)至 +5.9pp(E2 headline),
   t 3~4,31/31 格、全部子窗口正。**機制**:LEAP = 唯一結構解(槓桿+非 benchmark 工具兌現 T1)+
   右側遲滯閘 + 恐懼 dip 入場;佢就係「core 唔使做英雄」嘅 modest 真 alpha。
2. **代價講清楚**:β≈1.0、MaxDD −45%(唔係半個 SPY 回撤)、肥尾(單月可 −12.8%)、趨勢反覆年會輸 2-7pp。
3. **靠 proxy 嘅部分**:S2 絕對幅度(RV-proxy IV)、S4 貢獻上限;**靠真數據舊證據**:T1 技巧存在
   (`rsi2_200sma` 附錄 α 4-6%/yr t2-2.9)、閘幫 LEAP(`leap_timing`)、CSP/SC 細正貢獻。
4. 板塊 ETF **唔入 core**(0/28 因子、TAA 輸、oracle EW premium 得 +0.6pp)——見策略檔 §5 說明。
