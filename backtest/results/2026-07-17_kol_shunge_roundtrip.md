## 0. 直接答

**(1) 跟佢完整 round trip(入+出),扣除「升市短揸本來就贏」之後,仲有冇邊際?**
**冇淨邊際,但亦唔係負 alpha——係打和。** 中位超額 vs SPY(同一段日子)= **-0.00%**,即完全貼住零。資本效率 +18.4%/年 vs 同期 SPY +22.1%/年,差 3.7pp。**但呢個差嘅正負號會隨一個預先登記嘅設計旋鈕反轉**:primary 臂(「減倉」當平倉)佢輸 SPY 3.7pp;exit-only 臂(淨係「清倉」先平倉)佢**贏** SPY 2.8pp(+24.2% vs +21.4%)。老實講法:**打和,方向落喺設計旋鈕嘅噪音入面,兩邊都唔可以當已證實。**

**(2) 佢嘅出場訊號本身有冇價值?**

**(3) 修正 mirror 之後,scorecard 嘅「看多負 alpha」結論要唔要改寫?**
**要,而且要撤回兩條結論,唔止改寫一條。** 詳見 §9。呢份報告係認錯,唔係補鑊。

**(4)〔追加〕佢自稱個股 75% / 大盤 85% 勝率,核實到嗎?**

## 1. 兩個修正 —— 點解要重測

### E1. Mirror 錯咗
scorecard 攞佢嘅入場訊號**死揸 21/63/126 日**。佢從來冇提出過呢個策略,佢原話係「soxl 144 這裡有些支撐……**如果要買就只能進進出出**。反彈目標 165 左右 lower high」。

**同一批入場、淨係換 mirror 嘅 A/B**(全部用本報告同一套價格機器,唯一變數 = 出場規則):

| 出場規則 | n | 命中率 | 中位超額 vs SPY | 資本效率 |
|---|---|---|---|---|
| 死揸 21 日(舊 mirror) | 894 | 48.2% | **-1.88%** | +4.8% |
| 死揸 63 日(舊 mirror) | 894 | 47.4% | **-5.55%** | +8.9% |
| 死揸 126 日(舊 mirror) | 894 | 51.3% | **-7.25%** | +12.9% |
| **跟佢自己嘅出場(本報告)** | 894 | **56.7%** | **-0.00%** | **+18.4%** |

**判詞:** 單單改返 mirror,中位超額由 -7.25% 變 0.00%——scorecard 嗰個「看多負 alpha」有大約 **7pp 純粹係度緊一個佢從未提出嘅策略**。

### E2. 抽取漏得犀利(呢個影響仲大過 mirror)
舊關鍵詞規則:方向**逐訊息**判,一條提到 11 隻 ticker 嘅訊息會將同一個方向套落全部 11 隻;判唔到就當「模糊」丟棄。

**LLM 逐 ticker 抽取 vs 關鍵詞規則(同一批 5,734 條訊息、同一個 ticker universe):**

| 指標 | 數 | 佔比 |
|---|---|---|
| 舊規則丟棄嘅「方向模糊」訊息 | 2,584 | 全部 ticker 訊息嘅 45.1% |
| ↳ 其中 LLM 抽到**明確交易動作** | **1,263** | **佔被丟棄嘅 48.9%** |
| 即舊報告掉咗嘅真訊號 | | **全部 ticker 訊息嘅 22.0%** |
| 舊規則判「有方向」但 LLM 判**冇動作** | **1,010** | **佔舊規則 claim 嘅 32.1%** |

被丟棄嘅真訊號實例(原文照錄):
- 「Nflx 可以开始加量sell put 400 以下的仓位。premium 不错」→ NFLX add
- 「利用疯牛机会套现一点。baba 夜盘也差不多达到我几天前预算117」→ BABA trim
- 「今天早上也大量sell put smci 500-580 这些价位」→ SMCI entry
- 「Nvda 公司透露减仓serv, 加仓APLD rxrx, NBIS. 大家可以考虑加仓」→ NBIS / RXRX entry

**判詞:** 舊抽取**兩邊都錯**——漏咗被丟棄訊息入面接近一半嘅真訊號,同時收咗三分一純閒聊當 claim。呢個唔係精度問題,係樣本本身錯咗。

### 抽取嘅 hindsight-blind 設計(點解今次准用 LLM)
原本禁用 LLM 抽取係為咗防後見之明。今次係**結構性封死**而唔係迴避:

- **B1** 抽取員只見訊息文字。冇價格、冇回報、冇市場數據;明令只准用 Read/Write,禁 WebSearch/WebFetch/Bash。
- **B2** 抽取員**唔見日期**。批次檔剝走 timestamp,事後用 message id 駁返。認唔到日期就用唔到「我知呢隻後來點」。(已程式驗證批次檔零日期洩漏。)
- **B3** 標籤係**語言判斷**(「呢句係咪買賣指令?」),唔係評價判斷(「佢啱唔啱?」)。
- **B4** ticker 詞彙**凍結**喺關鍵詞臂用嘅同一個正則 + 交易所 universe;LLM 只准標派俾佢嘅候選,唔准自己加。所以「關鍵詞 vs LLM」係**單一變數 A/B**:淨係 action 標籤變,ticker 解析不變。
- **殘留風險(申報,冇解決):** LLM 有知識截止日,理論上可以由內容推斷年代(例如認得某次銀行危機)。B1-B3 封死咗價格同日期通道,年代通道封唔死。

**抽取品質:** 5,734 條訊息 / 60 批 / 預期 9,094 條記錄 → 實收 **9,088(99.93%)**;1 行因為 ticker 唔喺候選名單被程式**拒收**(唔係靜靜收貨),6 條缺失。

## 5. 出場訊號有冇價值?(對照 c —— 隔離出場)

同一批入場,唯一變數 = 用佢嘅出場 vs 用一個固定日數計時器(日數 = 該組中位持倉期):

| 組 | 佢嘅出場 | 計時器對照(c) | 差距 |
|---|---|---|---|
| 有出場訊號嗰批(n=734) | 命中 **59.3%** / 資本效率 **+36.3%** | 9 日計時器:命中 52.7% / **+15.3%** | **+21.0pp** 資本效率 |
| 全書(n=894) | 命中 **56.7%** / 資本效率 **+18.4%** | 15 日計時器:命中 50.7% / **-1.1%** | **+19.5pp** |
| 個股(n=822) | 資本效率 **+19.1%** | 15 日計時器:**-4.0%** | +23.1pp |

**判詞:** **對照一個蠢計時器,佢嘅出場加值好大(+19 至 +23pp 資本效率)。** 但呢度必須接返混淆測試嘅發現:`kol_bear_confound` 已證佢嘅看空 = 動能翻版、冇超出動能嘅資訊(配對百分位中位數釘死 0.500)。**兩個發現唔矛盾,而且合埋解釋咗機制**:一個出場**唔需要有預測力都可以有價值**——「跌就走」係**狀態反應**,計時器係**時間觸發**,狀態反應本來就贏時間觸發。但呢個亦即係話:**佢個出場好可能一條 trailing stop 就複製到,唔使畀錢訂閱佢。** 本測試**冇做 trailing stop / 動能出場對照**,所以我只能講「贏計時器」,**唔能夠講「有獨有價值」**——呢個係本報告最重要嘅未補洞(§10)。

**同一個出場訊號亦係佢資本效率排第 1 百分位嘅元兇:** 佢嘅出場紀律**同時**製造咗高命中率(59.3%)同埋切走咗右尾(資本效率 +18.4% vs 隨機 +34.8%)。呢兩樣嘢係同一個行為嘅兩面,唔可以只要一邊。

**判詞:** **「佢贏定輸 SPY」呢條問題,答案隨旋鈕反轉**——exit-only 臂贏 2.8pp,primary 臂輸 3.7pp,warning 臂輸 5.0pp。**呢個就係點解我唔會寫「佢跑輸 SPY」做結論:三個臂全部落喺 SPY ±5pp 以內,呢個叫打和,唔叫輸。** 我照 R1 用 primary 做頭條,但唔會扮呢個 3.7pp 有意義。

**做空污染穩健性檢驗:** 我個 schema 冇「開空倉」呢個 action,所以佢嘅做空 call(「Dpz…可以做空,目标360」)會被摺埋入 `entry` 變成**做多**——方向完全相反。實測污染 = **77/3,334 = 2.3%** 嘅開倉動作。剔走之後:命中率 56.7% → **57.3%**、資本效率 +18.4% → **+17.2%**、中位超額 -0.00% → **+0.00%**、個股命中 56.2% → 56.6% [53.2%, 60.0%]。**結論全部唔變。** (呢個係設計缺陷,已測、已申報、無實質影響。)
