# Result — Crash-switch: SPY base holding -> QQQ/SPMO after a big drawdown, back to SPY on recovery (real data)

**Date:** 2026-07-08  **Script:** `backtest/experiments/exp_crash_switch.py`  **Status:** active

## Question

用戶問：QQQ 或 SPMO 大冧之後，把底倉由 SPY 換過去，回升後換返，會唔會好過一直揸 SPY？呢個係一個 DYNAMIC 換底倉決定（未測過——Core v2 同 `exp_base_mix.py` 只測過 STATIC 底倉選擇），本 script 完全隔離 LEAP sleeve/現金/top-up，100% NAV 永遠淨係 揸 SPY 或者候選標的其中一樣。

## Method

- 100% base-holding-only（冧 sleeve、冧現金、冧 top-up），Control = 100% SPY B&H （HK 30% 股息預扣淨額，`r_net` 公式同 `exp_base_mix.build_core_only` 一致，呢度本地 重做一份，因為唔需要 options engine）。
- 訊號：drawdown/200SMA/歷史高位全部用候選標的**自己嘅 RAW 收市價**計（同 `exp_leap_real_sweep.build_gates` 嘅 200SMA 閘一致，價格驅動，唔係 total-return 驅動）；組合報酬用各腿自己嘅 `r_net`（HK 淨額 total return）複利。
- 執行滯後：**T 收市訊號 -> T+1 收市執行**（比 repo 慣常「T 收市訊號 -> T+1 起持倉」多一日滯後——呢個 study 刻意咁 pre-register，模擬全數換馬需要一整個交易日先執行到）。
- 成本：5bps/邊，一次全數換馬（賣舊 100% + 買新 100%）= 10bps NAV，喺執行嗰 bar 一次性 扣減 NAV。
- V1（左側）：未持有候選 AND 候選收市價 <= 自身歷史高位 -X%（confirmed close）-> 換入；持有候選 AND 候選創新高（confirmed close）-> 換返 SPY。X ∈ {20%,30%(headline),40%}，候選 = QQQ。
- V2（右側）：候選回撤曾 <= -30%（episode armed）AND 候選收市重新企上自身 200SMA -> 換入（armed 消耗）；持有候選 AND 收市跌穿 200SMA -> 換返 SPY。候選 = QQQ。
- V3：V1(30%,headline) + V2 嘅 SPMO 版，窗 2015-10-12+（SPMO 上市日）。
- 窗：FULL = 候選自身完整公開交易史（QQQ: 1999-03-10+ ，本身就係 QQQ 嘅完整歷史，無截斷 artifact，包含 2000-02 完整熊市）+ 2016-2020 + 2021+；全部係**同一條連續模擬**嘅日期切片（唔係逐窗重跑），同 `exp_core_topup.py` 嘅 `wslices` 慣例一致。

## Cross-foot verification

- 32,882 bar-level NAV>0 assertions across all 6 switch simulations (QQQ V1 x3 + QQQ V2 + SPMO V1 + SPMO V2), ALL passed. Every completed switch-in is paired with either a matching switch-back or an explicit 'still held at end of sample' open-episode flag — no orphaned episodes (see episode tables above).

## Conclusions

**答案：唔會 — 三個變體（V1 三個深度、V2、V3）全部冧過 Control（100% SPY B&H），無一個顯著贏。**

1. **V1（QQQ，左側 drawdown 觸發，20/30/40%）**：全部 3 個深度喺 FULL 窗（1999-03+）α 都係
   flat-to-negative（-0.1pp~-0.6pp，t 全部 <0.3，唔顯著），但 **MaxDD 大幅轉差
   -74.6%~-80.5%，遠差過 Control 自己嘅 -55.6%**。呢個完全由 **2000-02 episode 主導**：
   換入訊號喺 2000-04（QQQ 已經由 3 月高位跌 20/30/40%）觸發，之後 QQQ 一路跌到 2002 年見底
   （跌幅約 -83% 峰值），呢個 episode 一直揸到 QQQ 喺 **2016-09-07 先重新創新高**先換返
   SPY（`port +41-81% vs SPY +88-100% -> -18%~-51%` 超額，見 episode 表）——即係「接刀」咗
   16 年先返家鄉。2016-2020/2021+ 兩個子窗方向唔一致、幅度細、全部唔顯著（最好嘅一格 V1-30%
   於 2021+ 都只係 +1.8pp t+1.0）。**結論：買跌唔會保護你唔再跌，只會令你更早接飛刀,再揸
   十幾年——risk 轉差,冇 alpha 補償。**
2. **V2（QQQ，右側 200SMA 復甦確認）**：FULL 窗 120 次換馬（~每年 4.5 次），α 幾乎打平
   （-0.2pp，t-0.2），MaxDD 都轉差（-58.6% vs -55.6%）——2000-02 熊市期間 QQQ 多次假突破
   200SMA 觸發入市、又好快再跌穿觸發換返，變成密集 whipsaw，冇改善風險亦冇 alpha。
   **「等 200SMA 收復先入」直覺喺呢個換馬設計上唔成立。**
3. **V3（SPMO 版）**：α 幾乎打平（V1 +0.1pp t+0.2，V2 +0.0pp t+0.9），**唔顯著**。
   **重要偏離 pre-registration**：spec 原先假設 SPMO 有 2020/2022 兩單 episode，但真實數據
   顯示 SPMO 喺 2022 年由自身歷史高位最多只跌 **-23.7%**（2022-09-26），未夠 -30% 觸發
   V1 門檻——所以 V1(-30%) 全期淨係揸到 **一單**（2020-03-24 換入 -> 2020-07-16 換返，
   `port +33.0% vs SPY +32.3% -> +0.6%`）。單一 episode、超額幅度細（+0.6pp）仲未計入
   已扣嘅換馬成本，**n=1 唔可以支持任何長史結論**。

**總判定：三種設計都唔應該取代現有 SPY 底倉。** V1 系列仲會令 MaxDD 明顯轉差（因為
2000-02 呢單接飛刀 episode），V2 只帶嚟 whipsaw 冇 alpha，SPMO 樣本太細唔夠證據。維持
100% SPY 底倉唔換，係現時證據下風險調整後最好嘅選擇。

## Caveats

- 單一歷史路徑，無 bootstrap；未做 Bonferroni/DSR 多重測試修正（呢個 study 係 用戶明確提出嘅單一假設驗證，唔係大格網 sweep，7 個 cell：QQQ V1×3 + QQQ V2 + SPMO V1 + SPMO V2 + Control，數目細，但都要意識到揀 30% 深度/200SMA 呢兩條規則本身已經係 judgment call，唔係窮舉最優）。
- **QQQ 2000-02 episode 係整個 V1 結果嘅主導因素**（見 Conclusions）——全數呈現喺 episode 表，唔剔除做 outlier；讀 V1 嘅 FULL 窗數字時必須連呢單一齊睇，唔可以淨睇 CAGR/α 就當冇事。
- **SPMO V3 嘅前提偏離**：pre-registration 假設 2020/2022 兩單 episode，實測 2022 年 SPMO 由自身 ATH 最深只跌 -23.7%（未過 -30% 門檻），V1 全期只得一單（2020）；SPMO 只有 ~10 年歷史 = 實質一個 regime（動能牛市+2020 V 型+2022 一次未夠深嘅回調），一單 episode 唔夠做長史結論。
- 換馬滯後（T 收市 -> T+1 執行）同成本（10bps/次）係模型假設，真實執行（尤其大手數）滑點可能更高；本 study 冇做滑點敏感度。
- 200SMA/歷史高位全部用 RAW 收市價（非 total-return 調整價）計；QQQ/SPMO 股息率低，呢個選擇對訊號時機影響應該好細，但未獨立驗證。

## Implication

**唔建議加入呢種 crash-switch 機制。** 維持現有 core v2 底倉 100% SPY（見
`docs/2026-07-06_core_strategy_v2.md` / `exp_base_mix.py` 已定案:SPY 底倉 + LEAP sleeve +
現金，STATIC 底倉唔換）。呢個 study 專門補齊咗一個未測過嘅 DYNAMIC 換底倉問題,答案係
負面——β 提升（QQQ 底倉 β~1.0-1.14）冇對應 alpha 補償,反而 V1 系列令 MaxDD 顯著轉差
（2000-02 接飛刀 16 年）,V2 系列純粹 whipsaw。若日後想再探討「危機入市」呢個方向,應該考慮
非 100%-of-book 嘅細倉衛星形式（例如 core v2 已有嘅 200SMA-GATED LEAP sleeve,細倉、有
premium 預算上限,唔係全數換馬）,而唔係本 study 呢種底倉全額置換設計。
