## 問題

- realcost 檔已證舊核心 v2 勝出格(C-monthly / b15% / Δ0.50 / SPY+QQQ 50/50)係喺已被否定嘅 m=0.85 揀出;判詞 3 逐字:「應該直接喺 m=1.15 上面重新跑成個 (b, Δ, cadence) 格,因為勝出格本身就係喺一個錯咗嘅報價下揀出嚟嘅,『邊格最好』呢個結論本身都可能跟住變」。
- SETTLED.md #2「Core v2 最終配置:SPY 底倉+SPY/QQQ LEAP、預算 15-20%、Δ0.50」就係現行已定案格;本檔用真價(m=1.15)重驗佢係咪仲係資本效率最高嗰格。
- **用戶授權:用真價重揀,以資本效率為最優目標。** 本檔只報數。

## 方法(凍結咗乜、變咗乜)

- **引擎全部 verbatim import**,一行都冇重寫,格間差異只來自 (b, Δ, mix, m):
  - `build_underlying`/`build_gates`/`simulate_unit_path`/`TD` ← `exp_leap_real_sweep.py`
  - `damp_iv`/`to_wslices`/`window_metrics`/`bench_metrics`/`cost_drag`/`CAPITAL` ← `exp_core_assembly_real.py`
  - `simulate_portfolio_topup`/`month_start_mask` ← `exp_core_topup.py`
  - `cap_eff`/`alpha_ci`(CE/CI 口徑)← `exp_core_topup_realcost.py`
- **Grid:** b∈{10,12,15,20}% × Δ∈{0.50,0.60,0.70,0.80} × mix∈{SPY+QQQ 50/50, QQQ-only, SPY-only} × cadence=C-monthly(凍結)= **48 格**,全部 m=1.15,base 同 damp=0.4 都跑。
- **深-ITM 誠實帶:** Δ∈{0.70,0.80} 用 m=1.15 係低估(07-09 spotcheck 實測 0.70Δ 隱含 m≈1.63 SPY / 1.26 QQQ),故此 24 個深-ITM 格另跑 m∈[1.3, 1.5](base+damp,FULL 窗口),擺喺對比旁包住,唔俾深-ITM 靠平價假設贏。
- **凍結:** cadence=C-monthly / cash=15% / 成本 0.5%/side / 純 200SMA GATED / roll@63td / T+1 收市 / CAPITAL=$500,000 / core 恆為 SPY / damp=0.4。
- **窗口(A4):** FULL(2001+,mix 共同窗口)主表 + H2 2011-2026 / 2016-2020 / 2021+ 子表(「2016+ 前後半」= 2016-2020 與 2021+)。全部 mix 都喺同一 2001+ 共同窗口跑,基準同為 SPY net-TR,48 格逐格可比。
- **資料尾巴凍結喺 2026-07-06:** live yfinance 無快取;凍結令 m 成為唯一報價變數,並令 b15/Δ0.50/50-50 呢格逐個數對返 realcost。
- **量度(A3):** 資本效率 CE = 年化 α(pp)÷ 中位 delta-notional 曝險(1.0x=100%NAV);絕對 PnL(CAGR、絕對 α)並列。CE 兩陷阱每表檢:(a) 細分母谷高比率 → 並列 DnMed 分母 + 標記下四分位格「⚠小分母」;(b) 蝕本比率倒轉 → α≤0 記 n/a-neg,不入排序。α 只喺全組合層(vs SPY net-TR),呢層用 alpha 係啱尺。
- **排序規則(睇數前登記):** 48 格按 damp×m=1.15 CE 由大到細排;新贏家 = 第 1 格;同舊贏家(b15/Δ0.50/50-50)正面對比;深-ITM 上榜即擺誠實帶喺旁。
- α 信賴區間 = 普通 OLS 標準誤(無 Newey-West),repo 一貫做法,照講明。
