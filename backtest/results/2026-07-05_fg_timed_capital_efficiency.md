## Question
CNN F&G 之前只測到「市場層貪婪 reward-exhaustion」(`2026-07-05_fg_vs_vix.md`)同「cross-sectional
spec tilt 唔成立」(`2026-07-05_fg_crosssectional.md` 已 retract)。真正問題:**用 F&G 做逆向擇時
——恐懼買入、貪婪走返現金——喺唔同股種/市值,資本效率(部署CAGR、條件Sharpe)贏唔贏 B&H?邊個
entry/exit 最抵?邊個籃最夾?**

## Method
- 規則:F&G < ENTRY {20,15,10,5} 入場(買恐懼);F&G > EXIT {75,80,85,90} 出場走現金(賣貪婪);
  T+1 執行,look-ahead-safe。16 個 entry×exit 組合。
- 量度(**資本效率**,per user 框架):**部署CAGR%**(只計落場日,年化)/ **條件Sharpe**(落場日)
  / **曝險%**。對埋每籃 B&H(CAGR/Sharpe/MaxDD)。總CAGR/全期Sharpe 屬 portfolio 階段,此處不作結。
- 覆蓋(照 [[backtest-testing-standard]]):**4 類別乾淨 ETF**——大盤指數(SPY/QQQ/SPMO)、細價股
  (IWM/IJR)、板塊ETF(11 SPDR)、Mag7;**+ 4 市值層個股籃**(micro<$300M / small$300M-2B /
  mid$2B-10B / large>$10B,2699 檔,等權日籃)。
- F&G 2011+,10bps/turnover。市值層個股日報酬 clip 到 [-0.5, 1.0] 殺 penny pct_change 爆炸。

## Conclusions
1. **F&G 逆向擇時喺全部乾淨籃嘅資本效率贏 B&H**——部署CAGR + 條件Sharpe 高過各籃 B&H,**甜區
   一致喺極端恐懼入場 `entry<5`**(大盤 32/1.21、細價 24/0.94、板塊 24/0.98、Mag7 48/1.30、
   large 37/1.29,全部條件Sharpe 高過 B&H)。緊 entry = 少而精、曝險低但落場賺率最高。
2. **活躍度唔算罕見**:放鬆 entry(<10/<15/<20)曝險 38/41/51%,即 1/3~1/2 時間有貨。
3. **large ≥ 大盤指數 > Mag7(擇時價值排序):**
   - large tier 條件Sharpe(timed 1.29)略高過 大盤(1.21),但**大盤指數更乾淨可交易(零
     survivorship、最流動、有期權=Karst tier-1),兩者實務上打和**。
   - **Mag7 排最後唔係質素差,係「F&G 逆向擇時 vs 動能股本質相沖」**:Mag7 timed 條件Sharpe 喺
     `<10`(1.07)、`<20`(0.98)**低過** B&H 1.17,只 `<5`(1.30)先贏。機制:Mag7 最好日子喺
     貪婪動能延續,F&G 貪婪一到就走 → 走漏 Mag7 最賺嗰啲日。逆向擇時只夾「會均值回歸」嘅籃。
4. **市值:large 最可信**(clean、tradeable);micro 表面 Sharpe 最高(1.37)但**紙上富貴**——
   survivorship 最重、clip 依賴(未 clip 前 +inf,B&H Sharpe 1.08 對 micro 本身唔合理 = 灌水訊號)、
   實質買唔到(價差闊、10bps 嚴重偏低)。small/mid 絕對數要打折,睇相對形狀(一樣係 <5 最好)。

## Caveats
- **資本效率階段結論**;總財富(idle cash)輸唔輸 B&H = portfolio 階段先計,此處不作結(per user)。
- **樣本 = 獨立入場 episode 數,唔係在場日數**(關鍵區分,實數 2011-2026 / 3876 交易日):
  | entry/exit | 獨立入場次數 | 曝險 | 平均每次 hold |
  |---|---|---|---|
  | <20/>75 | **15** | 51% | 131 日 |
  | <10/>75 | **10** | 38% | 146 日 |
  | <5/>75 | **7** | 22% | 121 日 |
  `entry<5` 一世得 **7 次入場**(2011-08、2014-10、2015-08、2018-12、2020-03、2022-05、2025-04);
  22% 曝險 = 7 條連續倉,倉內日日自相關 → **有效樣本 ≈ 7,唔係 ~850 在場日**。其中 **2020-03 COVID
  V-反彈一單 dominate 咗 `<5` 格嘅 Sharpe**。∴ `<5` 個數字最靚但 error bar 最闊、最靠 2020。
- **穩健 = 梯度,脆弱 = 峰值**:「entry 愈緊 → 部署效率愈高」呢個梯度喺**全部 8 個籃**單調成立
  (跨籃 corroboration,可信);但 `<5` 嘅**確切峰值**(1.21-1.37)靠 7 次 → 當「方向 + 上限」,
  唔好當精準數。**落地揀 `<10`(10 次入場、38% 曝險)做主,`<5` 當「極端加碼」訊號。**
- 市值層 survivorship(cache 只有可定價名 → 死咗嗰批跌出)+ clip 位置隨意 → 絕對數偏高,睇相對。
- 全部籃同時進出(F&G 市場層)→ 「揀邊籃」係另一問題,呢度只證「F&G 擇時本身有資本效率」。

## Implication for Karst
- **F&G 恐懼 = 資本有效嘅逆向部署計時器**,對「會均值回歸」嘅籃(大盤/large/板塊/細價)最夾;
  **落地以 `<10`(10 次入場、38% 曝險)做主門檻,`<5` 當「極端加碼」**(峰值靠 2020,唔賭單格)。
  **Mag7 等動能名唔好用 F&G 逆向擇時**(除非極端 <5)。
- tier-1(SPY/QQQ/SPMO)最適合落地(乾淨、有期權);大盤 F&G<10 = 加曝險/加 CSP-賣恐懼窗口。
- 呢個係 **risk knob / 部署計時器**,唔係 standalone alpha(同 [[regime-and-fear-greed-findings]]、
  [[tier1-metrics-decision]] 一致)。財富貢獻待 portfolio 階段接線後量。
