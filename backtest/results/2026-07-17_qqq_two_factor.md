# MAGS + SMH/SOXX 兩端可唔可以代表 QQQ?(+ SMH vs SOXX 對決)— 2026-07-17

**產物**:`backtest/experiments/exp_qqq_two_factor.py`(可重跑)
**數據**:backtest/data.py load()(yfinance,total-return adjusted);MAGS 上市限制共同樣本為 2023-04 至今(n=818)

## 問題

用戶問:科技軸兩端(Mag7 藍籌端 = MAGS、半導體端 = SOXX/SMH)合埋,係咪已經代表到 QQQ?
另問:半導體端載具 SMH 係咪好過 SOXX?

## 結果

### A. 兩端對 QQQ 嘅解釋力(日回報 OLS,2023-04+)

| 組合 | R² | 年化追蹤誤差 |
|---|---:|---:|
| 淨 MAGS | 0.815 | 8.6% |
| 淨 SMH | 0.800 | 8.9% |
| 淨 XLK(對照) | 0.931 | 5.2% |
| **MAGS + SOXX** | **0.940** | **4.9%** |
| MAGS + SMH | 0.934 | 5.1% |
| MAGS + SOXX + IGV | 0.958 | 4.1% |

**判詞**:兩端合埋解釋 QQQ 日波動 94%,好過 XLK 單獨(93%);加埋軟件(IGV)先去到 96%。**統計上「QQQ ≈ Mag7 端 + 半導體端」成立**——軸嘅兩端已經係成條軸嘅主要內容,剩返嗰 5-6% 係軟件/其他嘅殘餘。

### B. 但「可投資」版本會偏離 QQQ——而樣本內係偏離向上

限制權重加和=1(真金白銀揸兩隻 ETF):最佳配比 74% MAGS + 26% SOXX,R² 得 0.79、追蹤誤差 9.2%,而且樣本 3.2 年累計**跑贏 QQQ 約 +30 個百分點**(log)。原因:QQQ 有 55% 唔係呢兩端(份量被中間股稀釋),而樣本期兩端剛好都強過中間。**呢個 +30pp 係樣本期特定現象(AI 牛市兩端領漲),唔係恆常規律**——兩端集中 = 高 beta 表達,牛市放大、熊市一樣放大。

### C. SMH vs SOXX(2016+,n=2648)

| | CAGR | 年化波動 | MaxDD(log) |
|---|---:|---:|---:|
| SMH | +35.0% | 32.8% | -60.3% |
| SOXX | +32.8% | 33.9% | -61.2% |

相關性 0.988——**基本上係同一隻嘢**。SMH 歷史 CAGR 高 ~2.3pp、波動略低,來源係佢更集中(NVDA+TSM 佔三成幾,SOXX 冇 TSM 咁重)。呢個差距係「集中度賞金」,贏家持續先有;但作為半導體端載具,SMH 流動性更大、有 TSM,**揀 SMH 合理,差別唔關鍵**。

## 業務結論

1. 「QQQ = Mag7 端 + 半導體端(+少量軟件殘餘)」統計成立(R² 0.94)——支持將軸嘅兩端各自立 theme 做監察(mag7-hyperscaler + 半導體 cycle),兩個 theme 嘅 kill metrics 合埋就係 tier-1/2 核心倉嘅完整煙霧感應網。
2. 但「直接揸兩端代替 QQQ」係另一個決定:等於加 beta,唔係中性替代(樣本內 +30pp 係牛市放大效應嘅示範,反面就係熊市多跌)。核心倉繼續用 QQQ,兩端做傾斜工具。
3. 半導體端載具用 SMH(同 SOXX 相關 0.99,歷史略優,有 TSM)。

## 局限

- 共同樣本只有 3.2 年(MAGS 2023-04 上市),而且全程係 AI 牛市——R² 喺風格轉換期可能下降。
- 最佳配比(74/26)係樣本內事後最優,唔係事前可知。
- B 節嘅 +30pp 跑贏冇統計檢定,只作方向示範。
