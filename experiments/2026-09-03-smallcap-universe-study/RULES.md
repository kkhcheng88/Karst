# 判讀規則(跑數之前寫好)——KARST-162 小型股宇宙研究

日期:2026-09-03。本目錄只做**覆蓋率量度**,不建宇宙、不抓大量價格、不寫入 `data/`。

## 一、量什麼

KARST-160 的五年窗十倍股名單(138 家,`experiments/2026-09-02-tenbagger-scan/out/tenbagger_names.csv`
的 `horizon=5y` 行)。對每個候選宇宙定義 U,答一條問題:

> **若當年就有宇宙 U,這 138 家之中有多少家在自己的 t0(那個通往十倍的起點月底)已經在 U 之內?**

這個比例叫 **t0 覆蓋率**。

## 二、市值怎樣算(近似,三層來源,逐家標明用了哪層)

1. **panel**:`experiments/2026-09-02-tenbagger-scan/out/t0_cells.parquet` 的 `mcap` 欄
   (= 已還原拆股的收市價 × 已還原拆股的攤薄股數,證監會 XBRL,知情時點 `filed ≤ 月底`)。最準。
2. **panel_ffill**:同一家在 t0 之前最近一格的 `shares_adj`,乘以 t0 當日收市價;
   只准向前補(不准用未來股數),補的距離上限 24 個月。
3. **sec_frames**:證監會 XBRL frames API 的封面頁股數
   (`dei:EntityCommonStockSharesOutstanding`,每年 Q1 瞬時格),取 t0 當年或之前最近一年的值,
   乘以 t0 當日**未還原拆股**的價格。**這一層最粗**:封面頁股數是申報原值(未還原拆股),
   而倉內價格已還原,所以必須用未還原價格對數;倉內沒有未還原價格時,用拆股表
   (`experiments/2026-09-02-fourpiece-test/data/splits.parquet`)把還原價乘回去。
4. **未知**:三層都拿不到 → 不計入分子亦不計入分母,另行列出。

**報兩個數:下限(未知一律當作不在宇宙內)與上限(未知一律當作在宇宙內)。**
下限與上限之間的距離,就是這一節的不確定度。

## 三、候選宇宙定義(跑數前凍結)

市值門檻一律用**名義美元**,不作通脹調整(調整會令 2009 年的門檻與 2021 年不可比,
但不調整同樣有偏差;此處選不調整,並在報告聲明)。

| 代號 | 定義 | 備註 |
|---|---|---|
| **U0** | 現役宇宙:標普 500 歷史成分骨幹 + 2026 年補進的主題股(728 家) | 對照組;用 `in_index` 與宇宙分段欄近似 |
| **U1** | 羅素 2000 近似:t0 市值 3 億 – 50 億美元 | 成分歷史要付費,此處用市值帶近似,標明近似 |
| **U2** | 全美上市小型股:t0 市值 < 50 億美元(無下限) | 收微型股,家數最多 |
| **U3** | 自定義:t0 市值 2 億 – 100 億美元 | 上限放寬到中型股,下限擋殼股 |
| **U4** | U3 再加成交額門檻(日均成交額 ≥ 100 萬美元) | **倉內日線沒有成交量欄(D-131 已記)**,本輪量不到,標「未能驗證」 |

## 四、宇宙家數量級怎樣估

用證監會 XBRL frames API 的 `dei:EntityCommonStockSharesOutstanding`,逐年取 Q1 瞬時格,
數有多少個 CIK 有值。**這是「有申報封面頁股數的申報人」數目,不等於「美國上市公司」數目**
——它含基金、信託、外國申報人、未上市的申報人,亦漏掉不用 XBRL 申報的細公司。
所以它是**上限性質的量級參考**,不是宇宙家數本身;報告必須這樣寫。

## 五、明知的偏差(讀數之前先看)

1. **138 家本身來自 728 家的宇宙**,而 728 家全部活到今日。所以「覆蓋率」答的是
   「一個小型股宇宙能撈到多少**我們看得見的**十倍股」,**不是**「能撈到多少全部十倍股」。
   真正的小型股宇宙會多出大量今日已除牌的公司,分子分母兩邊都會變,方向未知。
2. **t0 是事後揀出來的最佳起點**(通往十倍的那一格)。用它算市值,等於問
   「十倍股起飛那一刻有多大」,不是「隨機一個月它有多大」。
3. **市值門檻不作通脹調整**,見第三節。
4. **U4 量不到**,見第三節。
