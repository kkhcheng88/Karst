## 零、本票答什麼

D-160 依 KARST-173 在**小型股名單 v1 + 面板 v3 + 新價格庫**上量到同一件事「不存在 / 量不出」。

兩次結果相反,但**對照組、單位、量度、樣本四樣同時變了**,所以編表人拒絕推翻 D-155,做法對。
本票只答一條:

> **KARST-173 量不到關係,是由哪一樣變化造成的?**

做法是四步隔離,**每步只變一樣**。本票不裁 D-155,只把主因指出來。

## 二、量度口徑(照 KARST-166 一字不改,四步共用)

| 項 | 定義 |
|---|---|
| **S1 淨現金對市值** | `(cash − total_debt) ÷ mcap` |
| **總債務** | `lt_debt + st_debt`,`st_debt` 缺 → 當 0(照 KARST-166 判準第三節寫死) |
| **缺值** | `lt_debt` 缺、`cash` 缺、`mcap` 缺 → S1 缺值(不填零) |
| **AUC** | 秩 AUC,直接 import `features_t0.auc`;x = S1、y = `is10x`,缺值剔除 |
| **逐年加權 AUC** | 按 t0 年份分層,某年**十倍格 ≥ 5** 且兩類都有格才入數,以該年格數加權平均 |
| **T1 門檻** | `S1 > 0`(淨現金為正);不合者當被剔走 |
| **誤殺率** | 被剔走的十倍格 ÷ 有齊欄位的十倍格 |

**判詞規則(照 KARST-166 第四節,一字不改):**

| 情況 | 判詞 |
|---|---|
| 可算格 ≥ 1,000 **且** 可算十倍格 ≥ 50 **且** \|逐年加權 AUC − 0.5\| ≥ **0.05** **且** 全樣本與逐年加權兩個 AUC 同在 0.5 的同一側 | **存在**(附方向) |
| 可算格 ≥ 1,000 且 可算十倍格 ≥ 50 但 \|逐年加權 AUC − 0.5\| < 0.05 | **不存在** |
| 可算格 < 1,000 或 可算十倍格 < 50,或兩個 AUC 分處 0.5 兩側 | **量不出** |

## 三、四步(每步只變一樣)

### ① 基準(重現 KARST-166)

直接沿用 `safety_features.py` 的 S1 路徑,一格不改。
**停手線:** 逐年加權 AUC 必須落在 **0.648 ± 0.02**(即 0.628 – 0.668)。
落不到就**停下**,不跑②③④,票上留言報主 agent,說明差在哪。

### ② 只換面板 v3

- 格、`is10x`、t0 一律照①;**市值分母亦照①**(舊面板 v2 的攤薄股數 × 拆股因子 × 舊調整價)。
- 只把分子換掉:`cash` 與 `total_debt` 改由面板 v3 取,規則 `filed_date ≤ t0` 的最後一列
  (面板 v3 是季度、以 `entity_id` 為鍵;由 `panel_monthly_v2.cik` 補零十位接回)。
- **②附(對照,不算主步)**:連市值分母的股數也換成面板 v3 的 `shares_outstanding`
  (申報原值 × t0 之後累積拆股因子)。出這一格是為了分開「分子換了」與「分母換了」兩件事。

### ③ 只換宇宙

- 面板、口徑、價格、格全部照①,**只把樣本收窄**到:該代號在 t0 接得回的 `entity_id`
  在 `universe_smallcap_v1` 之內的格。
- 接法照 KARST-173 判準第三節(代號時段覆蓋 t0;多段命中用同實體別名閘挑一);
  接不回的格不入分子亦不入分母,逐個記數。
- **限制(必須寫入報告)**:面板 v2 只覆蓋舊宇宙,所以這一步量到的是「舊宇宙之中屬於
  小型股名單那一批」,**不是**在 3,117 家上重建一次。它答的是「換一個較細的樣本會不會
  令關係消失」,不是「新宇宙全體」。新宇宙全體由④答。

### ④ 全換

- 宇宙 = `universe_smallcap_v1` 的 3,117 個 `entity_id`。
- 格 = (實體, 月底 t0, 五年窗),照 KARST-160 RULES 第二節重建:
  - t0 = 2009-01 至 2021-09 每個月最後一個有價交易日(完整窗要求 t0 + 5 曆年 ≤ 2026-09-01);
  - 價格取價格庫 `series_role == 'primary'` 的列;
  - **倍數 = 窗內(t0 之後至 t0 + 5 曆年)最高 `adj_close` ÷ t0 `adj_close`**,`≥ 10` 為 `is10x`。
    用 `adj_close` 是為了與①的格定義同一把尺(舊價格檔是 `auto_adjust=true`);
    D-160 第 4 條「不直接用 `adj_close`」針對的是水平量,本票的水平量(市值)照下一行用 `close`。
  - t0 無價、窗不完整、窗內無有效價 → 該格不入。
- 市值 `mcap(t0)` = `close(t0)` × `shares_outstanding`(`filed_date ≤ t0` 最後一列)
  × t0 之後累積拆股因子(照 KARST-173 判準第四節)。
  拆股表不覆蓋該代號 → 因子當 1,標 `split_table_absent`;
  `CPWR` / `EP` / `PARA` 三個代號市值一律缺值。
- `cash` 與 `total_debt` 由面板 v3 取,`filed_date ≤ t0` 的最後一列。

### 兩步共用的貨幣規則(只適用於用面板 v3 的②與④)

面板 v3 不做貨幣換算(KARST-172 誠實聲明第 3 條)。S1 是「本國貨幣淨現金 ÷ 美元市值」,
對非美元申報人是錯的。所以:

- **主口徑**:面板列的 `currency != "USD"` → S1 記缺值,原因 `non_usd`;
- 另報一個**不設此限**的對照 AUC,證明這條規則不是結論的來源。

## 四、總債務補算(先答的那一條)

面板 v3 的 `total_debt` 定義是 `lt_debt + st_debt`(`st_debt` 缺當 0),而且
**`lt_debt` 缺就整格缺**(`missing_reason = tag_absent`)——所以覆蓋率 41.4% 完全由 `lt_debt` 決定。

補算規則(有標籤才補,補不到記 `tag_absent`,一格都不填零):

| 情況 | `total_debt_filled` | 標記 |
|---|---|---|
| `lt_debt` 有值 | `lt_debt + (st_debt 或 0)` | `orig` |
| `lt_debt` 缺、`st_debt` 有值 | `st_debt` | `filled_st_only` |
| 兩者皆缺 | 缺值 | `tag_absent` |

**租賃負債補不到。** 面板 v3 沒有租賃負債欄,原料層沒有這個標籤,要補得擴標籤表重建面板;
本票不新抓、不改面板,所以這一條一律記 `tag_absent`,並在報告寫明它是下一張票的事。

出兩張表:

1. **分層缺失表**:按 `entities.parquet` 的 `approx_mcap_usd` 分四層(> 50 億 / 5–50 億 /
   < 5 億 / 無市值,照 KARST-172 第三節的線),列每層家數、缺總債務家數、可補家數、補不到家數;
   以每家**最新一期**計,另出一版以全部面板列計。
2. **補前後覆蓋率**:兩個口徑各報一個百分比。

**四步一律用補後口徑**(即 `total_debt_filled`),**並附補前口徑的對照 AUC**。
①③用面板 v2,面板 v2 的 `total_debt` 由 `lt_debt + panel_extra_v1.st_debt` 組成,
同樣照上表補(`lt_debt` 缺但 `st_debt` 有值就補),補前對照即 KARST-166 原口徑。

## 五、主因怎樣判(先寫死)

四步的逐年加權 AUC 並列。由①起逐步看:

- **第一個令逐年加權 AUC 跌穿 0.55**(即偏離 0.5 少於 0.05,照第二節的線)**的那一步,
  就是主因。**
- 兩步都跌穿 → 兩者並列為主因,各報自己那一步的跌幅(相對上一步)。
- 四步都不跌穿 → 主因判「**量不出**」,並寫明 KARST-173 量不到關係不由這三樣變化任何一樣
  單獨造成(可能來自它用的是家數口徑而非格級口徑,那是另一張票的事)。
- 任何一步落入「量不出」(可算格 < 1,000 或十倍格 < 50)→ 該步不參與主因判定,
  只報覆蓋不足,並寫明它擋住了哪一段推論。

**AUC 的差不是統計檢定。** 0.05 這條線是 KARST-166 事先講定的實用線,本票原樣沿用,
跑數之後不動。

## 七、誠實聲明(報告首段必寫)

1. **倖存者口徑。** 舊 728 家全部活到今日;小型股名單 v1 來自今日仍在申報的公司,
   中途除牌、被併購、私有化的一家都不在。任何比率都系統性偏樂觀,幅度**量不出**。
2. **可得日是申報日。** 四步一律用 `filed ≤ t0`;但面板 v3 每格放的是**首次申報值**,
   面板 v2 的部分欄放的是**最新重述值**——②相對①的差,有一部分來自這個口徑差,
   本票分不開它與「換了資料來源」兩件事,只能寫明。
3. **t0 是事後揀出來的最佳起點**(通往十倍的那一格),不是隨機一個月。這是盤點,不是預測。
4. **市值是近似入位。** ①②沿用 KARST-166 的做法(已除息調整的價 × 拆股還原後的股數),
   這對派息股系統性低估市值,是繼承下來的缺陷,本票不修;
   ④用封面頁股數(季度快照)乘 `close` 乘一張只覆蓋舊 728 家的拆股表,近似度更差。
5. **`adj_close` 不是不變量**(D-160 第 4 條):④的倍數綁定價格庫 2026-09-03 這一份,
   換一個抓取日重跑會有細微差別。
6. **③不是新宇宙全體。** 見第三節③的限制。
7. **`total_debt` 覆蓋在原料層就是低的**,補算之後仍然補不到租賃負債;
   「沒有這一格」與「零負債」在原料上分不開,本票不把缺當零。

## 九、增補(2026-09-03,四步跑完之後加)

**原判準原文一字未改;本節只加一項附錄診斷,不改任何門檻、不改任何判詞。**

原因:四步跑完,逐年加權 AUC 全部落在 0.58 – 0.77 之間,**一步都沒有跌穿 0.55**,
所以按第五節的規則,主因在四步的框架之內判「量不出」。這樣收檔答不到票面問的
「KARST-173 量到不存在的主因是什麼」——只排除了三個嫌疑,沒有指出真兇。

所以加一項**附錄診斷**(`diag_n1.py`),在**第④步同一批格**上換兩樣東西,各自單獨看:

1. **口徑**:把 S1 的 N2 口徑(`現金 − 總債務`)換成 KARST-173 票面的 N1 口徑
   (`現金 + 短投 − 負債總額`),其餘不變;
2. **量度**:把「格級連續值的 AUC」換成「二元符號的比率」,再把格塌成公司
   (每家取最早一個可算的 t0 作代表,十倍公司對非十倍公司兩組)。

**這一節不產生存在性判詞**,只報數,用來指出四步之外還有哪一樣在動。
第五節的主因判定規則維持原樣,不因這一節改寫。
