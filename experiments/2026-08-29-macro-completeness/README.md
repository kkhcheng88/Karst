# 宏觀序列齊全度:以現有快照重新核對一次(KARST-061)

> 跑法(倉根目錄):
> ```
> set PYTHONUTF8=1
> python experiments/2026-08-29-macro-completeness/audit_macro_snapshots.py ^
>     --max-stale-days 3 --max-missing-ratio 0.01
> ```
> 本目錄不寫庫、不凍快照、不抓數:只由磁碟上已凍結的讀數重算,只落檔。

## 一、一句話

**新做的這道關,拿去核換來源之前那份快照,一次就抓到了 ^VIX3M 停更那 28 個交易日;
拿去核現役那份,十四條序列連最嚴的門檻(0 日、0%)都一條都不報。**

抓得到已知的那一件、又不誤報齊全的那十三條——這兩件同時成立,這道關才算做得到事。

## 二、核對的是什麼

以前只數三個數:一條序列**真有讀數**幾多日、**前值填補**幾多日、**留空**幾多日
(快照說明檔第七節)。^VIX3M 那件事之所以 28 個交易日無人察覺,不是因為那張表錯,
是因為**那張表答不到「這條數夠不夠新」**——停更之後每一日都算「留空」,與中段有洞的
序列長得一模一樣,而且頭三日還會被前值填補接住,看上去更加正常。

本票加的是這一格:

| 新的一格 | 它答的問題 |
|---|---|
| `stale_days` 尾段落後 | 最後一個**真讀數**之後,主日曆上還剩幾多個交易日。前值填補與留空都不算真讀數,所以填補那三日遮不住它。 |
| `missing_ratio` 留空比例 | 整段窗口留空的日數佔主日曆幾多。停更以外的洞由這一格接住。 |

兩個門檻**都是參數、都沒有預設值**:「幾多日算停更」不是數據的性質,是對這條訊號的
容忍度——期貨轉倉那幾日、外匯假期那幾日,容忍度本來就與指數不同。

## 三、結果

門檻 **3 個交易日 / 1%**(落檔 `summary.json`;`嚴格門檻/` 那一份是 0 日 / 0%):

| 快照 | 主日曆 | 序列 | 3 日 / 1% | 0 日 / 0% |
|---|---|---|---|---|
| `2026-08-28-dc2d9f1a1778`(現役) | 2015-01-02 ~ 2026-08-26,2,929 個交易日 | 14 | **零警報** | **零警報** |
| `2026-08-28-810facb50382`(換來源之前) | 同上 | 14 | **1 條:`VIX_3M`** | **1 條:`VIX_3M`** |

被抓到那一條,原文照錄:

> `VIX_3M`:最後一個真讀數在 2026-07-17,比主日曆尾日 2026-08-26 短 **28 個交易日**
> (門檻 3 日);留空 25 日,佔主日曆 0.85%(門檻 0.00%)

**28 這個數與 KARST-058 當日人手數出來的完全一樣**(真有讀數 2,901 日、前值填補 3 日、
留空 25 日、最後讀數 2026-07-17)。分別只在於:當日那個數要有人去翻說明檔第七節、
再自己對住主日曆數一次才得出來;自此凍結那一刻就會講出來。

## 四、「不誤報」是怎樣驗的

現役那份的十四條,連 **0 日 / 0%** 這一套都一條都不報。當中有三條其實**有前值填補**:

| 序列 | 真有讀數 | 前值填補 | 留空 | 尾段落後 |
|---|---|---|---|---|
| `FF_FUTURE`(聯邦基金期貨) | 2,927 | 2 | 0 | **0** |
| `OIL_WTI`(WTI 原油期貨) | 2,927 | 2 | 0 | **0** |
| `USD_INDEX`(美元指數) | 2,927 | 2 | 0 | **0** |
| `UST_3M` / `UST_5Y` / `UST_10Y` / `UST_30Y` | 2,928 | 1 | 0 | **0** |

期貨與外匯的假期本來就與美股不同,中段少一兩日是**正常的**,不是停更。這道關分得開
兩者:它數的是**尾段**,不是總共有幾多日填補過——所以這七條一條都不報。

反過來也一樣要成立:一條序列尾段只停兩日(仍在前值填補上限三日之內),留空欄會是
**零**、舊那張表一格異樣都看不出,而尾段落後那一格照樣會是 2。這一條在
`tests/test_macro_completeness.py::test_filled_days_do_not_hide_a_stale_tail` 驗得到。

## 六、這道關管不到的事

它核的是**已經抓回來的讀數對不對得住主日曆**,不是「來源本身有沒有更好的一家」。
名冊上其餘十二條序列仍然只靠 yfinance 這一層(假設 A-008 講的正是這件事);這道關
令它們再停更時**第一時間有人知**,但不會自動換來源——換來源仍然要像 KARST-058 那樣
另外開一票。
