## 二、觀察值過濾(照 KARST-146 `RULES.md` 第三、六節)

- 表格:`10-K`、`10-Q`、`20-F`、`40-F`,以及它們的 `/A`。
- 分類體系:`us-gaap`、`ifrs-full`。單位:`USD`。
- 欄位四個:`revenue`、`net_income`、`cfo`(流量,跨度 Q 80–100 日 / H 170–190 日 /
  FY 330–400 日,其餘跨度丟棄)、`assets`(存量,instant)。
- 標籤回退表照 `RULES.md` 第四節。**分組以「同一個標籤」為準**,所以公司中途換標籤
  (例如 2018 年 `SalesRevenueNet` 換成 `RevenueFromContractWithCustomer…`)
  不會被誤當成一次修訂。代價是「換標籤同時改數」那一類會漏掉——寧可漏,不可假。

## 三、修訂事件定義(跑數前寫死)

分組鍵 = (代號, 標籤, `start`, `end`)。組內把 (`filed`, `val`) 去重後按 `filed` 升序。

- **首版** v0 = 最早 `filed` 的非 `/A` 觀察值(全部都是 `/A` 時取最早那個);其申報日記為 f0。
- 由 f0 之後逐個看下去,**第一個**同時滿足下列兩條的申報日 f1 就是事件日:
  - 相對門檻:|v1 − v0| / |v0| > τ,τ 取 **0.02** 與 **0.05** 兩檔,分開報。
  - 絕對下限:|v1 − v0| ≥ **1,000,000 美元**(擋四捨五入雜訊)。
- 每一組最多產生**一宗**事件(第一次跨門檻那一次),因為市場第一次看見就是那一日。
- 方向:v1 < v0 為**向下**,v1 > v0 為**向上**。
- **事件時點 = f1,即修訂版的申報日**(那一日市場才可能知道)。
- **進場 = f1 之後第一個月底**(嚴格大於 f1 的第一個日曆月底)。

## 四、排除規則(每一條都要數出來)

| 編號 | 規則 | 理由 |
|---|---|---|
| E1 | 股數類欄位不入測試 | 四個欄位全部是美元總額,拆股不會改動它們;`diluted_shares` 明文不做(KARST-148 拆股陷阱守則) |
| E2 | (f0, f1] 之間有拆股,且 v1/v0 與該累計拆股比率 r(或 1/r)相差在 1% 以內 → 排除 | 機械性的拆股追溯調整,不是修訂 |
| E3 | 首版 |v0| < 1,000,000 美元 → 排除 | 分母太小,百分比無意義 |
| E4 | 代號在日收盤檔中沒有價格序列 → 排除出回報測試 | 有帳目無價格那一批,數出來作誠實聲明 |
| E5 | 代號沒有板塊 ETF 對照 → 排除出殘餘回報測試 | 沒有板塊基準就砌不到配對組 |
| E6 | 進場月底或到期月底沒有價格 → 該持有期丟棄 | 逐個持有期分別計,不整宗丟 |

## 五、分開標記(不是排除,除非下面寫明)

| 旗標 | 定義 | 處理 |
|---|---|---|
| F1 `via_amendment` | 那個修訂值第一次出現在 `/A` 修訂申報 | **由主臂(靜默)剔走**,另行分開報——`/A` 有廣播,不算靜默 |
| F2 `near_8k_402` | 同一家公司在 [f1−90 日, f1+90 日] 內申報過帶 Item 4.02(不可依賴)的 8-K | **由主臂剔走**,另行分開報——正式重述有廣播 |
| F3 `standard_transition` | 被修訂那一期的 `end` 落在 2018 或 2019 年(ASC 606 / ASC 842 轉換) | **留在主臂**,同時另出一欄「剔走轉換年之後」作穩健性對照 |

**主臂(靜默修訂事件集)** = 通過 E1–E5,且 F1、F2 皆為否。

## 六、回報量度

- 持有期 H ∈ {3, 6, 12} 個月,由進場月底起計。
- 原始回報 = 收盤(進場月底 + H 個月,取不晚於該月底的最後一個交易日) ÷ 收盤(進場月底) − 1。
- 殘餘回報兩種,兩種都報:
  - 對 SPY:r_股 − r_SPY(同一個窗口)。
  - 對板塊 ETF:r_股 − r_板塊ETF(同一個窗口)。
- 判準用的那一格是**對板塊 ETF 的殘餘回報**(配對組已經同板塊同月,兩者一致)。

## 七、配對法

- 每一宗事件的對照組 = 同一個板塊 ETF、同一個進場月底、有價格、而且**在該月底之前
  十二個月內沒有任何修訂事件**(任何欄位、任何方向、任何門檻檔)的全部公司,等權。
- 配對差 d_i = 該事件的殘餘回報 − 其對照組同窗口殘餘回報的等權平均。
- 對照組為空的事件丟棄(數出來)。

## 八、顯著性(聚類 t)

- 統計量對象:逐事件的配對差 d_i。
- 聚類單位:**板塊 × 進場月份**(同一個板塊同一個月的事件算一群)。
- 聚類穩健標準誤:SE = sqrt( Σ_c ( Σ_{i∈c} (d_i − d̄) )² ) / N,N 為事件數;t = d̄ / SE。
- 報 N、群數、d̄、t。

## 九、分段

以**事件日**分兩段:2009-01-01 – 2016-12-31、2017-01-01 – 2026-08-31。

## 十、存在性判詞(跑數前寫死,不產生及格)

判準只看**一格**:主臂靜默、**向下**、τ = 0.02、**6 個月**、對板塊 ETF 的殘餘回報配對差。
其餘所有格(向上、另一檔門檻、3/12 個月、對 SPY)一律照報,但**不參與判詞**。

- **量不出**(優先於其餘兩個判詞):主臂靜默向下事件數 < **200 宗**。
  事件不夠就寫「量不出」,**不准寫「不存在」**。
- **存在**:同時成立 ——
  1. d̄ < 0 且聚類 t ≤ −2.0;
  2. 2009–2016 與 2017–2026 兩段的 d̄ 同為負數(方向一致)。
- **不存在**:|d̄| 換算成年化 < 1 個百分點,**且** |t| < 1,**且** N ≥ 200。
- 其餘全部情況 = **量不出**(證據不足以判方向)。

不產生「及格」:本票是探索票,不出任何可以拿去實作的參數組合;冠軍格不是結論。

## 十二、誠實聲明(必入報告首段)

1. **倖存者**:面板 718 家之中 84 家有帳目無價格(81 家已除牌)。最愛改數的公司很可能
   正是走了那批,所以效應**可能被低估**;方向對本測試有利,但幅度量不到。
2. **知情時點靠 `filed` 欄**:事件日完全建基於證監會 companyfacts 的 `filed`。若那一欄有
   系統性誤差,事件時點會偏,整個測試的成績跟著偏。
3. **事件數可能少**:低頻事件。少於 200 宗一律寫「量不出」,不寫「不存在」。
4. **修訂大部分是良性的**:重分類、四捨五入口徑改變、比較欄重貼,都會落入「修訂」這個
   籃子。雜訊很大,真訊號被稀釋。
