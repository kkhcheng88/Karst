# 2026-08-28 宏觀訊號接入與宏觀驅動器(KARST-040)

**一句話結論:把美債孳息曲線的斜度變化拿來當移權依據,最優格連成本後對 SPY 年化超額
+4.66%,首次越過價格驅動器的最好成績(相對強弱 +4.17%),而且 2015–2019 / 2020–2022 /
2023–2026 三段全部為正——但它是孤峰(鄰域平均只有 +1.21%),回撤 −33.8% 比相對強弱的
−18.9% 差一大截。整個計劃至今唯一一個平原出現在 VIX 期限結構開關身上,只是它的超額
(+0.58%)還低過固定權重 95/5 的 +1.20%。所以宏觀訊號證明了「有相關、抓得到、入得到數據」,
但還沒有證明「值得換掉現有的價格驅動器」。**

- 宏觀快照:`2026-08-28-3b2de5c59740`(14 條序列,41,006 行,來源 `yfinance-macro`)

## 1. 掃的是什麼

用戶 2026-08-28 裁定的第一層四件事,全部接進來了,而且**一分錢、一把 API 鑰匙都沒有用**:

| 要的東西 | 用了什麼 | 代價 |
|---|---|---|
| VIX 與期限結構 | `^VIX`、`^VIX3M` | `^VIX3M` 的歷史尾段停在 2026-07-17,主日曆上尾段缺 25 日 |
| 信用利差 | `HYG` / `LQD` 收市價之比 | FRED 的高收益 OAS 要鑰匙,故用兩隻 ETF 的比值代替;比值不是利差本身,只同向 |
| 美債息率與曲線斜度 | `^IRX`、`^FVX`、`^TNX`、`^TYX`;斜度 = 10 年 − 3 個月 | 3 個月替代 2 年,故斜度的**絕對水位**與市場慣講的 10y−2y 不同,方向一致 |
| 聯邦基金利率預期 | `ZQ=F` 聯邦基金期貨 | **FedWatch 本身不免費**;FRED 的 DFF 免費但要鑰匙。期貨報價是市場對同一件事的定價,免費且即日可得 |

第二層(`DX-Y.NYB`、`CL=F`、`IWF`/`IWD`、`IWM`)照裁定**只入成績表作對照,不開參數格**。

六個宏觀驅動器,每個 5 個門檻或回望 × 3 個傾斜幅度 × 2 個換手節奏 = 30 格,共 180 格。
**所有門檻與回望期都是掃描參數,沒有預設值**——沒有一個數字是我挑的。

| 驅動器 | 用到的序列 | 移權邏輯 |
|---|---|---|
| VIX 水平開關 | VIX | 高於門檻 = 恐慌,傾向低波與質量;低於門檻傾向動能 |
| VIX 期限結構開關 | VIX、VIX_3M | 3 個月 / 即月之比低過門檻(曲線倒掛)= 恐慌 |
| 信用利差變化方向 | HY_ETF、IG_ETF | 比值在回望期內轉弱 = 利差擴闊,轉防守 |
| 曲線斜度變化方向 | UST_10Y、UST_3M | 斜度在回望期內變陡傾向價值,變平傾向低波 |
| 10 年息率趨勢 | UST_10Y | 息率升傾向價值,息率跌傾向低波 |
| 聯邦基金利率預期方向 | FF_FUTURE | 期貨價跌(隱含利率升)傾向價值,反之傾向低波 |

## 4. 判讀

### 4.1 曲線斜度是目前最好的一格,但它是孤峰

`lookback_days=20、tilt=1、cadence=monthly` → +4.66%,`run-a3d8dd0ad9cd2b78`。
鄰域平均只有 +1.21%,判為孤峰——換言之,如果當初回望期揀了 10 日或 40 日而不是 20 日,
拿到的會是完全不同的數字。**但這個驅動器的鄰域本身不差**:鄰域平均最高那一格
(`lookback_days=40、tilt=1、monthly`,`run-a04d56e8839516ac`)仍有 +3.03%、鄰域平均
+1.75%,已經高過固定權重 95/5 的 +1.20%,而且三段皆正。所以「揀錯格會蝕」在這裡的
意思是「賺少了」,不是「反轉蝕錢」——這與 KARST-036 那兩個價格孤峰不同。

代價寫清楚:回撤 −33.8%(相對強弱 −18.9%)、換手 5.72(相對強弱 2.51)。**用回撤與
換手換來的 0.49pp**,以現時證據不足以判它勝出。

### 4.2 全計劃第一個平原,出在 VIX 期限結構

KARST-036 掃四個價格驅動器、KARST-043 加密重掃到 60 格,**平原數目都是零**。這次
VIX 期限結構開關的 30 格裡出了 1 個平原(`threshold=1.1、tilt=1、monthly`,
`run-c7b65b53780666f0`):+0.58%,鄰域平均 +0.29%,全期只做 68 筆交易、換手 0.33。

值得記住的是它**為什麼**平:這個驅動器一年只講幾次話(VIX 曲線倒掛不常見),其餘時間
維持基準權重,所以參數郁一格,結果也只郁一點點。**穩健是因為它做得少。** 它的超額低過
固定權重 95/5,所以現階段的用途是「一個講得出理由的防守開關」,不是「一個可以自己上場
的策略」。

### 4.3 信用利差是唯一輸錢的,而且原因可能出在替代品

用 HYG/LQD 比值代替真正的高收益 OAS,最優格 −0.56%、鄰域平均 −2.11%,全格 30 個一致地差。
兩隻 ETF 的比值同時混入了存續期差異與流動性溢價,不是乾淨的信用訊號。**要判信用利差
本身沒用,現有證據不足**——先判的是這個替代品沒用。

### 4.4 第二層序列的相關度(只作對照,不開格)

以「動能減低波的月度變化」為參照:成長 ETF +0.501、小型股 +0.371、價值 ETF +0.195、
油價 −0.021、美元指數 −0.084。成長與小型股的相關度最高,但兩者都是股票價格,與因子
輪動同源,**不算獨立資訊**;真正外生的美元與油價幾乎不相關。這支持一件事:宏觀訊號
之中,**利率一族才是與因子輪動有關係的那一族**,恐慌指標其次,商品與匯率暫時看不到。

## 5. 外部數據(全部免費、無鑰匙、收市後可得)

| 序列 | 來源 | 免費 | 知情時間 |
|---|---|---|---|
| VIX、VIX_3M | yfinance `^VIX`、`^VIX3M` | 是 | 收市後可得 |
| HY_ETF、IG_ETF | yfinance `HYG`、`LQD` | 是 | 收市後可得 |
| UST_3M/5Y/10Y/30Y | yfinance `^IRX`、`^FVX`、`^TNX`、`^TYX` | 是 | 收市後可得 |
| FF_FUTURE | yfinance `ZQ=F` | 是 | 收市後可得 |

**知情時間處置**:宏觀序列一律當收市後才知情,所以決策日只看得到**當日收市及以前**的
讀數,可執行點是下一根可交易 bar 的開市(照 D-021)。這一條寫在 `karst/data/macro.py`
的 `MACRO_INFORMED_POLICY`,並隨每份宏觀快照寫入 manifest。

**非可投資序列處置**:VIX 這類序列沒有 CIK、不可買賣,不入實體表。宏觀序列自成一種快照
(`data/macro_snapshots/<編號>/`),以**序列代號**為主鍵,經 `store.register_snapshot`
以來源 `yfinance-macro` 登記,拿到與價格快照同一套編號、同樣可引用。因為宏觀代號從來
不進價格面板,「不小心持有 VIX」在結構上寫不出來,不是靠紀律避免。

**缺數處置**:對齊主日曆後最多前填 3 日,超過就留空;驅動器見到空值即拋
`InsufficientHistory`,由排程層記為數據不足並沿用熱身權重——**不當零、不當上次的數**。
`^VIX3M` 尾段 25 日缺數就是這樣處理的。

## 9. 未解與風險

1. **+0.49pp 買不到結論。** 曲線斜度贏相對強弱 0.49pp,但輸回撤 15pp、換手多一倍。
   以現有證據不能說宏觀驅動器應該取代價格驅動器;它證明的是「利率資訊有增量」。
2. **六個驅動器裡五個是孤峰。** 與價格驅動器同一個病。KARST-047 正在改的軸向平原判讀
   落地之後,這批格要重判一次——現在的「孤峰」是用舊判讀出的。
3. **信用利差用了替代品,結論只及於替代品。** 要判信用利差本身,需要真正的 OAS,而
   那要一把 FRED 鑰匙。
4. **`^VIX3M` 尾段停在 2026-07-17。** 期限結構開關在最後 25 個交易日沒有訊號,沿用熱身
   權重。若這條序列長期不更新,期限結構驅動器要換來源。
5. **利率序列與 2015–2026 這一段的宏觀環境高度綁定**:期內經歷一次零利率、一次急速加息、
   一次倒掛。曲線斜度的超額有多少來自「這十年剛好利率大起大落」,現有分段還答不到。
6. **宏觀序列沒有跨來源覆核。** 全部來自 yfinance 一家;抓錯一格不會有第二家對得出來。
