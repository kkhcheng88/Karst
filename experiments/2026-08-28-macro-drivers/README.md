## 1. 掃的是什麼

用戶 2026-08-28 裁定的第一層四件事,全部接進來了,而且**一分錢、一把 API 鑰匙都沒有用**:

第二層(`DX-Y.NYB`、`CL=F`、`IWF`/`IWD`、`IWM`)照裁定**只入成績表作對照,不開參數格**。

六個宏觀驅動器,每個 5 個門檻或回望 × 3 個傾斜幅度 × 2 個換手節奏 = 30 格,共 180 格。
**所有門檻與回望期都是掃描參數,沒有預設值**——沒有一個數字是我挑的。

| 驅動器 | 用到的序列 | 移權邏輯 |
|---|---|---|
| VIX 水平開關 | VIX | 高於門檻 = 恐慌,傾向低波與質量;低於門檻傾向動能 |
| VIX 期限結構開關 | VIX、VIX_3M | 3 個月 / 即月之比低過門檻(曲線倒掛)= 恐慌 |

| 10 年息率趨勢 | UST_10Y | 息率升傾向價值,息率跌傾向低波 |
| 聯邦基金利率預期方向 | FF_FUTURE | 期貨價跌(隱含利率升)傾向價值,反之傾向低波 |

## 4. 判讀

### 4.1 曲線斜度是目前最好的一格,但它是孤峰

`lookback_days=20、tilt=1、cadence=monthly` → +5.37%,`run-aa8a7f812b7ad0d7`。
鄰域平均 +2.89%,判為孤峰——換言之,如果當初回望期揀了 10 日或 40 日而不是 20 日,
拿到的會是完全不同的數字。**但這個驅動器的鄰域本身不差**:鄰域平均最高那一格
(`lookback_days=40、tilt=1、monthly`,`run-2c69e99a5dc9ca78`)仍有 +3.54%、鄰域平均
+3.35%,已經高過固定權重 95/5 的 +1.21%,而且三段皆正。所以「揀錯格會蝕」在這裡的
意思是「賺少了」,不是「反轉蝕錢」——這與 KARST-036 那兩個價格孤峰不同。

代價寫清楚:回撤 −33.7%(相對強弱 −18.8%)、換手 5.74(相對強弱 2.51)。**用回撤與
換手換來的 0.88pp**,以現時證據不足以判它勝出。

### 4.2 當日那片「平原」,按軸型判讀是一條山脊

KARST-036 掃四個價格驅動器、KARST-043 加密重掃到 60 格,**平原數目都是零**。這次
六個宏觀驅動器 180 格,**平原同樣是零**:當日按舊口徑判出來的那一格平原
(`threshold=1.1、tilt=1、monthly`,`run-5e256f3ce1111a78`)按 KARST-047/048 的軸型判讀
是一條**山脊**——沿住門檻與押注比重站得住,換去季度那一層就跌穿高地門檻。逐格對照見
[`../2026-08-28-macro-rejudge/README.md`](../2026-08-28-macro-rejudge/README.md)。

那一格本身:+0.63%,鄰域平均 +0.43%,全期換手只有 0.33 轉。單點最優其實在隔鄰
(`threshold=1.05、tilt=1、monthly`,`run-952ddfbebb5e046b`):+0.64%、換手 0.45,判普通;
兩格只差 0.0001,屬於貼身並列。

值得記住的是它**為什麼**站得住:這個驅動器一年只講幾次話(VIX 曲線倒掛不常見),其餘
時間維持基準權重,所以門檻郁一格,結果也只郁一點點。**穩健是因為它做得少。** 它的超額
低過固定權重 95/5,所以現階段的用途是「一個講得出理由的防守開關」,不是「一個可以自己
上場的策略」。

### 4.3 信用利差幾乎等於白做,而且原因可能出在替代品

用 HYG/LQD 比值代替真正的高收益 OAS,最優格只有 +0.16%、鄰域平均 −0.17%,全格 30 個
一致地貼近零甚至為負;連示例成本那一份對照更差(最優格 −0.56%、鄰域平均 −0.69%),
即成本一入就由白做變成蝕錢。兩隻 ETF 的比值同時混入了存續期差異與流動性溢價,不是
乾淨的信用訊號。**要判信用利差本身沒用,現有證據不足**——先判的是這個替代品沒用。

### 4.4 第二層序列的相關度(只作對照,不開格)

以「動能減低波的月度變化」為參照:成長 ETF +0.501、小型股 +0.371、價值 ETF +0.195、
油價 −0.021、美元指數 −0.084。成長與小型股的相關度最高,但兩者都是股票價格,與因子
輪動同源,**不算獨立資訊**;真正外生的美元與油價幾乎不相關。這支持一件事:宏觀訊號
之中,**利率一族才是與因子輪動有關係的那一族**,恐慌指標其次,商品與匯率暫時看不到。

## 5. 外部數據(全部免費、無鑰匙、收市後可得)

| 序列 | 來源 | 免費 | 知情時間 |
|---|---|---|---|
| VIX、VIX_3M | yfinance `^VIX`、`^VIX3M` | 是 | 收市後可得 |
| HY_ETF、IG_ETF | yfinance `HYG`、`LQD` | 是 | 收市後可得 |
| UST_3M/5Y/10Y/30Y | yfinance `^IRX`、`^FVX`、`^TNX`、`^TYX` | 是 | 收市後可得 |
| FF_FUTURE | yfinance `ZQ=F` | 是 | 收市後可得 |

**知情時間處置**:宏觀序列一律當收市後才知情,所以決策日只看得到**當日收市及以前**的
讀數,可執行點是下一根可交易 bar 的開市(照 D-021)。這一條寫在 `karst/data/macro.py`
的 `MACRO_INFORMED_POLICY`,並隨每份宏觀快照寫入 manifest。

**非可投資序列處置**:VIX 這類序列沒有 CIK、不可買賣,不入實體表。宏觀序列自成一種快照
(`data/macro_snapshots/<編號>/`),以**序列代號**為主鍵,經 `store.register_snapshot`
以來源 `yfinance-macro` 登記,拿到與價格快照同一套編號、同樣可引用。因為宏觀代號從來
不進價格面板,「不小心持有 VIX」在結構上寫不出來,不是靠紀律避免。

**缺數處置**:對齊主日曆後最多前填 3 日,超過就留空;驅動器見到空值即拋
`InsufficientHistory`,由排程層記為數據不足並沿用熱身權重——**不當零、不當上次的數**。
`^VIX3M` 尾段 25 日缺數就是這樣處理的。

## 7. 重跑

主報(零成本,落 `results/`):

```
PYTHONUTF8=1 python experiments/2026-08-28-macro-drivers/run_macro_sweep.py --fee-rate 0 --slippage 0
```

對照(連示例成本,落 `results-連成本/`):

```
PYTHONUTF8=1 python experiments/2026-08-28-macro-drivers/run_macro_sweep.py --out experiments/2026-08-28-macro-drivers/results-連成本
```

**命令列的預設仍然是連成本**(每股 US$0.005 + 滑點 5bp),所以主報那一句一定要顯式寫出
`--fee-rate 0 --slippage 0` 兩個零,否則跑出來的是對照那一份。這是刻意的,免得口徑靜靜
地變。

`--macro-snapshot` 的預設值**已經就是現役那一份宏觀快照**(住在
`experiments/snapshot_ids.py`),所以平時不用傳;**要強制重抓一份新的,才傳
`--macro-snapshot new`**。價格那半完全離線;宏觀那半只在要求重抓時才連網。同一格不會
重算——運行指紋(策略版本 × 參數集 × 期間 × 快照 × 引擎版本)相同就讀回舊運行,所以
價格與固定權重那 6 行不用重算,直接讀回。

## 9. 未解與風險

1. **+0.88pp 買不到結論。** 曲線斜度贏相對強弱 0.88pp,但輸回撤 15pp、換手多一倍。
   以現有證據不能說宏觀驅動器應該取代價格驅動器;它證明的是「利率資訊有增量」。
2. **六個驅動器裡四個的最優格是孤峰**(VIX 水平、曲線斜度、10 年息率、聯邦基金預期);
   VIX 期限結構的最優格判普通、信用利差的最優格判山脊。與價格驅動器同一個病。
   KARST-047/048 的軸型判讀已經接入生產掃描路徑,上面這批裁決就是用現行規則出的。
3. **信用利差用了替代品,結論只及於替代品。** 要判信用利差本身,需要真正的 OAS,而
   那要一把 FRED 鑰匙。
4. **`^VIX3M` 尾段停在 2026-07-17。** 期限結構開關在最後 25 個交易日沒有訊號,沿用熱身
