# 估值與預期 — valuation / L4

輸入：本地 bundle 路徑、允許讀原文清單、研究委託、L4 紀律、情境問題、已固定雜湊的 industry/company 片段。可回讀原文及補查。輸出 `layers.L4`；`payload` 僅 `valuation`、`target_date`。

必答四問：方法為何符合公司的經濟結構？最敏感三個假設及證據、改變它們會如何影響價值？另一合理視角得到什麼、分歧來自哪裡？相對上次何者改變（首次明寫無上次）？方法不能為既有看法服務。

分開今天內在價值、固定目標日的價格、技術阻力。今天基準價值由經營假設推導，不取悲觀樂觀中點；目標價需解釋持有期內經營／催化劑／估值變化的橋接及分派，不直接貼今天 DCF。反推現價要求時寫明固定了什麼與反推什麼。

管理層指引、單一分析員／Morningstar、聚合共識、現價反推要求四者分開；核版本日期、預測期間、GAAP／調整、幣別及單位後才比較。來源間 PE 差異不能平均。同業比較先核商業模式，不照搬供應商產業桶。

0.2 計算契約目前只支援年度期末 FCFF DCF：FCFF 配 WACC，現金、非營運資產、債務、其他請求權與稀釋股數橋接；輸出 bear/base/bull 三情境的 calculation，交程式重算。不得將 FCFE 或倍數法偽裝成 FCFF。若適用方法或輸入未受支援，`valuation.status=unavailable`、`scenarios=[]`、`gap_reason` 明確說明，其他敘述欄保留條件估值與補查方向；不能以編數填滿 schema。

數值假設的來源與選值理由寫入每個 scenario 的 rationale 及 top_assumptions；說清再投資、SBC／稀釋、失敗／融資、終值假設。`target_prices` 是有日期的條件情境，不必硬填。不得任意配概率製造期望回報。最終運算值由程式產生，不靠心算。
