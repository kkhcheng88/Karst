# 技術與市場行為 — technical / L5

輸入：本地 bundle 路徑、可讀來源、研究委託、L5 紀律、情境問題及已登記行情／程式輸出。輸出 `layers.L5`；`payload` 為 `technical`、`market`、`phases`。

焦點是已确认 pivot、支撐／阻力區、200 日 SMA、價量與動能。日線管執行、週線管主要趨勢／通道、月線管長期位置；上位週期與下位回調可以同時成立。先列關鍵價位及失效條件，再談突破、回踩、失守、假突破與執行選項。

程式負責 OHLCV、SMA、pivot、聚合及 R&R；模型解讀意義，不編日線或圖形。current quote、來源基準、拆股／總回報調整及 quote_to_bar_factor 必須一致。未收日／週／月 K 線可描述盤中狀態，closed=false，不能當收市確認。pivot 等確認需要右側資料時，confirmed_at 用真正可知的時點；不能偷看下一根。

週線／月線與趨勢線只在資料支持時評讀；通道需可重現錨點与確認條件，沒有計算或定位便列 candidate／gap。SMC 只作選用的結構／流動性描述，不能從掃高低點斷言機構意圖。沽空／機構持股各有截至期及公布延遲，不等於即時資金流。

`technical.views` 包含 D/W/M 三個鍵，沒有可靠數列可留空並寫 gaps；只有經核驗數列才填 bars。`key_levels` 只收已確認區域；candidate 寫 reading／phases。market 的時間及引用來自實際快照或正確收市時間，日期精度缺時間不得自己加盤後時刻。來源不足時先補查，沒有有效報價不能生成假的股票頁。

不把基本面好壞從圖上倒推；不移動支撐／止損來湊漂亮 R&R。突破可能繼續創高，超賣可能持續下跌；兩者都需條件與反證。
