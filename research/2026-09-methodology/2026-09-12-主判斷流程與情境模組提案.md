# 提案:四類注由「四套策略」改為「一套共用判斷流程的四個情境模組」(2026-09-12,主 agent 提出,待用戶裁)

> 起因:用戶 2026-09-12 反思(原話節錄):「whether the whole exercise is actually all in 1 single thing … it just seems a skill file to define how the agent should assess the stock at a specific point of time, and additional or specific assessment angles must be explicitly applied under certain scenarios … I can't really see that there is anyway in scriptable or machinery way can have Information Advantage.」GPT 第七輪同意方向。本提案把它寫成可裁的形狀;裁了才動 D-166 相關條文。

## 一、改什麼

| 項 | 現在(D-166 起) | 提案 |
|---|---|---|
| 四類注的性質 | 四套策略,各自要有篩選、進場、退出、回測、基準率 | **一套共用判斷流程**(研究員在某個時點對一家公司要答的問題),四類是**情境標籤**,決定要多問哪幾組問題 |
| ①錯殺注 | 獨立策略,要證有錯殺優勢 | 情境模組「行業被共同拋售」:公司間實際暴露、傳導差異、共同假設(即清單 v3 步〇至步五,加證偽與時限;估值步暫停作判詞) |
| ②趨勢注 | 獨立策略,對帳單十一節逐節講解後立項 | 情境模組「股價上升且預期持續上調」:經營改善能否延續、價格已反映多少、什麼令上調停止;兼任①候選的執行層(進場、持有、退出) |
| ③熱敘事注 | 獨立策略 | 情境模組「熱門敘事」:敘事如何轉成收入與現金流、現價要求多大成功 |
| ④未共識敘事注 | 獨立策略 | 情境模組「尚未廣泛認知的變化」:證據可靠否、何時對盈利重要、為何尚未被反映 |
| 一家公司只歸一類 | 是 | **否**:同一家可同時啟用幾個模組 |
| 資金配置 | 跨注分散、注內集中(D-166) | 不按類別預留席位;按**合格交易**配置(D-170/D-171 方向);跨注分散改為「跨共同假設分散」 |
| 引擎 karst/ 與 data/ | 曾要求它找優勢 | 定為四件事:保存當時可得資料與日期、比較新舊披露找變化、統一計算口徑與情境敏感度、追蹤預測與結果 |

## 二、不改什麼

- 敘事三件(護城河、經濟學、財務)仍是每個模組的機制歸類骨架(D-166)。
- 「不做即日、技術面只在事件窗、不賭活不活得過」三條邊界照舊。
- 已做的①材料全部保留:清單 v3 就是①模組的正本;②③④對帳單就是各模組的材料。

## 三、優勢在哪一層,怎樣證

- 公開資料加模型**不產生獨家消息**;機器買到的是時點紀律、覆蓋、記帳三件——它們是優勢若存在時能被看見的前提,不是優勢。
- 優勢若有,只在**判斷層**:把分散的公開資料接成一個市場價格尚未充分反映的經濟結論,而且比簡單方法早或準。
- 證法:每個模組選**一項可核對的具體判斷**,對比簡單對照。①模組那一項已在跑(KARST-216:暴露判斷對「跌得少/財務簡篩/低波動」;KARST-217:加①比單用②)。②模組的那一項由②材料定(候選:「上調會不會停」的判斷對「近四季上調次數」這種簡單規則)。
- **驗證分兩層**:先看讀對推對沒有(研究品質),再看那個判斷在當時價格下有沒有用(交易效果)。
- **接受的結果之一**:最後是一個好的研究助手,不是超額回報策略。

## 五、要用戶裁的三件
