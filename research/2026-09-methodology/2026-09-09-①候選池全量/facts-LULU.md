## 八、負債與現金(以 10-Q 為準,補缺——CSV 的 net_debt 定義需澄清)

【補缺,重要澄清】舊卡引用「現金 15.15 億(2026-05-03)」是 Q1 數字;screen60_full.csv 的 net_debt +7.51 億是 Q2(2026-08-02)數字,兩者本身沒有矛盾,是不同財季。但 CSV 的 net_debt 定義**不是**「有息負債 − 現金」,核實如下(數字均取自 SEC 10-Q,財季止 2026-08-02,accession 0001397187-26-000127):

| 項目 | 金額(千美元) | 備註 |
|---|---|---|
| 現金及現金等價物 | $1,389,737(13.90 億) | 資產負債表無「短期投資」獨立項目 |
| **有息負債(長期負債)** | **$0(資產負債表無此項目)** | LULU 賬面**沒有**任何長期借貸;業績稿另披露截至季末有 $593.7M 未提取的循環信貸額度(committed revolving credit facility)——這是**未動用**的額度,不是負債 |
| 流動經營租賃負債 | $366,649 | |
| 非流動經營租賃負債 | $1,774,478 | |
| 經營租賃負債合計 | $2,141,127(21.41 億) | 與舊卡「21.36 億」數字接近(舊卡取用日期略有不同) |
| 總負債 | $3,693,404 | |
| 總股東權益 | $4,791,174 | |
| 上半年(26 週,至 08-02)營運現金流 | $589,278(去年同期 $209,722) | 增幅顯著,主要因關稅退款及存貨管理改善 |
| 近四季營運現金流(ocf_ttm,CSV 給出) | 19.82 億 | 未重新推算,沿用 CSV 數字 |

**核實結論(這是本項最重要的一點):CSV 的 net_debt = +7.51 億,算法是「經營租賃負債合計 21.41 億 − 現金 13.90 億 = 7.51 億」,即把租賃負債當成債務計算。如果用傳統「有息負債 − 現金」的定義(LULU 有息負債為零),LULU 其實是淨現金 13.90 億,不是淨負債。** 兩種講法都不算錯,只是定義不同,寫報告時要註明用哪個定義,避免與舊卡的「淨現金 15.15 億」對不上而誤判為矛盾。

【補缺,結論:不適用,但附說明】傳統定義的「技術性替代」(新技術/新通路取代舊有能力)在 LULU 個案沒有查到正在燒的爭議。查到的競爭壓力,性質是「品牌型替代」——數位原生品牌 Alo Yoga(約 99 間美國門店)、Vuori(約 93 間美國門店,2026 年完成 $825M 融資、估值 $5.5B)在搶佔 LULU 核心客群(千禧世代及 Z 世代、注重健身身份認同的男女性消費者),用社群行銷、AI 驅動的社交電商搶市佔,但這是品牌/產品競爭,不是技術取代舊技術的敘事。
