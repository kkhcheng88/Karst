**先修正三個會直接影響策略去留的問題。**

**第一,「負期望」與報告自己的平均回報互相矛盾。**

§2B.5 寫一年平均超額回報為 **+5.2%**,中位數為 −2.5%。假如兩者來自同一樣本、同一持有期及同一超額回報定義,便只能說:

> 多數事件跑輸,但少數大贏家令樣本平均超額回報為正;這個平均值的可靠性與可實現程度尚待核實。

不能說已量出負期望。

同樣,若勝率 p=45.3%,而「賠率」是**盈利事件的平均超額收益/虧損事件的平均超額損失絕對值**,則:

x̄ = p·x̄₊ − (1−p)·|x̄₋|

平均超額為正,要求這個比值高於約 **1.21**。它與「賠率約 1.0」不能在同一口徑下同時成立。很可能用了中位盈虧比、不同版本或不同收益口徑,必須對帳。

這不表示策略有效。倖存者偏差、極端值、成本及每年只選幾注,都可能令 +5.2% 無法轉化成可用收益。**但這是「優勢未確立」,與「已證明負期望」是不同裁決。**

**第二,這張表還沒有測到完整的①,也沒有分離各層貢獻。**

它測的是「大跌+若干財務條件」,沒有完整測到估值、經營反證、證據進場及實際退出。因此不能推導「只有模型判斷層可能有價值」,也不能說「原始篩選零貢獻」——後者還需要與未加篩選的對照比較。

報告的 23,883 次觸發,亦不等於 23,883 個獨立合格投資案例。主線一年樣本是 2,686;文中另提涉及 296 家公司,兩者關係要交代。同公司 120 日後再觸發,仍可能與之前的一年持有期重疊;同一市場危機跨行業出現,也不是獨立事件。

**第三,五家走通測到了流程改變,尚未測到投資改善。**

模型否決一家公司,只證明決定改變。必須追蹤被否決者,才知道避免了損失,還是錯過了右尾贏家。

而且「五家只有一家符合」不能在六十家結果未出時,寫成「六十家只有一家」。五家本來就是刻意選取,不能用來估合格比例。

**1. 判斷層要贏多少,①才值得做?**

我會用**扣成本後、相對可投資替代方案的回報改善,加上風險與研究成本**作主要門檻。勝率與盈虧比是診斷項,不宜分別設成淘汰線。

你們目前「勝率不過 45%,或者賠率低於 1.5 就降級」會錯殺一些有價值的策略。例如,低勝率但偶爾大贏,與高勝率但平均盈利較小,都可能有正期望。

先用簡化的兩結果模型說明:

E[R] = pU − (1−p)D − c

其中 U 是成功情境收益、D 是失敗情境損失、c 是成本。若要求回報至少為 h,所需成功概率為:

p_required = (D + c + h) / (U + D)

純示例,假設損失 30%、成本 1%,要求持有期回報 10%:

| 成功情境收益 | 所需成功概率 |
| ------ | -----: |
| +30%   |  約 68% |
| +60%   |  約 46% |

**不存在一條適用所有候選的「勝率達到多少就值得做」。**

這亦提供一個較符合你對概率疑慮的做法:**先反推出現價需要多高的成功率,再問證據是否足以支持。** 不必假裝知道勝率是 57.3%,但也不能完全忽略成功可能性。

正式版本應至少加入「論點未破、但一年內沒有重估」這個第三情境。你們的一年硬上限,使它非常重要。

策略層則比較三個同步記錄的結果:

* 可投資的被動替代方案;
* 不含模型的估值與財務規則;
* 加入模型及證據判斷的完整①。

資訊比率可以日後報告,但一年三至六注時,不宜把它當主要決策門檻。事件平均收益亦不能直接當成組合年回報:還要處理重疊持倉、閒置資金及實際可持有數量。

**2. 一個月至一年,與較長反轉窗口衝突,怎樣處理?**

**我選丙:低頻例外、沒有固定席位。同時提出第四條路——把大跌由必要入場條件,改為候選提醒。**

你們真正有意義的假說是「市場對某項可驗證結果定價過度悲觀」,未必需要股票先相對大市跌 25%。這道閘可能把研究集中在業務仍在惡化的公司,也可能漏掉價格長期低迷、但近期出現改善證據的公司。

值得獨立預登記的新版本是:

> 在熟悉的行業內,先找持有期內有重要驗證事件的公司,再檢查價格是否低估合理結果;大跌只是其中一個候選來源。

這是新假說,要與原版分開驗證,不能回頭混入原表。

我不建議因為一至三個月「中位接近零」就縮短窗口。**沒有優勢的短窗口,不會因縮短而變成優勢。** 也不應把一般性的動能/長期反轉研究,讀成每家公司必須等三至五年才會修正;你們這張一年表本身沒有測到三至五年的結果。

①若保留一年硬上限,就應要求「一年內有合理的價值實現路徑」,而非「長期看來便宜」。

**3. 純賠率排序怎樣修正?均線位置應否成為硬閘?**

**不把均線結果升為硬閘。** 驗證年份沒有重現,現在再固定這條規則,沒有足夠依據。相對均線的位置也不是估值;不能由此判定「跌的是漲幅,不是估值」。

兩個分格方向相反,更不能說它們「互相抵消」——沒有交叉條件分布,無法作這種運算。

至於純賠率排序,我不同意報告所說「賠率可以事前定死」。**能鎖定的是假設,並非將來的收益與損失。** 上行目標與壓力跌幅,同樣可能被模型估錯。

兩項便宜的修正是:

* **先列「倍數不變」的一年回報。** 如果主要收益全靠倍數上升,必須另有可核查的重估理由;不能只因歷史倍數較高就給它較高順位。
* **先過證據及估值穩健性要求,再用賠率排序。** 起步年、合理利潤率或折現率稍變便由便宜變昂貴者,先歸為「對假設敏感」。

你可以保留 R&R 作比較工具,但只在**證據品質、期限及假設可靠性相近**的候選間使用。否則最高賠率可能只是最樂觀的估值模型。

**4. 回報底線用相對還是絕對口徑?**

我建議把兩個用途分開:

* **事前篩選:** 用預先固定的持有期要求回報,避免逐月猜大市再調門檻。
* **事後考核:** 與同一期間實際可投資的基準總回報比較,另用行業/規模對照診斷來源。

若希望事前要求隨利率變化,可用「期限相近的低風險收益率+固定風險補償」,按固定日期更新。補償多少應在組合層決定,現有報告不足以證成某個精確數字。

**15% 可以暫作研究候選的上行空間篩選,但不能稱為已具充分補償。** 它只是某情境的回報,尚未考慮發生概率及失敗損失。

同樣,不要直接把歷史中位輸大市 5%,加成「所以多要求 5%」;中位數不是可如此加減的期望拖累。

**5. 勝率區間怎樣計分?二十注夠不夠?**

先定義「成功」:是賺錢、跑贏指數、達到目標價,還是經營預測成立?這些要分開。

每注建議登記:

* 一個用於評分的**中央概率**;
* 一個描述估計不確定性的範圍;
* 支持它的證據,以及可能改變判斷的條件。

中央概率以 Brier score 評分:(p−y)²,越低越好,再與相同案例上的基準概率比較。**概率區間不能直接當成營收等可觀察數值的預測區間來評分**,因為單次結果只是 0 或 1,不會揭示那筆交易的「真實成功概率」。連續經營指標則可以用固定覆蓋率的區間評分,同時懲罰過闊區間和漏中。[Gneiting 與 Raftery 的原始研究](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)

45% 是可能的**對照預測**,不是「成功線」。由 50% 降到 45% 亦沒有令勝率門檻變嚴。

二十注適合流程覆核,不足以可靠分辨小幅優勢。粗略計算,假設案例完全獨立、基準 45% 已知、雙側 5% 顯著水平及 80% 檢驗力:

| 真實勝率 | 與 45% 區分所需案例,約 |
| ---- | -------------: |
| 55%  |            195 |
| 60%  |             86 |

這只是簡化的勝率檢驗;比較兩套預測的 Brier 分數,樣本需求還取決於逐案分數差異。案例相關、基準本身不確定,都會增加難度。

仍值得登記,但不要等二十筆真實下注才開始:對候選及被拒者的關鍵經營結果都作前瞻預測,較早檢查研究能力。這可以支持繼續研究,不能替代交易收益驗證。

**6. 倖存者偏差有沒有便宜估法?**

先刪去「這批公司被收購機會大過破產機會」的確定語氣,除非找到同條件、同窗口的資料支持。

收購有公告溢價,也不代表從你們的觸發價格起計就賺錢或跑贏市場。公司可能先大跌,再以溢價被收購;缺失樣本也不只包含收購與破產。

便宜的方法是先做**翻轉結論的敏感度表**:

μ_完整 = (1−m)·μ_已觀察 + m·μ_缺失

m 是缺失事件佔完整母體的比例,兩部分必須用同一回報定義。

例如,暫用報告的 +5.2% 平均超額,假設缺失事件平均超額為 −100 個百分點,缺失比例約 4.9% 已足以令完整平均降到零。這只是敏感度示例,不是缺失比例估計,也不是損失界限。

下一步可抽取**少數固定歷史日期或季度**,補回當時符合條件、後來停止掛牌的公司,估計缺失比例及退出結果。不必一次重建十六年全市場。

若連缺失比例也不知道,外部整體退市率只能提供情境假設,不能保證方向。先說「方向仍未知」比給一個不成立的上下界好。

**7. 沒有歷史指引與共識,怎樣做錯價來源標籤?**

**我會先改標籤的核心,而不是急着找價格代理。**

「市場比管理層悲觀」既不是錯價的充分條件,也不是必要條件。管理層可能太樂觀;市場與指引一致,也可能共同低估了未來。

報告還有期限錯配的風險:**下一季/下一年的指引,不能直接與反推的五年收入路徑比較,再宣稱兩者重疊。** 「今年跌 5%」與「連跌五年,每年 5%」是不同預期。

我建議主要標籤改成:

| 機制        | 必須寫清楚的分歧           |
| --------- | ------------------ |
| 經營損害被高估   | 哪個指標會比現價隱含路徑好、何時可核 |
| 現金或資產價值實現 | 什麼具體行動、時間及失敗條件     |
| 倍數重估      | 哪項風險或盈利品質變化支持較高倍數  |

「相對指引如何」保留為補充欄,不決定策略身份。

股價跳空混合了盈利、指引、估值、倉位及此前預期,不能單獨代理市場是否過度悲觀。盈利修訂若沒有當時版本的預估資料,也不能可靠重建。

歷史研究可小規模抽取當時的 8-K 業績附件及公司公告;SEC 提供申報歷史與 XBRL 資料接口,但不是完整的標準化共識資料庫。[SEC 官方說明](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)

**8. 是否降級?用什麼門檻避免無限改規則?**

**現在就取消固定席位,保留有限研究預算。** 理由是可執行優勢未成立,資料與估值口徑仍有缺口;不用等待「證明無效」才停止預留資金。

我建議三個階段:

| 階段   | 完成要求                         | 未達標的處理               |
| ---- | ---------------------------- | -------------------- |
| 資料可信 | 對清平均/中位/盈虧比;核實主要極端收益、市值與財務時點 | 暫停用歷史表作去留裁決          |
| 機制可做 | 能找到不靠任意倍數回歸、且一年內可驗證的候選       | 保留觀察,停止擴建交易功能        |
| 前瞻有用 | 在相同候選與期限下,研究或決策有可追蹤的增量       | 有增量才考慮擴大;證據不足就維持小型研究 |

我會給下一輪一個**固定研究工時預算及到期日**,而不是「做到二十注為止」。以一年三至六注計,二十注可能拖三至七年,與你的時間要求不合。

到期後若只剩「把折現率降低」「退出倍數調高」「換均線」才能找到交易,應停止這個版本。若資料可信、機制具體,但結果尚未成熟,便維持觀察,無須假裝成功或失敗。

也不要因①未成立,就默認②或④較好;它們要通過自己的驗證。模型如果只增加研究效率,也可以保留為工具,而不讓它承擔選股裁量。

**9. 空手月份怎樣防止底線被調低?**

單人系統不可能完全阻止自己改規則,但可以令改動無法悄悄影響既有決定:

* 規則以版本編號及生效日保存;每張候選卡綁定當時版本。
* 新版本只適用生效後的新決策,保留舊版的影子結果。
* 只在預定覆核日改策略;修正資料錯誤則立即處理,另行標記。
* 固定研究預算,禁止設定必須成交的注數。
* 系統輸出「本期無合格候選」,視為正常完成狀態。

連續空手月數可以報告,但不要設成觸發放寬規則的警報。更有用的指標是:研究了多少、哪些原因被拒、多少依賴倍數上升,以及每個可用判斷花了多少核實時間。

**讓①更可做,我會優先修改以下四處,而不是再增加候選條件。**

**一、重寫一年退出估值。**

近一年與四年歷史市銷率都是背景資料,沒有哪一個天然叫「真正折讓」。目前「四年作廢」同時又要求「兩把尺都過」,規則亦互相衝突。

每個候選至少展示:

1. 經營按預期發展、倍數不變;
2. 經營改善、倍數仍收縮;
3. 具體反證出現,支持有限重估;
4. 論點失效。

倍數可以變,但要接到盈利能力、增長、風險或資本配置的變化。唯一入選的服飾品牌,若主要靠 1.0 倍升至 1.7 倍才成立,就需要說明**什麼令投資者一年內願意多付這個價**。歷史中位數本身不是答案。

**二、核查現金流與折現率是否配對。**

「國債+5%」可作統一比較假設,不能自動視為每家公司的正確資本成本。尤其要查計算器究竟折現企業自由現金流,還是股東自由現金流:前者對應 WACC,後者對應股權成本,兩者不可混用。[Damodaran 的估值教材](https://pages.stern.nyu.edu/~adamodar/pdfiles/valn2ed/ch2.pdf)

若基本口徑不對,固定規則只會固定偏差。敏感度也應包含合理的**聯合情境**,不止各假設分別 ±10%。

**三、把下行風險與「一年最大回撤」分開。**

近一年回撤可以作風險參照,不適合單獨充當可靠的壓力下限。平靜一年會低估未來風險;從舊高位跌下來的幅度,也不等於從今天再跌的幅度。

保留護城河失效、融資或流動性惡化等壓力情境,再以單股及共同風險上限限制倉位。參數未定前,繼續只做紙上配置。

**四、先做一次有限的資料修復,再開下一個策略版本。**

最必要的對帳是:

* 平均、中位、勝率及盈虧比是否同樣本同口徑,股票與指數是否都計總回報;
* 最大贏家是否有拆股、代號、股數或價格調整錯誤;
* 財務數值是否確實來自當時申報,而非後來重述;
* 確認進場是否計入始終沒確認的事件,期限與對照是否一致;
* 2022 年後資料已被用來改規則,就不再是新版本未見過的驗證集。

右尾真實存在就要保留,同時報告收益集中度,不能為了讓結果平滑而刪掉。反過來,也不能由「右偏」直接推出「任何止盈都會砍掉利潤」;具體退出規則仍需要驗證。

**我願意繼續投入的是「有期限、有證據支持的預期差投資」。現階段不支持把「大跌後等歷史倍數恢復」當成固定策略。下一輪的目標應是辨明這兩者,而非把①調整到看起來一定能交易。**
