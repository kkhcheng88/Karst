# KARST-066:因子檢視「預測力」分頁——畫面變體

- 狀態:待用戶揀,舉手已於票上留言
- 範圍:只出變體與畫面狀態,**不實作**(Kira UI 決策關規矩);揀定後照稿接真數據(`karst factor ic`/`karst.factorpredict`)

## 一句問題

「預測力」這個新分頁——是掛在既有「運行詳情」頁右欄那個因子檢視分頁旁邊(變體 A),
還是獨立開一個不依附任何運行的頁面(變體 B)?兩者答的其實是不同層次的問題,
版面決定藏著一個範圍決定,不能只揀好看那個。

## 前文後理

現有「因子檢視」(`prototype/run.html` 右欄第三分頁、`stock-a.html`/`stock-b.html`
兩個舊變體)是**個股層**的解釋畫面:選定一次運行、點一筆交易、看那隻股票那一日
各因子的分數與入選狀態——回答「策略那天為什麼揀了這隻」。

本票要加的「預測力」完全是另一種形狀:它答的是「這條因子在這個宇宙、這個持有期
窗口,對未來回報準不準」——**跨股票、跨因子版本,不屬於任何一次運行**。輸入是
「宇宙(數據快照)× 因子(可多選)× 持有期窗口」,不是「這次運行 × 這隻股」。
兩個問題共用「因子」這個詞,但一個是個股解釋、一個是因子本身的統計評估
(IC/ICIR),數據來源也不同:前者讀某次運行選中的因子分數,後者直接讀
`karst.factorstore` 的因子值長表 + 價格面板,完全不需要先有一次運行。

## 建議

**建議變體 B(獨立頁面)**,理由:
1. 預測力評估不依附運行——運行詳情頁的右欄邏輯(選股票、蠟燭圖十字線同步)整個
   用不上,硬塞進同一個分頁列會誤導使用者以為這是「這次運行」的表現。
2. 因子預測力是「因子」本身的屬性,查閱時機通常在**選因子、定策略之前**(要先
   知道哪條因子有訊號才值得用),不是運行跑完之後才回頭看——擺位應該貼近因子
   定義,不是貼近運行結果。
3. 獨立頁可以自由選宇宙(十二隻 / 標普 500)與窗口(1/5/21 日),不受單一運行
   綁死的快照與因子清單所限;變體 A 若要達到同樣自由度,右欄那張卡會被撐得
   遠超原本三分頁的資訊量級。

代價:多一個要學的入口(現有導覽是策略總覽/策略詳情/運行詳情/參數掃描四頁,
D-023 已定為 v1 基線),新增一個頂層頁面等於改動這份基線,要另外決定它掛在
哪個導覽位置。

## 變體 A:掛在運行詳情頁右欄(第四分頁)

### 版面文字線框

```
┌─ 運行詳情:趨勢波段 · 2024-01-02~2026-08-28 ──────────────────────────┐
│ [ 主圖:淨值走勢 / 個股蠟燭圖(鑽取後) ]      │ ┌ 指標 │ 逐筆交易 │ 因子檢視 │ 預測力 ┐│
│                                              │                          │
│                                              │  預測力分頁內容(見下)   │
└──────────────────────────────────────────────┴──────────────────────────┘
```

分頁內容(取代右欄卡身,不動主圖與左側其餘三個分頁):

```
┌ 預測力 ────────────────────────────────────────────────┐
│ 宇宙:本運行快照(唯讀,顯示快照編號)                     │
│ 持有期窗口:( 1 日 ) ( 5 日 ) ( 21 日 )  ← 分段選擇鍵    │
│ ─────────────────────────────────────────────────────── │
│ 因子                    IC均值   ICIR    樣本日數        │
│ Alpha158·KMID           +0.021   0.054      2928         │
│ Alpha158·ROC5           +0.007   0.018      2923         │
│ …(本運行引用的因子清單,依 |IC均值| 由大到小排)          │
│ ─────────────────────────────────────────────────────── │
│ 滾動 ICIR 小圖(選中一條因子後在下方展開一條時序線)      │
└───────────────────────────────────────────────────────────┘
```

### 三個畫面狀態

**無數據**(運行引用的因子在這個快照上未入庫預測力,或算出來對齊表是空的):
```
┌ 預測力 ────────────────────────────────────────────────┐
│  這個宇宙這批因子還沒有算過預測力。                       │
│  [ 立即計算 ]                                            │
│  (灰階空表格輪廓,行數 0)                                 │
└───────────────────────────────────────────────────────────┘
```

**計算中**(按下「立即計算」或首次進分頁觸發背景運算):
```
┌ 預測力 ────────────────────────────────────────────────┐
│  ⟳ 計算中……158 條因子 × 3 個窗口,預計數十秒到數分鐘      │
│  (表格骨架以淺色橫條佔位,不顯示假數字)                    │
└───────────────────────────────────────────────────────────┘
```

**有結果**:如上方主線框所示,表格 + 排序 + 選中一條因子展開滾動 ICIR 小圖。

## 變體 B:獨立頁面「因子預測力」

### 版面文字線框

```
┌ 頂層導覽:策略總覽 │ 策略詳情 │ 運行詳情 │ 參數掃描 │ 因子預測力 ┐───────────┐
├──────────────────────────────────────────────────────────────────────────┤
│ 宇宙:( 起步十二隻 ) ( 標普 500 )        持有期:( 1 日 )( 5 日 )( 21 日 ) │
│ 因子篩選:[ 搜尋因子名稱……          ]  排序:[ |IC均值| 由大到小 ▾ ]     │
├──────────────────────────────────────────────────────────────────────────┤
│ 因子                    IC均值    IC標準差   ICIR     樣本日數           │
│ Alpha158·KMID           +0.0205    0.3805   0.0538      2928            │
│ Alpha158·ROC5           +0.0071    0.3841   0.0184      2923            │
│ … 158 條全列,逐頁 50 條                                                 │
├──────────────────────────────────────────────────────────────────────────┤
│ 選中一條因子 → 右側/下方展開:                                            │
│   逐日 IC 時序圖(細,灰底零線)                                          │
│   滾動 ICIR 時序圖(疊在同一張,或並排第二張)                            │
│   對照列:A 股基準約 0.04–0.05 · 美股個人重現約 0.005                    │
└──────────────────────────────────────────────────────────────────────────┘
```

### 三個畫面狀態

**無數據**(選中的宇宙 × 窗口組合未曾入庫或未曾算過,例如標普 500 剛入完因子值
但預測力還沒跑):
```
┌ 因子預測力 ─────────────────────────────────────────────┐
│  宇宙:( 標普 500 )  持有期:( 5 日 )                       │
│  這個組合還沒有算過。                                       │
│  [ 開始計算全部 158 條因子 ]                                │
│  下方留一段說明:「跑一次約需 X 分鐘(625 個實體 × 158 條)」 │
└───────────────────────────────────────────────────────────┘
```

**計算中**:
```
┌ 因子預測力 ─────────────────────────────────────────────┐
│  ⟳ 計算中(38 / 158 條因子)……                              │
│  進度條 + 已完成因子的結果隨算隨填表(不用等全部做完才顯示)  │
│  [ 取消 ]                                                   │
└───────────────────────────────────────────────────────────┘
```

**有結果**:如上方主線框,含選中因子後的時序圖與對照列。

## 共通元件備註(供實作參考,兩個變體皆適用)

- 表格排序、篩選、分頁沿用 `.kira/design-system.md` 第 3 節既有的表格元件與
  `--accent` 選中色、`--text-2`/`--text-3` 兩級次文字。
- IC 正負用 `--up`/`--down` 意義色標示方向,但**不要**用「升/跌」的語意直接套用
  ——IC 為負不代表因子「差」,可能是反向訊號,顏色只用來輔助掃視正負,文案上
  仍要講清楚。
- 「樣本日數」欄照 `karst.factorpredict.summarize_ic` 的定義:當日算得出 IC 的
  交易日數,不是宇宙日曆的全部天數。
- 對照基準那一行文案要清楚標明「A 股基準」與「美股個人重現」的可信度不同
  (前者官方基準、後者業餘覆現),不可以並列成同一級數的參考——沿用
  research/2026-08-29-factor-horizon-evidence.md 結語的用詞。
