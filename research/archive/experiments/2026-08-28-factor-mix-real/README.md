# 因子混合策略(ETF 版):等權示例運行的重生腳本(KARST-041)

一句命令重跑,得回同一份成績:

```
set PYTHONUTF8=1
python experiments/2026-08-28-factor-mix-real/run_backtest.py
```

腳本收工前會**自己核對一次**:運行編號、交易日數、換倉次數、成交筆數,加三項指標
(對到小數點後四位)。對不上即當場拋錯——重生腳本交不出同一份成績,就不是重生,
是另一次運行。

**本檔的取值全部是示例,不是現役設定。**

## 數據目錄重建(KARST-057,2026-08-28)

倉根 `data/` 被誤清空,無備份,當作重建。

| 項目 | 舊 | 新 |
|---|---|---|
| 數據快照 | `2026-08-27-91a5d51339d9` | `2026-08-28-000b4820a23a` |
| 運行編號 | `run-f4c162e5aac34347` | `run-024df83fb4891c89` |

**運行編號變了,三項核對指標一個都沒有變**:累計回報 3.2186、年化 0.1319、
最大回撤 −0.3493,對到小數點後四位一字不差;交易日 2,929、換倉 47 次、成交 188 筆
亦完全相同。編號會變是因為它由「策略版本 × 參數集 × 期間 × **數據快照** × 引擎版本」
算出來,而重抓必然換一個快照編號。

腳本內的 `EXPECTED_RUN_ID` 已隨之更新;三項 `EXPECTED_METRICS` 一個字都不用改。
