# KARST-096:凍結模組合成之後,重凍一次對得住嗎

**一句答案:對得住。** 現役 S&P500 快照與現役宏觀快照,用原輸入經新的凍結模組各重凍
一次,兩個快照編號與內容雜湊**逐位相同**;改動之前先跑一次同一支腳本,改動之後再跑
一次,兩次凍出來的三個 parquet 逐位相同、說明檔逐行相同。

| | 已凍結那份 | 重凍出來 | |
|---|---|---|---|
| 價格(S&P500) | `2026-08-28-3bf7ab0a522a` | `2026-08-28-3bf7ab0a522a` | 逐位相同 |
| 宏觀 | `2026-08-28-dc2d9f1a1778` | `2026-08-28-dc2d9f1a1778` | 逐位相同 |

價格那次是**由 1,681,050 根日線由頭凍起**(`reused=false`,不是走等價重用那條捷徑),
宏觀那次 40,996 個讀數,同樣由頭凍起。

## 兩支腳本,刻意分家

`replay.py` **只凍不判**:照原輸入再凍一次,把凍出來的東西完整寫落一個目錄。它要在
改動**之前**跑一次、改動**之後**再跑一次,而它本身一個字都不准改——否則「改動前後
一樣」這句話就證不到任何事。判對錯在 `compare.py`。

```
python experiments/2026-08-30-freeze-module/replay.py --label before --out <目錄>
#   ……改碼……
python experiments/2026-08-30-freeze-module/replay.py --label after  --out <目錄>
python experiments/2026-08-30-freeze-module/compare.py --out <目錄>
```

**動的是複本。** 每次跑都把 `karst.sqlite` 複製一份去輸出目錄,快照亦寫進輸出目錄
自己的快取根;生產庫與 `data/` 一個位元都不碰。判詞落 `結果.json`(本目錄),三道
閘任何一道不過即回非零。

原輸入不是憑空砌的,是由**已凍結的快照本身**加當日那次重凍留下的副產檔還原:日線取
`bar_status = actual` 那批(填補與留白由管線重新生成)、代號對照取
`experiments/2026-08-29-ticker-history/snapshot-anchors-083.csv`、呼叫方註記由 manifest
的 `notes` 切出來。**那一刀切在哪裡不是猜的**:管線自己補的那批佔位錨註記由代號對照
算得回,算出來與 manifest 尾巴逐條核對,核得上才切,核不上當場拋錯。

## 三道閘

**甲、對生產逐位。** 重凍出來的編號與內容雜湊 vs 已凍結那兩份。四格(before/after ×
價格/宏觀)全部相同。

**乙、改動前後逐位。** 兩個目錄 18 個檔逐位比,包括三個 parquet。8 個逐位相同,
10 個有分別,而分別**全部**落在三格明列的東西上,清單以外一位都沒有差:

- `fetched_at`(抓取時間)—— 牆上的鐘,刻意不入內容雜湊(D-026 第 3 條:同一批內容
  重抓要落回同一個編號)。
- `*.gateway-key` —— 每複製一次庫身就新開一把簽章匙,與凍結無關。
- `summary.json` 的 `label` —— 就是 before / after 這兩個字本身。

容許清單是**逐條寫死**的,不是一條「差得少就當過」的容差。

**丙、說明檔對已凍結那份。** 價格差 11 行、宏觀差 27 行,而且 **before 與 after 差的
是同樣那幾行**(剔走抓取時間之後逐行相同)——即這些分別在改動之前已經存在,不是本票
改出來的。逐行看過,兩份都是**純新增,一行都沒有刪走**:

| | 多出來的是 | 為什麼 |
|---|---|---|
| 價格 9 行 | 身分表的「宇宙表代號數 / 同實體別名剔除數 / 三數等式」三行,加「五之三、同實體別名裁決」整節 | KARST-084 的欄目,那份快照凍結時還未有 |
| 宏觀 25 行 | 「七之一、齊全度核對」整張表,加「七之二、註記」那一行 | KARST-061 的欄目,同樣是那份快照凍結之後才加 |

換句話說:**重凍出來的說明檔包含已凍結那份的每一行,一行不缺**,多出來的是後來新增
的欄目。這兩份現役快照要不要按新版說明檔重凍一次,是另一件事,不在本票——本票只證
「凍結程序合成一份正本之後,凍出來的還是同一份東西」。

## 這裡在改什麼

改動之前,「凍結一個數據快照」那條程序有三份各自的實作:價格線 `karst/data/pipeline.py`、
宏觀線 `karst/data/macro.py`、重凍腳本 `experiments/2026-08-29-ticker-history/refreeze083.py`。
改動之後只有一份:`karst/data/freeze.py`。三個呼叫者各自只剩「來源適配器」那一段。
