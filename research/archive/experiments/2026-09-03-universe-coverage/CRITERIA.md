## 二、十倍股定義與 t0(照 KARST-160/162 一字不改)

- 十倍股名單、t0(通往十倍的那個最佳起點月底)、倍數,一律直接讀 `tenbagger_names.csv`
  的 `horizon == "5y"` 行,**本票不重跑掃描、不重新定義**。
- 該名單的定義出處:`experiments/2026-09-02-tenbagger-scan/RULES.md` 第二節
  (t0 = 2009-01 起每個月底;窗 = t0 至 t0+5 曆年;倍數 = 窗內最高收市 ÷ t0 收市;
  ≥10.0 為十倍;窗必須完整)。

## 三、代號怎樣接回實體

`tenbagger_names.csv` 以代號為鍵,本票的主鍵是 `entity_id`(CIK 十位補零)。接法:

1. 查 `ticker_periods`,取 `ticker` 相同**且**時段覆蓋 t0 的那一段
   (`valid_from ≤ t0` 且(`valid_to` 為空或 `t0 ≤ valid_to`))。
2. 多過一段命中 → 照同實體別名閘(KARST-084)排序:`valid_to` 為空者先、
   價格庫真實列數多者先、代號字母序。取第一段。
3. 一段都沒有 → 該家記 `entity_unmatched`,**不計入分子亦不計入分母**,逐家列出。

代號時段表的 `confidence` 全部是 `low`(由今日代號快照與申報期外推,不是查證的代號歷史),
所以第 1 步的時段覆蓋是**近似**,報告要寫明。

## 四、市值怎樣算(t0 那一刻)

> `市值(t0) = 收市價(t0) × 申報股數(申報日 ≤ t0) × t0 之後的累積拆股因子`

- **收市價**:價格庫的 `close` 欄(yfinance `auto_adjust=False`,即**已還原拆股、未還原股息**)。
  取 t0 當日;t0 無價(停牌/假期)則取 t0 之前 5 個交易日內最近一日;仍無 → 市值缺值。
- **申報股數**:面板 v3 的 `shares_outstanding`(封面頁 `dei:EntityCommonStockSharesOutstanding`),
  取 `filed_date ≤ t0` 的最後一列。**申報原值,未還原拆股。**
- **累積拆股因子**:`splits.parquet` 之中該代號 `report_date > t0` 的 `ratio` 連乘。
  代號不在拆股表內 → 因子當 1,並標旗 `split_table_absent`。
  `CPWR` / `EP` / `PARA` 三個代號的拆股因子已知被代號重用污染(KARST-160 RULES 第九節),
  這三家市值一律設缺值。
- 三個部件任何一個缺 → 市值缺值,記 `mcap_missing_reason`。

**這是近似入位,不是真市值**:封面頁股數是季度快照、拆股表只覆蓋舊 728 家、
非美元申報人的股數與美元價格相乘會出錯(見第九節第 5 點)。

## 五、淨現金怎樣算(t0 那一刻)

面板 v3 取 `filed_date ≤ t0` 的最後一列,兩個口徑**並報**,不擇一:

| 口徑 | 算式 | 缺值處理 |
|---|---|---|
| **N1**(本票票面) | `cash_and_equivalents + short_term_investments − liabilities > 0` | `short_term_investments` 缺 → 當 0(公司多數是真的沒有);`cash` 或 `liabilities` 缺 → N1 缺值 |
| **N2**(KARST-166 判準第三節 S1 的符號) | `cash_and_equivalents − (lt_debt + st_debt) > 0` | `st_debt` 缺 → 當 0(照 KARST-166 寫死的做法);`lt_debt` 或 `cash` 缺 → N2 缺值 |

**兩個口徑覆蓋率相差很遠**(面板 v3 最新一期:`liabilities` 88.1%、`total_debt` 41.4%),
所以報告必須兩個都出,並報各自的可算家數。**本票不選口徑**——選哪個是策略層的事。

只用**符號**(正 / 非正),不用「淨現金對市值」比率:非美元申報人的帳目以本國貨幣入面板
(面板 v3 不做貨幣換算),同幣種相減符號仍然成立,但除以美元市值就錯。

## 六、指數成員身份

`sp500_historical.csv` 以代號查:`joined_on ≤ t0` 且(`left_on` 為空或 `t0 ≤ left_on`)
即 `in_index = True`。代號不在表內 → `False`(不是缺值)。
**這張表只有標普 500,沒有羅素**;所以「細且不在指數」這條只答得到標普那一半,
羅素成分史是付費資料,本票**量不出**。

## 八、基礎率(倖存者口徑)

- **分母**:`universe_smallcap_v1` 之中,在年份 Y 的 1 月 1 日**有價**(價格庫在
  Y-01-01 前後 5 個交易日內有 `adj_close`)**且有股數**(面板 v3 有 `filed_date ≤ Y-01-01`
  的 `shares_outstanding`)的實體。
- **年份範圍**:Y = 2010 – 2021。下限是 XBRL 強制申報起點(2009 年起才有股數),
  上限是完整五年窗的要求(2021-01-01 + 5 年 = 2026-01-01 ≤ 價格庫尾日 2026-09-01)。
- **十倍**:`窗內最高 adj_close ÷ t0 adj_close ≥ 10`,窗 = Y-01-01 至 Y-01-01 + 5 曆年。
- **>50% 回撤**:`窗內最低 adj_close ÷ t0 adj_close − 1 ≤ −0.50`。
- 兩個比率逐年報,另報全期平均(以各年分母加權)。

**這批數字一律標「倖存者口徑」**(D-152/D-157):宇宙來自今日仍在申報的公司,
中途除牌的不在分母,十倍率必然偏高、回撤率必然偏低,**偏高偏低幾多量不出**。

## 九、判詞規則(先寫死)

| 情況 | 判詞 |
|---|---|
| 兩組可算家數各 ≥ 50 **且** 比率之差 ≥ **5 個百分點** | **存在**(附方向) |
| 兩組可算家數各 ≥ 50 **且** 比率之差 < 5 個百分點 | **不存在** |
| 任一組可算家數 < 50,或所需欄位在原料上根本沒有 | **量不出** |

中位數類(②)不出存在性判詞,只報數與對照。
5 個百分點不是統計檢定,是一條事先講定的實用線:低過這個幅度的差,拿來做過濾器沒有意義。

## 十、A-045 怎樣裁

A-045 自己寫定的查證方向:「拿同一日的逐月市值對本票的近似市值逐家比,
報兩份名單的對稱差;差超過一成即這條假設不成立。」照做:

- **甲名單** = `universe_smallcap_v1` 的成員(近似市值 = 封面頁股數 × 2026-09-02 現價 < 50 億)。
- **乙名單** = 同一批 5,257 家,用面板 v3 的**時點正確**股數(`filed_date ≤ 2026-09-02` 的最後一列)
  乘價格庫 2026-09-02 的 `close`,再劃同一條 50 億線。
- **對稱差比例** = |甲 △ 乙| ÷ |甲 ∪ 乙|。
- 判:比例 ≤ 10% → A-045 `holds`;> 10% → A-045 `refuted`;
  兩份名單任何一份的可算家數 < 4,000 → `unverified`(量不出),原文照留。

更新一律經 Edit 寫入 `.kira/assumptions.jsonl`,附 `verifiedAt` 與一句指得到出處的證據。

## 十一、誠實聲明(報告首段必寫)

1. **全部數字是倖存者口徑。** 宇宙(5,257 家)全部是今日仍在證監會申報的公司,
   中途除牌、被併購、私有化的一家都不在。基礎率因此系統性偏樂觀,幅度**量不出**。
2. **138 家十倍股本身來自舊的 728 家宇宙**,那 728 家亦全部活到今日。
   所以「覆蓋率」答的是「這個宇宙撈得到幾多**我們看得見的**十倍股」,
   不是「撈得到幾多全部十倍股」。這是盤點,不是預測。
3. **t0 是事後揀出來的最佳起點**(通往十倍的那一格),不是隨機一個月。
   用它算市值,答的是「起飛那一刻有多大」。
4. **市值是近似入位**:封面頁股數是季度快照、拆股因子靠一張只覆蓋舊 728 家的表、
   代號時段表的 confidence 全部是 low。逐家標明用了哪一層、缺哪一件。
5. **面板 v3 不做貨幣換算**:外國申報人的帳目以本國貨幣入面板,所以任何「金額 ÷ 美元市值」
   的比率對它們是錯的;本票只用淨現金的**符號**,不用比率(見第五節)。
6. **`adj_close` 不是不變量**(KARST-171 量到:同一家公司對生產快照的比值 0.9885–0.9939,
   除息日一過就整條序列改寫)。倍數與回撤用 `adj_close` 算,**換一個抓取日重跑會有細微差別**;
   本票的數字綁定價格庫 2026-09-03 這一份。
7. **面板 v3 兩個已知弱點**(KARST-172 報告第零節):財年末的流量格取第四季不是全年;
   `total_debt` 覆蓋只有 41.4%。前者不影響本票(本票只用存量欄),後者是 N2 口徑覆蓋低的原因。
8. **羅素成分史付費**,U1 只是市值帶近似;成交額門檻(KARST-162 的 U4)倉內日線有成交量欄,
   但本票不重開那一格,標「本票不量」。
