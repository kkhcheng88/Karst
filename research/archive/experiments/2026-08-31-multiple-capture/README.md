# 板塊倍數每日存檔件:首次實抓(KARST-124,依 D-084)

2026-08-31 開檔。由今日起,平台每日留得低一份「今日市場肯畀邊個板塊幾多倍」的當日紀錄。

## 一句話講清楚它有什麼用

前瞻市盈率(市場對未來一年盈利的共識,除出來的倍數)**沒有任何免費來源肯給歷史**:
發行商官網每日原地覆寫,今日拿到的就只有今日一個數(KARST-121 勘察結論,
`research/2026-08-31-倍數數據勘察.md`)。所以唯一一條不用畀錢就會隨時間變成資產的路,
是由今日起每日抄低一次——一年之後,我們手上就有一條自己造的、無可爭議的
point-in-time 前瞻倍數序列。**遲一日開始,就永遠少一日,補不回。**

## 每日跑一次(操作句)

在 `C:\projects\Karst` 開 PowerShell,一句:

```powershell
$env:PYTHONUTF8 = "1"; python -m karst.gateway multiples capture
```

- 一日跑一次就夠;**同日重跑安全**——每一格數字都沒變就不會加多一列。
- 週末照跑無妨:發行商的截數日仍是上一個交易日,那一列如實記住「這一日我們見到的是這個數」。
- 跑完想看:`python -m karst.gateway multiples list`(每隻最新一列),
  或 `python -m karst.gateway multiples list --symbol XLK`(某一隻的逐次讀數)。
- 排程本票不做。日後接排程,接的就是上面那一句,不用改任何程式。

## 來源

- **形態**:發行商基金頁面,伺服器直出 HTML,不用瀏覽器、不用鑰匙、不用登記、免費。
- **網址**:`https://www.ssga.com/us/en/intermediary/etfs/<基金英文名連代號>`,
  例如 `.../the-technology-select-sector-spdr-fund-xlk`。代號對網址的對照表逐隻寫死在
  `karst/data/multiples.py`,估不出來的東西不猜。
- **抓哪幾格**:頁面「Index Characteristics」一節取前瞻市盈率 FY1、後顧市盈率、市現率、
  三至五年每股盈利增長預估、成分數;「Fund Characteristics」一節取市帳率、加權平均市值、
  基金層的 FY1、成分數。兩節各自帶發行商自報的截數日,兩個都存。
- **知情滯後**:截數日通常是抓取日的前一個交易日。**日後回測對齊要用截數日,不是抓取日。**

## 存檔的規矩

| 落點 | 是什麼 | 入不入 git |
|---|---|---|
| `vintage/sector-multiples/readings.csv` | 存檔正本,一列一次(抓取 × 代號),17 欄 | **入** |
| `vintage/sector-multiples/說明.md` | 給日後讀這份數據的人的說明 | 入 |
| `vintage/sector-multiples/raw/<抓取編號>/<代號>.html.gz` | 當次原始頁面 | 不入(`.gitignore` 已擋) |

四條規矩:

1. **追加式**:一次抓取寫一列,舊列一個字都不動。
2. **同日冪等**:同日重跑而每一格都一樣,不再寫;**數字變了兩列都留**,以抓取時間戳分辨。
   「同一日之內來源改過數」本身就是關於這個來源的事實,覆蓋掉就查不回。
3. **不寫空值**:任何一格抓不到即整隻不收,並講明是哪一節、哪一欄斷了;
   其餘代號照寫,命令回傳碼非零。
4. **原始頁面先落檔、後解析**:解析當場失敗,`raw/` 內那一日的頁面仍在,
   日後修好解析器由存檔重跑補得回——那一日不會白蝕。

**正本入 git 是刻意的。** 倉根 `/data/` 被 `.gitignore` 擋走,理由寫明是「可重抓的數據」;
這一份的性質剛好相反——今日不抄以後補不回,只住在一部機上等於隨時歸零,所以另開
`vintage/` 一格,正本跟住倉走。原始頁面那一堆體積大(每日約 0.9 MB,一年約 220 MB),
擋在 git 以外;正本每列帶原始頁面的 SHA-256,追溯照指得回,舊的 `raw/` 日後清得走。

## 一項與票面不同的地方,講清楚

票與 D-084 寫「九隻 SPDR + SPY」共十隻;實作抓的是**十二隻**——倉內板塊名單
`SECTOR_ETF_UNIVERSE` 本來就是十一隻,多出來的是 XLRE(房地產)與 XLC(通訊服務)。

理由:這個檔的全部價值在於「今日不抄,以後補不回」。漏了這兩隻,日後板塊計分要用全套
倍數時,這兩格會**永遠**是空白;而多抓兩隻的成本是零。票點名那十隻全部在內,是超集不是
替換。若日後裁定只要十隻,由存檔剔走兩隻是隨時做得到的事;反過來補不回。
