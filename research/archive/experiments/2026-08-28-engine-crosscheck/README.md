# KARST-059 引擎外部對照:獨立手算 vs 引擎,逐日對淨值、逐筆對成交

**結論:引擎通過外部對照。九格全部對得上,規則路徑逐日淨值逐位相同(差 0.0),
排名路徑差在 float64 最後一兩個 bit(2.8e-16)。兩處初期差異都是手算讀錯規約,
不是引擎錯;查證過程見〈差異表〉。**

兩條引擎路徑互相對得上只證明一致,不證明都對。這一票造一把不靠引擎的尺:同一批
K 線,一邊行引擎,一邊行純 pandas 逐日迴圈,兩邊相減。

## 怎樣跑

```
set PYTHONUTF8=1
python experiments/2026-08-28-engine-crosscheck/fetch_data.py   # 抓日線落本目錄
python experiments/2026-08-28-engine-crosscheck/compare.py      # 對照,結果落 results.json
```

## 紀律(票上的硬規矩,逐條做到)

* **不入定義庫、不寫 `data/`、不碰 `karst.sqlite`。** 日線經 yfinance
  (`auto_adjust=True`)抓到本目錄的 CSV;引擎只以記憶體內的 `BarPanel` /
  `PricePanel` 呼叫,不經登記、不經唯一入口。排名路徑因此自己砌目標比重表,
  不行 `run_ranking_rebalance`(那條路要 store)。
* **手算獨立。** `handcalc.py` 一個 `karst` 的東西都不 import,只有 pandas 與 numpy;
  刻意寫成慢版逐日迴圈,與引擎的向量化路徑不同構,撞啱同一個錯的機會低得多。
* **不改引擎程式。** `karst/engine/`、`karst/risk/`、`karst/strategies/` 一字未動。

## 容差怎樣定

票寫 1e-9。淨值在百萬量級,**絕對** 1e-9 等於要求 float64 最後一個 bit 都一樣——
那是在考浮點運算次序,不是在考回測邏輯,兩個不同構的實作沒理由做得到。所以判定用
**相對**誤差 1e-9;結果是規則路徑連這個都用不著(差正好是 0.0),排名路徑差 2.8e-16,
比容差細七個數量級。

賠率門檻 1.5、月度熔斷 6%、本金 100 萬、注碼基數=當下權益、零成本按 D-030)。

## 差異表(第一輪跑出來的兩處,連裁決)

第一輪九格之中兩格對不上。兩處**都是手算錯**,引擎沒有錯:

### 差異 1:熔斷落閘之後有沒有解除 —— 手算錯

* **現象**:rule-E 引擎報 22 個熔斷日,手算只報 1 日。逐日淨值仍然逐位相同
  (那段日子本來就沒有訊號要攔,所以錢沒有分別)。
* **查證**:`MonthlyLossBreaker` 的規約白紙黑字寫住「落閘之後直到下個月第一根
  K 線才解除」。手算把它寫成逐日重判——權益反彈回門檻之上就自動解閘。
* **判定**:手算漏讀規約,引擎照規約行事。已修正手算(加一個閂,月頭才重置)。

### 差異 2:賣出那一根能不能同日再開新倉 —— 手算錯,但規約沒有明寫

* **現象**:rule-F 第 9 筆,引擎 2023-02-06 以 149.894510 入場,手算 2023-02-03
  以 145.434108 入場;之後淨值分家,最大相對差 1.08e-2。
* **查證**:2023-02-03 那一根,舊倉觸目標以 152.822254 賣出。手算把「先離場、
  後入場」寫成同一根之內做得到,於是同日又開一注。但**入場價是開價,離場是開市
  之後才發生的事**——開市那一刻舊倉仍然在手,那一注根本開不成。引擎的做法對。
* **判定**:手算錯。已修正(改為看「開市那一刻手上有沒有倉」)。
* **但這一格規約沒有明寫**:`rules.py` 那份「全倉唯一一份出場規約」講齊了跳空、
  同根兩者皆中、期末未平,唯獨沒有講「賣出當根可否再入場」。引擎的行為是對的,
  但它現時只活在實作裡,不在規約裡——下一個人手寫對照、或者日後換引擎,會再踩
  同一個坑。**建議把這一句補入出場規約的文字。** 這不是引擎錯,所以沒有在票上
  `raised` 舉手,留在這裡與票的〈留言〉。

## 覆蓋不到的地方(誠實交代)

* **多股票的抽籤分現金**:票指定規則路徑用一隻股票,所以 `tie_break_seed` 那條
  「同根多隻齊發訊號、現金不夠分」的路沒有行到。要對那一條,要另開一格。
* **交易成本**:按 D-030 基準情境零成本(手續費與滑點皆為零),所以滑點與兩種
  手續費型別的算式沒有被這次對照驗到。
* **票面窗口單獨看很薄**:50 日回望在 62 根的窗口裡只發得出 3 張訊號、成交 1 筆,
  而且期末未平。真正有力的證據來自 rule-B/F/G 那三格(暖身足、交易多)。
* **數據來源**:yfinance 的已調整價,與倉內快照不是同一份數。這一票對的是引擎的
  **算法**,不是數據管線;數據只要兩邊同一份就夠。
