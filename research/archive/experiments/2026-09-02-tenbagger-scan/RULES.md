## 二、「十倍」怎樣算

- **起點格 t0**:2009-01 起每個月底(取當月最後一個有價交易日),至 2026-08。
- **窗**:3 年 = t0 至 t0 + 3 曆年;5 年 = t0 至 t0 + 5 曆年。
- **倍數** = 窗內收市價最高值 ÷ t0 收市價(**已調整價**,故拆股不影響)。
- **十倍股** = 該公司在該窗長之下,存在任何一個 t0 使倍數 ≥ 10.0。
- **完整窗要求**:只計 t0 + 窗長 ≤ 2026-09-01 的起點格。故 3 年窗的起點年份為
  2009–2023,5 年窗為 2009–2021。窗被截斷的起點格一律不入基礎率分母,亦不入分子
  ——**不准用「未跑完的窗已經升了八倍」當作十倍**。
- 該公司在 t0 必須有價(即已上市),否則該格不入分母。

## 三、分年基礎率

對每個起點年份 Y:

- 分母 = 該年之內至少有一個合資格 t0(有價 + 完整窗)的公司數。
- 分子 = 在該年之內任何一個 t0 達到 ≥10× 的公司數。
- 基礎率 = 分子 ÷ 分母。
- 同時報 ≥2×、≥3×、≥5× 三個門檻作對照。

「全期十倍家數」另計:任何起點年份達標即算一次,分母為全宇宙可測家數。
**注意這兩個數不可互相加總**——分年基礎率的分母逐年重數。

## 四、名單欄位

每家十倍股記:最佳起點日、峰頂日、倍數、峰頂之後的最大跌幅
(峰頂至 2026-09-01 之間最低收市 ÷ 峰頂 − 1)、今日相對峰頂位置、鏈位。

- **鏈位**:`experiments/2026-09-02-chain-layers/chain_membership_v0.csv` 的 `theme` 欄。
- **樽頸**:v0 鏈表**沒有樽頸欄位**,而 A-032 已推翻事後貼樽頸標籤的做法(六個標籤兩個貼錯)。
  本票**不自行事後貼樽頸標籤**,改用一個由帳目生成的客觀代理:
  t0 前三年「資本開支 ÷ 資產」的變化為負(供給紀律),報告只當作代理而非樽頸本身。

## 五、t0 特徵

在十倍股的最佳起點格 t0(月底)取面板值,一律遵守面板第一節的知情時點規則
(`filed ≤ 月底`,首版優先):

| 特徵 | 算法 |
|---|---|
| 起點市值 | 已調整收市價 × **拆股還原後**的攤薄股數。面板股數是申報原值(未還原拆股),價格是已還原,兩者不同尺;故先用 `experiments/2026-09-02-fourpiece-test/data/splits.parquet` 把股數乘上 t0 之後的累積拆股因子,再乘價格。 |
| 前 12 個月股數變化 | 同樣還原拆股後,`diluted_shares(t0) ÷ diluted_shares(t0−12月) − 1` |
| 營業額增速 | `revenue_ttm(t0) ÷ revenue_ttm(t0−12月) − 1` |
| 經營現金流正負 | `cfo_ttm(t0) > 0` |
| 資本開支紀律 | `capex_ttm ÷ assets` 由 t0−36 月至 t0 的變化 |
| 鏈位 | 見第四節 |

**對照組**:同一批起點格上、同一年份、有面板數的**非十倍股**。逐年配對之後合併,
避免「十倍股集中在某幾年」造成的年份混淆。報中位數與四分位,不報平均
(重尾分佈平均無意義)。

**已知拆股表污染**(RULES v2 第九節):CPWR / EP / PARA 三個代號的拆股因子被
後來重用同一代號的公司污染。這三家在市值與股數變化兩欄設缺值。

## 六、迷因過濾器

反例名單(t0 = 各自的狂熱起點,見腳本):BYND、GME、AMC、SPCE、NKLA、RIDE、CLOV。
其中只有 GME 在宇宙內;其餘六家的價格與股數本票另行由 yfinance 抓取
(**這是宇宙沒有的新原料,不是既有原料的副本**),存於 `data/`。

規則各自定義見 `meme_filter.py`,每條報:

- **誤殺率** = 被該規則剔走的真十倍股 ÷ 有齊該規則所需欄位的十倍股;
- **捕捉率** = 被該規則剔走的反例 ÷ 有齊欄位的反例。

**這兩個數不是成績。** 規則是看着名單設計的,即樣本內;報告只作提案,
任何「最佳組合」都必須在未來的新窗上重驗才算數。
