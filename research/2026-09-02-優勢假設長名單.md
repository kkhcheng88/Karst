# 優勢假設長名單(KARST-149)

- 日期:2026-09-02
- 票:KARST-149(research,只讀只寫,不跑回測)
- 用戶新總目標:D-127「持續尋找任何可能的優勢、驗證並不斷改進策略;唯一原則是決策次序由上而下——市況 > 價值鏈 > 個股 > 技術觸發;方法不設限,大膽假設,先做初步存在性證明」
- 本報告不含任何實測結果。所有數字都是文獻量級或本倉已有的舊測結果,逐個附出處與查證日期。

## 結論先行

**過去兩星期我們一共判死了十一條線,但十一條全部死在同一個地方——九隻板塊。** 那個場地只有一點六隻獨立資訊(D-124),意思是就算真有每年兩三個百分點的優勢,在那裏也量不出來。所以現在最要緊的不是再想新訊號,是**換一個量得出的場地**,再在新場地上重試。

本報告列出二十六條未走過的假設(市況 6、價值鏈 8、個股 6、技術觸發 6),並提出三項貫穿全部測試的方法更正:

**價值鏈層按用戶 2026-09-02 的兩次指示重寫。**先是修正定義(D-129),稍後再補分層方法(D-130):**分類方法由 agent 自定,舊倉那張人手表只作對照;敘事分組應該是所有優勢的起點。**用戶的判斷是:人工智能時代的優勢更多在非結構化的文本資訊,按「故事」分組比按 GICS 分組更有價值。所以本節的量法主線改為**用按申報日定格的申報文本做機器分層**,GICS 只留作對照。而「同層反應是否真的比 GICS 同組更相似」這一格已另開 KARST-152 在做,本報告不重複,一律當作待驗證假設 A-037,凡建基於「層是真的」的假設都寫明依賴它。

**原修正定義(D-129)照舊有效:**價值鏈 = 產業鏈,鏈再分「層」,**一層 = 在鏈上佔同一位置、被市場講同一個故事的一群公司,行業有任何消息時同層受到的衝擊非常相似**。這句定義最要緊的一點是:它把「層」由一個分類問題,變成一個**量得出的問題**——我們不必爭論哪家公司該歸哪一層,只需要問「這批公司對同一則消息的反應是不是真的相似」。而倉內剛好有一張在無人量過這件事之前就凍結的第一版人手分層表(33 條鏈位、138 個代碼),可以直接拿來驗。

1. **存在性測試改用「排名相關度」,不要用組合回報。** 用組合回報去證明一件事存在,在十七年的資料上需要每年五個百分點的優勢才看得見;用同一批資料算每月的排名相關度,一個每年只值三、四個百分點的訊號一樣看得見。分別是二百一十二個月各自算一次,還是十七年只算一個總數。
2. **先證「存在」,才談「收得到」。** 存在性測試一律用「最好那批 vs 最差那批」的對照,不設交易成本、不設六隻上限;過了這一關才拿去問「揸六隻收不收得到」。過去幾張票把兩件事綁在一起做,結果是集中度懲罰把訊號淹沒,分不清是訊號無用還是器皿太窄(D-115/D-118/D-121 三票都吃過這個虧)。
3. **歷史長度是最便宜的解析度。** 市況層的訊號只需要指數,而指數免費歷史有七十六年。同一條規則用 2004 年起的資料要每年 3.7 個百分點才測得出,用 1950 年起的資料只要 2.0 個百分點。這一格幾乎零成本,但我們一直只用 2004 年起那批。

**四層之中,我認為最值得先開的三條是:①價值鏈層的可行性關卡(它一過,是我們唯一一個從未量過的新場地);②個股層的年報文字改動(倉內沒有、但免費拿得到,文獻量級是全份名單最大的一條);③技術觸發層的分批換馬(它直接攻擊我們已經量出來的那筆最大開支)。** 詳見第七節。

**同時要講清楚一件不好聽的事:這份名單上有六條,文獻自己已經說它們近十幾年衰減甚至消失了**(FOMC 週期、應計項目、大型股的盈利公布後漂移、業績公布月溢價、波動率管理組合、客戶動量)。我照樣把它們寫進來並標明,是為了讓下一個人不用再查一次;它們排在名單後半,不是前八條。

## 第零節:三項方法更正(先看這節,後面每條假設都建基於它)

### 0.1 偵測地板:同一批資料,問法不同,地板差三倍

D-124 量出的「每年 3.6 個百分點」是這樣算出來的:九隻板塊、每月揀三隻、2013 年後、只做多。這個地板高,是因為那個設計把幾乎所有可用資訊都丟掉了。

同一批資料換三種問法,地板如下(粗算,用於排優先次序,不是判準):

| 問法 | 觀察數 | 大約偵測地板(t=2) |
|---|---|---|
| 九隻板塊、每月揀三隻、只做多、2013 年後(D-124 實況) | 約 150 個月 × 1.6 隻有效 | 每年 3.6pp |
| 718 家股票、每月十分位長短倉、2009 年起 | 212 個月 | 每年約 5pp(長短倉月度波幅約 3%) |
| 718 家股票、每月排名相關度、2009 年起 | 212 個月 × 每月數百家 | 排名相關度約 0.015(對應每年約 2–3pp) |
| 大市擇時、2004 年起(本倉現有日線) | 22 年 | 每年約 3.7pp |
| 大市擇時、1950 年起(免費指數) | 76 年 | 每年約 2.0pp |

**讀法:**同一條訊號,用「排名相關度」問比用「組合回報」問,靈敏度大約高一倍;市況層把歷史由二十二年拉到七十六年,靈敏度也高接近一倍。兩件事都不用多買任何數據。

### 0.2 「存在」與「收得到」要分開兩關

- **第一關(存在):**長短倉或排名相關度,零成本、零上限、全樣本。判準只有一條——這個訊號有沒有攜帶資訊。
- **第二關(收得到):**在第一關過了的訊號上,才加六隻上限、加 15bp 成本、加現實換馬節奏,量剩下多少。

D-121 已經量出第二關的價格:揸六隻的拖累等於持倉自己的月度半方差,由平穩股的 0.82pp 到深度價值股的 5.61pp,而基準自己也在交 1.24–2.72pp。所以第二關的真實門檻是「差額」,不是絕對值。這一格以後每張票都要照這樣寫。

### 0.3 倖存者聲明(全份報告通用)

- 帳目面板:1,209 個歷史成分股之中,只有 718 家入面板;487 家連公司編號都查不到,完全缺席;另有 84 家有帳目但沒有股價(其中 81 家已除牌)。2010 年之前除牌的 361 家不可能補回(D-125)。
- 日線價格檔:597 隻要求、584 隻拿到,而名單來自今日仍在的成分股為主。
- **後果:**個股層與價值鏈層的一切結果都偏樂觀,而且是系統性偏向「活下來那批」。凡報數必須同時報「這批數是在 718 家上面量的,不是在真實宇宙上量的」。
- 市況層與技術觸發層用指數與 ETF,不受此限。

### 0.4 行業分類的前視風險(A-029,現在有便宜的修法)

A-029 至今未查證:行業分類用的是今日的快照回溯,若前視偏差夠大,個股層「行內排名」的結論全部白做。

**本票新發現的修法:**美國證監會每一份申報的檔頭都帶當時的行業代碼(SIC),而本倉已經快取了 698 份公司帳目原檔與 101 份申報清單。用「申報當日的行業代碼」代替「今日的行業分類」,就得到真正的知情時點分類,免費、幾小時內做得完。這一格應該在任何「行內排名」測試開跑之前補上。

## 第二節:市況層(六條)

市況層的共同優勢:只用指數,沒有倖存者偏差,而且免費歷史深達 1950 年——把偵測地板由每年 3.7 個百分點降到 2.0 個百分點,零成本。

共同限制:D-049 已經判死四個**價格系**開關。所以本層六條之中,四條刻意用非價格材料(宏觀、持倉、日曆),兩條用價格但換了函數形態(連續刻度、非單調)。

---

### M1 — 宏觀狀態開關(失業率趨勢),非價格

| 格 | 內容 |
|---|---|
| **假設** | 當美國失業率升穿自身十二個月移動平均、**同時**大市跌穿十個月線,才轉守;只有其中一隻腳響時不動。這條非價格的腳可以濾走 D-049 那批價格開關的假警報。 |
| **為何存在** | 誰在犯錯:價格開關的失敗不是因為它判錯方向,是因為它每年響很多次,而真正的熊市十年只有一兩次。失業率的趨勢是**慢變數**,七十年只轉向十幾次,它的職能是「否決」而不是「發起」——把價格開關的假警報濾走。誰被迫交易:真正的熊市由盈利下修與去槓桿驅動,而兩者都跟就業週期同步。 |
| **量級與來源** | 未找到直接對應的同儕審查文獻量級(查證 2026-09-02)。最接近的是 Gilchrist & Zakrajšek (2012, *American Economic Review* 102(4), 1692-1720) 證明信貸溢價對經濟活動有預測力;業界的「Growth-Trend Timing」做法廣為流傳但無期刊來源。**量級未找到,不准估數——這條要靠自己量。** |
| **數據** | 免費。美國聯儲經濟數據庫(FRED)UNRATE 由 1948 年起月度、ICSA 初領失業金由 1967 年起週度,無鑰匙。指數用 yfinance ^GSPC 1950 年起。抓取成本:幾分鐘。 |
| **偷看** | 中度風險,必須處理:失業率有發布滯後(當月數字下月初才出)且**會被修訂**。做法:一律用「發布日 + 一日」才生效,並用 FRED 的 ALFRED 版本序列核對修訂幅度。這一格不做好,整條線的成績是假的。 |
| **倖存者** | 零(指數與宏觀序列)。 |
| **化身** | 要查:它會不會只是「十個月線」的化身。防法:三臂對照——單十個月線 / 單失業率 / 兩腳齊響,量增量。 |
| **測試設計** | 1950–2026,月度。四臂:①乾坐;②十個月線;③失業率趨勢;④兩腳齊響。**存在** = 第四臂的年化回報高過第二臂 ≥1.5pp **而且**最大跌幅淺過第二臂 **而且** 1950–1990 與 1990–2026 兩半皆為正。**不存在** = 第四臂相對第二臂的增量 <0.5pp,或任一半為負。約 2 小時。 |
| **分辨力** | 高(912 個月;地板約每年 2.0pp)。 |
| **把握** | 中。機制講得通、成本近零,但沒有文獻量級撐腰,而且轉向次數少(七十六年只十幾次),所以就算贏也會贏得有點靠運氣——這一點要在報告寫明。 |

### M2 — 總體短倉比率預測大市(非價格,免費)

| 格 | 內容 |
|---|---|
| **假設** | 全市場的總短倉比率(所有股票的短倉股數 ÷ 流通股數,取橫截面平均)升高之後,未來一年大市回報偏低;降低之後偏高。用作三態機第一態(風險開 / 關)的**主訊號**,不是確認腳。 |
| **為何存在** | 誰在犯錯:賣空者是市場上資訊最好的一群(他們要付借券費、承受無限下行,不會為好玩而做),而總體短倉比率把他們的集體判斷聚合成一個數。這不是情緒指標,是**知情交易者的持倉**。 |
| **量級與來源** | Rapach, Ringgenberg & Zhou (2016), *Journal of Financial Economics* 121(1), 46-65:總體短倉比率是目前已知最強的大市回報預測變數之一,年度樣本內 R² 12.89%、**樣本外 R² 13.24%**;對均值方差投資者每年帶來超過 300 個基點的效用增益。樣本期 1973–2014。(查證 2026-09-02) |
| **數據** | 免費。美國金融業監管局(FINRA)官方端點 `https://api.dapi.finra.org/api/EquityShortInterest/GetESI?settlementDate=...`,回傳 CSV/JSON,無需認證,**每個結算日一個請求就拿到全市場快照**。每月兩次結算,公布滯後約 7–8 個工作日。歷史深度:納斯達克那份 2007-09 起完整;FINRA 那份要實測。抓取成本:約 400 個結算日 = 400 個請求,幾分鐘。 |
| **偷看** | 低但要處理:必須用**公布日**而非結算日作為生效日(滯後 7–8 個工作日)。原論文用的是年度資料與去趨勢處理,我們要用月度版本,去趨勢的方法必須在看結果之前寫死(否則就是在挑一個好看的去趨勢窗)。 |
| **倖存者** | 低。橫截面平均會隨成分變動,但不涉及「揀贏家」。 |

### M4 — 月末/月初的日曆結構

| 格 | 內容 |
|---|---|
| **假設** | 大市的月度回報高度集中在「上月最後一日至本月頭三日」這個窗口;窗口之外的二十天合計接近零。因此把月度調倉由「月底最後一日成交」改為「窗口過完之後成交」,可以避開在最貴那幾日入貨。 |
| **為何存在** | 誰被迫交易:退休金供款、基金分派、指數再平衡全部集中在月末月初,而且日期完全可以預先知道。Etula 等人的說法更精確——機構月底前為應付現金流需要淨賣出(所以月末前先跌),月初資金再投入後價格回升。這是**日程表造成的被迫交易**,不是任何人判斷錯。這是全份名單機制最乾淨的一條。 |

## 第三節:價值鏈層(產業鏈與「層」)

### 3.0 定義(用戶 2026-09-02 修正,以此為準)

用戶原話:「value chain to me is 產業鏈, and if you refer to KarstETF value chain can further break down into layers, it is defined as at 1 layer with companies sharing the same position with the same story or narrative in the market. So if any news or any update of the industry, the same layer will have very similar impact. So the same layer should be also the same business or position of 上下遊」

拆成三句白話:

1. **價值鏈 = 產業鏈。**由原材料到終端用戶,一整條上下游。
2. **產業鏈再分「層」(layer)。**一層 = 在鏈上佔同一個位置、而且在市場上被講同一個故事的一群公司。
3. **層的判別式是「反應」,不是「分類」。**行業有任何消息或更新,同一層的公司受到的衝擊**非常相似**。

第三句是本節全部設計的支點:**它把「層」由一個分類問題變成一個可以驗證的問題。**我們不需要爭論某家公司該歸哪一層,我們只需要問:「這批公司對同一件消息的反應是不是真的相似?」相似就是同一層,不相似就不是——無論分類表怎樣寫。

（詞彙表要新增「鏈層(chain layer)」一條,但本票只讀不改既有檔,已在收檔留言舉手交主 agent 處理。）

**第一版人手分層表已經在倉內。**主 agent 於 2026-09-02 由舊倉 KarstETF(2026-08-15 停案)原檔複製入 `experiments/2026-09-02-chain-layers/chain_membership_v0.csv`(UTF-8 BOM,讀取用 `encoding="utf-8-sig"`)。本票實查內容:

- 143 列、6 欄(`theme` / `ticker` / `valid_from` / `valid_to` / `role` / `note`),**33 條鏈位**、138 個唯一代碼(其中 `valid_to` 空白的現役代表 98 個)。
- 角色分布:core 137、weak_witness 5、strong_witness 1。
- 最大幾條鏈位:鈾與核電 7、雲端軟件 7、國防 6、加密 6、串流 6;最小的只有 1–2 個代表(大麻 1、小型模組化核電 2、元宇宙 2)。
- 舊倉的歸層機制:由語言模型讀業務描述與分部收入做窮盡分類並附引文核對,再由分析員依四步規則(純度閘 → 方向測試 → 代表性測試 → 市值排序)定代表,然後鎖死名單。
- **最關鍵的一句(README 自認):「同層對同一消息反應相似」這一條,舊倉只有質性的「方向測試」,從未做過統計量度。**所以這是一張**待驗證的標籤**,不是已驗證的分層。

**這張表為什麼特別有用:**它是在**沒有人量過反應相似度之前**就凍結的。即是說,用它來測「同層反應是否真的相似」,標籤本身沒有被結果餵過——這在本倉是罕見的乾淨起點(對比 A-032:事後印象標籤 6 個之中 2 個被文本自身推翻)。

**它的兩個必須聲明的缺陷:**①`valid_from` 大多是 2022-01-01 這種回填日期,而表在 2026-08 才凍結,所以**哪幾條敘事「重要到值得開一條鏈位」這個選擇本身帶後見之明**——這會令回報類的測試偏樂觀,但對「共同波動」類的測試影響較小(知道 Nvidia 後來升了,不會令 Nvidia 與 AMD 更同步)。②表內多條鏈位(量子、大麻、加密、鈾)的成員不是標普 500 成分股,倉內日線 584 隻大概率覆蓋不到,要用 yfinance 補抓(免費,幾分鐘)。

### 3.1 「層」與 GICS 子行業的分別(這一格必須講清楚)

這是全節最容易出事的地方:如果「層」最後只是 GICS 子行業的另一個名字,那麼整個價值鏈層就是板塊層的重演,而板塊層已經判死十一條線。

四個實質分別:

| | GICS 子行業 | 層(layer) |
|---|---|---|
| **依據** | 公司**賣什麼**(產品與服務的分類) | 公司在鏈上**站在哪個位置** + 市場**講它哪個故事** |
| **會不會橫跨** | 不橫跨——一家公司只屬一個子行業 | **會橫跨子行業**:半導體設備商、電力設備商、資料中心冷卻商在 GICS 分屬三個不同子行業,但在「人工智能基建」這條鏈上,它們站同一個位置、對同一則資本開支消息反應相同 |
| **會不會分拆** | 不分拆——同一子行業的公司歸同一格 | **會分拆一個子行業**:同屬「半導體」子行業的設備商與晶片設計商,在鏈上是上下游兩層,一則產能消息對兩者是相反方向 |
| **會不會變** | 幾乎不變(公司轉型才改) | **會變**:同一家公司可以在幾年之內由「舊經濟電力設備」被重新講成「人工智能基建」,層籍隨敘事改變而改變 |

**具體例子(說明用,不是已核實的分層):**GICS 把 Vertiv、Eaton、伊頓的同業歸入「電氣設備」,把台積電歸入「半導體」,把 Nvidia 歸入「半導體」。但按層的定義,Nvidia 與台積電是「晶片供應」層的上下游兩格,而 Vertiv 與 Eaton 與資料中心建設商同屬「基建與供電」層——後者三家在 GICS 分屬三個子行業,卻對同一則「某超大型雲服務商上調資本開支」的消息反應幾乎一樣。這正是 GICS 抓不到而層抓得到的東西。

**這個分別帶來一個可以驗證的預言:**若「層」是真的,那麼**同層的事件日反應相關度,應該顯著高過同 GICS 子行業的事件日反應相關度**。這就是 V1 的測試。

### 3.2 量法:三步,由粗到細

「層」不能只靠人手指定(那樣就沒有可檢驗性),也不能純靠統計聚類(那樣就變成數據挖掘,而且挖出來的東西沒有故事)。所以量法是**先用結構提出候選層,再用反應驗證它,最後與 GICS 對照證明它不是子行業的別名。**

**第一步:提出候選層——主線是文本機器分層(D-130 修訂)**

**主線:用按申報日定格的文本做機器分層。**做法三句講完:①由證監會 EDGAR 抓每家公司每年 10-K 的業務描述(Item 1)與 MD&A,**以申報日為生效日**;②把每份文本轉成向量,逐年做一次分群,得出「該年的層」;③層籍逐年重算,同一家公司可以換層——這正是用戶定義裏「敘事會變」那一句的機器版本。成本:文本抓取免費(每秒 10 次上限),向量化用本機開源模型零成本,全流程一到兩日。

**為什麼這是主線而不是人手表:**用戶 D-130 明講「敘事分組應該是所有優勢的起點」,而人手表只有 33 條鏈位、138 個代碼,覆蓋不到全市場,亦沒有逐年重算的能力。文本分層兩樣都做得到。

**人手表 `chain_membership_v0.csv` 的角色改為對照組:**它是一張在無人量過反應相似度之前凍結的乾淨標籤,所以它的用途是**替機器分層打分**——機器分出來的層,若在人手表覆蓋得到的那 33 條鏈位上與人手表大致吻合,機器分層就通過了合理性檢查;若機器分層的反應相似度**贏過**人手表,就證明機器分層有獨立價值。**不要改動這個檔。**

**這一步唯一的偷看陷阱,寫在這裏免得日後犯:**文本必須用申報當日那一版,不可以用今日的公司描述;分群不可以用回報做輸入(否則就是用結果分組);層的名字可以事後起,**成員名單不可以事後改**。

以下三個免費來源降為**輔助**用途:一是為層補上「誰在誰上游」這個方向(文本分群給得出「同層」,給不出「上下游」),二是擴闊成員名單。

- **來源 A — 投入產出表(BEA)。**`bea.gov/industry/input-output-accounts-data`,免費無鑰匙,基準表 1947 年起、2007 年起逐年更新,粒度三層大致對應 2 / 4 / 6 位 NAICS 碼。用途:給出**鏈上的位置**(誰在誰的上游)。缺點:只到行業層,而且 NAICS 對 SIC/GICS 的映射有雜訊。成本:半日。
- **來源 B — 文本垂直網絡(Hoberg-Phillips 的 VTNIC)。**免費下載,做法是把投入產出表的商品文字描述與上市公司年報描述業務產品的文字算相似度,得出行業間垂直關聯度。**這個來源與層的定義最貼近**——它同時帶「位置」(垂直)與「說法」(文本),而且有逐年版本,不會前視。成本:半日。
- **來源 C — 年報自述的敘事(EDGAR 全文搜尋)。**`https://efts.sec.gov/LATEST/search-index?q=...`,可用 `forms=10-K` 與日期範圍篩選,免費無鑰匙,全文索引 **2001-05-04 起**,單次最多回 100 筆、`from+size` 上限 10,000(要按日期分段),速率上限每秒 10 次。用途:抓「同一批敘事關鍵詞」(例如把年報裏同時提到某條鏈的關鍵詞的公司歸為候選同層)。**這一步正好解決「敘事會變」這個問題**——年報是逐年的,所以層籍也是逐年的。成本:半日到一日。

**已知的死路,不要走:**用「誰是誰的具名客戶」去砌鏈。會計準則 ASC 280-10-50-42 只要求披露「有一個客戶佔收入 ≥10%」這件事、金額與所屬分部,**明文寫毋須披露該客戶身份**;證監會 2020 年 11 月生效的 Regulation S-K Item 101(c) 修訂亦已把原本較貼近具名的要求改為原則導向。Cohen & Frazzini 原文靠的是要付費的 Compustat 分部檔,1998 年之前還要靠字串匹配加人手核對。**免費自動砌具名鏈一定會斷。**(唯一例外見 V5——那條只需要百分比不需要名字。)

**第二步:用「反應」驗證候選層(這是量法的核心;人手表那一半已由 KARST-152 承接)**

**先講分工:**「同層殘餘回報相關度是否顯著高過同 GICS 子行業」這一格,已經另開 KARST-152 在做(用按申報日定格的 10-K 業務描述做機器分層)。本報告**不重複這一格**,一律把結論當作待驗證假設 **A-037**。下面兩步保留在這裏,是因為它們是任何一版分層都要過的同一道關;差別只在標籤由誰出。

按用戶的定義,層的真偽只有一個檢驗:同一則行業消息,同層公司反應是不是相似。操作化成三個可算的量:

- **事件日反應相關度:**在該鏈的重大事件日(例如龍頭公司的業績公布日、行業重大新聞日),量同層成員當日超額回報的兩兩相關。
- **共同成分佔比:**用主成分分析,量同層成員回報的第一主成分解釋多少方差(層若是真的,這個比例應該高)。
- **對照組:**同一批公司按 GICS 子行業重新分組,重複上面兩個量度。**層要贏子行業,才算證明了層是一件獨立的東西。**

**第三步:與 GICS 對照,證明層不是子行業的別名**

除了上面的反應對照,還要量兩個結構指標:①每一層橫跨幾多個 GICS 子行業(若中位是 1,層就是子行業的別名,整條路收檔);②同一個 GICS 子行業被分拆到幾多層。**這兩個數字是判別式,不是描述性統計——它們決定整層要不要繼續做。**

**建議次序:**第一步先做來源 B(VTNIC,最貼定義且成本最低),來源 A 補位置,來源 C 留到第二步驗證通過之後才做(它最貴)。第二步與第三步一次跑完,即 V1。

|---|---|
| **假設** | 如果用戶的定義是對的(同層公司對同一消息反應非常相似),那麼**在同一層之內揀股票,可加的價值接近零**——因為同層成員的回報差異絕大部分是雜訊,不是可預測的東西。錢住在「揀哪一層」,不在「層內揀哪一隻」。 |
| **為何存在** | 這不是「有優勢」的假設,是**「優勢不在哪裏」的假設**,而後者的價值一樣大:它決定我們該把力氣放在哪一層。D-112 的憲法現時是「板塊層劃賽道、個股層揀贏家」;若本條成立,重心應該再往上移一格——賽道要劃得更細(到層),而層內只需要用最粗的規則(例如買該層最大那幾隻、或者等權買齊)就收得到絕大部分的錢。這正好與 D-115/D-118/D-121 三票的結果吻合:換完全相反的選股風格(深度價值對動能),六隻組合的波動懲罰只差 0.26pp,即懲罰是規則中性的——那批測試一直量不出選股規則的分別,可能不是因為規則不好,而是因為**分別本來就很小**。 |
| **量級與來源** | 未找到對應的同儕審查文獻(查證 2026-09-02)。本倉自有的間接證據:D-118 量出動能族與深度價值族的波動懲罰 3.81 對 4.07pp(差 0.26pp);D-120 量出十倍股的 12 項事前判別指標零統計顯著;D-121 量出親手揀的每注平均輸乾坐 SPY 0.20pp/月。 |
| **數據** | 倉內全部已有:日線 + `chain_membership_v0.csv`(只讀),零額外成本;缺席代碼用 yfinance 補抓幾分鐘。 |
| **偷看** | 零(這是方差分解,不是預測)。但層籍帶後見之明(見 V1 偷看格),所以「層佔方差」那一格會偏高——即本條假設會顯得比真相更容易成立,方向不利,要聲明。 |
| **倖存者** | 高(584 隻),而且方向不利:除牌者不在裏面,會**低估**層內離散度,即令本條假設看起來更容易成立。這一格要老實寫明。 |
| **化身** | 不適用。 |
| **測試設計** | 2004–2026 月度。把每隻股票的月度回報分解成三份:大市 + 層 + 個股殘差,量三者各佔方差幾多。再做一個上限測試:**假設事後全知**,在每層之內完美揀出最好那一隻,相對「該層等權」多賺幾多(即層內選股的獎品上限,照 D-050 的做法,並依 D-116 連帶一條笨規則實測核對)。**成立(即層內選股確實無用)** = 個股殘差佔方差 <35% **而且**層內完美選股的上限年化 <8pp(對比 KARST-139 量出的全市場完美選股上限 1,190%——一個小得多的上限就代表這一格不值得投入)。**不成立** = 個股殘差佔方差 >55%,或層內完美選股上限 >20pp(那就代表層內仍有大量可爭取的空間,D-112 的個股層要保留)。約 2–3 小時。 |
| **分辨力** | 高(方差分解是硬統計;上限曲線在本倉已做過三次,做法成熟)。 |
| **把握** | 中高。**這一條無論答案是「成立」還是「不成立」都直接改寫架構**:成立就把力氣由個股層搬去分層,不成立就證明個股層值得保留。而且它便宜、快、結論確定。注意 D-118 已把「規劃曲線三次核對三次嚴重高估」寫入紀律,所以上限那一半必須照 D-116 連帶笨規則實測。 |

### V4 — 層內掉隊者補漲

| 格 | 內容 |
|---|---|
| **假設** | 與 V3 相反的一面:同一層之內,若某一隻在該層的共同衝擊之後**反應明顯弱過同層其他**(例如同層平均升 8%,它只升 2%),之後一至三個月會補上來。 |
| **為何存在** | 誰在犯錯:層的定義本身就說「同一則消息對同層衝擊相似」。所以當同層之中有一隻明顯沒有跟上,只有兩個可能——(甲)市場對它有另外的、真的壞消息(那就不應該補漲);(乙)只是資金流與注意力先去了龍頭,散戶與被動資金要幾星期才輪到它(那就會補漲)。**這條假設押(乙)在中小型成員身上佔多數。**這也是散戶結構性可以做的事:機構要買流動性,所以先買龍頭;我們沒有這個限制。 |
| **量級與來源** | 未找到針對「層內掉隊者補漲」的同儕審查量級(查證 2026-09-02)。方向上與 Cohen & Frazzini / Ali & Hirshleifer 那一族「資訊沿關聯網絡緩慢擴散」的機制一致,但那幾篇量的是跨公司而不是層內。 |
| **數據** | 倉內日線 + `chain_membership_v0.csv`(只讀),零額外成本;缺席代碼用 yfinance 補抓。**注意成員數:**33 條鏈位平均只有 4 個代表,「同層中位」在 4 個成員上算出來很粗糙,實際只有成員 ≥5 的那十來條鏈位做得出這條測試。 |
| **偷看** | 零(只用過去回報)。 |
| **倖存者** | **高風險,而且方向不利:**掉隊之後永遠沒有補上、最後除牌那批正正不在 584 隻裏面,所以本條的成績會被系統性高估。這是全份名單裏倖存者偏差咬得最深的兩條之一(另一條是 M6)。結論只能讀方向,不能讀水平。 |
| **化身** | 高風險:這條與「短期反轉」幾乎同形,而短期反轉在板塊層已被劃走(D-104)。**但兩者有一個實質分別:**短期反轉是「跌得多的反彈」,本條是「同層都升了它沒升的補上」——後者要求有一個共同衝擊作參照。防法:必須加對照臂,量純短期反轉(不看層)的成績,若兩者成績相若,即判為短期反轉化身,收檔。 |
| **測試設計** | 2004–2026 月度。定義掉隊 = 過去一個月該股回報減同層中位回報,落在最低十分位。三臂:①掉隊者買入;②同層領先者買入(對照方向);③不看層的純短期反轉(化身對照)。**存在** = 掉隊臂之後 1–3 個月的超額 ≥1.5pp,**而且**明顯強過純短期反轉臂(至少高一倍),**而且**領先者臂為負或接近零(即方向對稱性合理)。**不存在** = 掉隊臂超額 <0.5pp,或與純短期反轉臂成績相若。約 3 小時(V1 做完之後)。 |
| **分辨力** | 中高(每月每層都有掉隊者,事件數多)。 |
| **把握** | 中低。機制講得通、與層的定義直接扣連、成本低;但它與已被劃走的短期反轉同形,而且倖存者偏差正好咬在關鍵那格。**應該與 V3 一齊做**——兩條是同一枚硬幣的兩面,V3 說層內沒有可揀的東西,V4 說有一種特定的層內錯配可以揀,兩條的答案合起來才完整。 |

### V5 — 對單一下游層的依賴度,作風險欄(不是超額訊號)

| 格 | 內容 |
|---|---|
| **假設** | 收入高度集中在單一下游層(或單一大客戶)的公司,不是回報較高或較低,而是**該下游層轉弱時跌得更深**;所以它應該當成 D-112「劃賽道」職能裏的一條風險欄(剔走),不是排名分數。 |
| **為何存在** | 誰在犯錯:市場在平常日子低估了「失去一個大客戶 / 下游整層減資本開支」這件事的尾部風險,因為它很少發生;但一旦下游那一層轉弱,這批公司的營業額是斷崖式而非漸進式下跌。Hertzel 等人已證:客戶破產前後,供應商錄得顯著負異常回報,而且反過來(供應商破產拖累客戶)沒有顯著證據——**不對稱**。用層來講更清楚:一家公司若整條收入線只服侍一條鏈位,它就沒有第二條腿。 |
| **量級與來源** | Dhaliwal, Judd, Serfling & Shaikh (2016), *Journal of Accounting and Economics* 61(1), 23-48,樣本 44,218 個供應商年度觀測、1981–2011:客戶集中度愈高,供應商股本成本愈高(即市場要求更高風險溢價);但若集中在政府客戶則相反(聯邦政府客戶佔收入 ≥10% 者股本成本低 19.1 個基點)。Hertzel, Li, Officer & Rodgers (2008), *Journal of Financial Economics*。Barrot & Sauvagnat (2016), *Quarterly Journal of Economics* 131(3), 1543-1592:受災供應商令客戶銷售增長下跌約 2 個百分點。(查證 2026-09-02) |
| **數據** | 證監會全文搜尋找「accounted for approximately X% of net sales」這類句式,只需要**百分比**不需要客戶名字——所以 ASC 280 那個「毋須具名」的缺口**不影響這一條**。這是自砌客戶鏈那條死路上唯一走得通的一格。下游層的轉弱用 V1 的鏈位等權回報量。 |
| **偷看** | 低:年報是公開申報,用申報日生效。 |
| **倖存者** | 高:失去大客戶而倒閉的公司正是不在面板裏那批,所以這條的真實效應**被低估**。方向上有利(我們會低估風險欄的價值,不會高估)。 |
| **化身** | 低:客戶集中度與規模、動量、價值都不是同一件事。要查的是它會不會只是「小型股」的化身(小公司客戶自然較集中)——防法:在同一規模組內比較。 |
| **測試設計** | 抽 100–150 家、2015–2024,用全文搜尋抽出客戶集中度百分比。量兩件事:①集中度高低兩組的平均回報(預期無差);②兩組在 2018Q4、2020Q1、2022 三個下跌窗的跌幅差。**存在** = 三個下跌窗之中至少兩個,高集中度組跌深 ≥3pp,而平常日子的回報差 <1pp/年(即它是風險欄不是 alpha)。**不存在** = 跌幅差 <1pp,或高集中度組平常日子回報明顯較高(那就變成風險溢價,是另一個故事)。約 4 小時(抽樣抓數為主)。 |
| **分辨力** | 中低(只有三個下跌窗;抽樣 100–150 家)。 |
| **把握** | 中。文獻方向硬、數據缺口剛好不咬這一條、而且它服務的是已經寫進憲法的「風險欄」職能(D-112)。扣分在下跌窗太少。 |

### V6 — 上游成本衝擊到下游層毛利的時滯

| 格 | 內容 |
|---|---|
| **假設** | 上游投入成本(用生產者物價指數的分項作外生衝擊)急升之後,下游層的毛利率在第二至第四季才受壓;而股價在這個時滯期間**反應不足**——即衝擊發生時股價未跌夠,毛利真的塌下來時才補跌。 |

| **測試設計** | 2009–2026,約 300–400 家有毛利數據的公司。定義「投入衝擊」= 對應生產者物價指數分項的三個月變化落在歷史最高十分位。量:衝擊後第 1、2、3、4 季的毛利率變化,以及衝擊後 0–3 個月與 3–12 個月的股價超額回報。**存在** = 毛利在第 2–3 季顯著下滑(≥50 個基點)**而且**股價的負超額主要落在 3–12 個月而非 0–3 個月(即反應不足)。**不存在** = 毛利無系統性下滑,或股價負超額集中在 0–3 個月(即市場當日已定價完)。約 4–5 小時。 |

### V8 — 層級敘事轉折:同層文本由「需求」轉向「供給受限」(D-130 新增)

| 格 | 內容 |
|---|---|
| **假設** | 一條鏈層的**集體敘事**會轉向,而轉向本身可以由文本量出來:當同一層之內、同一季之內,**多過一半成員**的申報文本由「需求 / 訂單 / 市場擴張」語言,轉為「產能 / 交貨期 / 供貨受限 / 配額」語言,該層在其後一至兩季的回報高過其他層。反方向(由供給受限轉回需求語言)預告該層回報轉弱。 |
| **為何存在** | 誰在犯錯:①**敘事轉折是層級的,但文件是公司級的。**每一份年報只講自己一家,沒有人把同層十家的措詞放在一起看,所以「整層同時開始講產能不夠」這件事在市場上沒有一個現成的觀察者。②**這是定價權易手的時刻。**需求語言人人都講,產能語言只有真的賣得斷貨的行業才講得出——它是一個難以偽造的訊號。③誰被迫交易:被動指數與板塊 ETF 按 GICS 買賣,敘事層根本不在它們的座標系裏,所以層級轉折不會被指數資金即時定價。 |
| **量級與來源** | **未找到直接對應的同儕審查文獻(查證 2026-09-02)。**最接近的三支旁證:Cohen/Malloy/Nguyen (2020, *JF*) 證明年報**措詞改動**本身有預測力(月度 188 個基點);Hoberg & Phillips 證明文本可以造出比 GICS 更有解釋力的行業;本倉 KARST-142 樽頸文本原型在封存尺下命中 2/6、零誤報(D-119)。**三者都不是本假設本身的量級,不准當成本條的預期值。** |
| **數據** | 證監會 EDGAR 10-K / 10-Q 的 Item 1 與 MD&A(免費,每秒 10 次);層籍用 KARST-152 的機器分層(A-037 待驗);語言分類用本機開源模型或關鍵詞尺,零邊際成本。倉內已有樽頸文本快取原型 12 份可作起步。 |
| **偷看** | **這是本條最大的風險,防法要寫死三條:**①文本一律以**申報日**生效,不是財政期末;②層籍用當年那一版,不可以用今日的分層回頭套落 2015 年;③**事後命名的故事不准回頭分組**——「人工智能基建」這個名字可以是今日才有的,但 2015 年誰算同層,必須由 2015 年那批文字決定。語言尺本身若用今日的語料調過,要另作聲明。 |
| **倖存者** | 高:只有仍在的公司才有連續多年的申報文本,講完供給受限之後倒閉的那批會被自動剔走,會**高估**效果。要聲明。 |
| **化身** | 中:可能只是行業動量或樽頸文本(V7)的化身。判別式有兩個——①**它必須是層級同步的**:同一層之內單獨一家講產能不夠沒有效,要多過一半成員同時講才有效(這一條純動量做不到);②控制該層過去 12 個月回報之後要保留一半以上幅度。 |
| **測試設計** | 分兩關。**第一關(便宜,先做,約 3 小時):存在性的最低證據**——在 KARST-152 的機器分層上,逐層逐季算「供給受限語言成員比例」,量這個比例的**季度變化**與該層其後一季等權回報的橫截面排名相關度(用排名相關度不用組合回報,理由見 0.1)。**存在** = 排名相關度平均為正、月度 t ≥2.5(k(M) 按考試協議 4.3 定),而且控制該層過去 12 個月回報後保留 ≥50%。**不存在** = 排名相關度不顯著,或方向與假設相反,或控制動量後剩不足 30%。**第二關(貴,過了第一關才做):**把關鍵詞尺換成語言模型判讀,看幅度會不會提升。 |
| **分辨力** | 中低。可用的層大概二三十條、每年四季,有效樣本不算多;而且「多過一半成員同時轉向」這件事本身罕見,真正的事件數可能只有幾十次。開票前要先數清楚事件數,少過三十次就不值得跑。 |
| **把握** | 中。機制是全份名單最貼近用戶 D-130 那句「敘事分組是所有優勢的起點」的一條,而且是唯一一條**用層做單位而不是用公司做單位**的文本假設——這是別人不做的位置。扣分項:沒有文獻量級、依賴 A-037 未驗、事件數可能太少、偷看防法要做得很小心。**排在 V1 之後、V2 之前。** |

## 第四節:個股層(六條)

共同資產:帳目面板 718 家 × 212 個月 × 97 欄,2009-04 至 2026-08,知情時點違規 0 格;每一欄都帶 `_filed`(申報日)、`_restated`(修訂後值)、`_was_restated`(是否被改過)。

共同限制:倖存者缺口只修一半(D-125);毛利只有 49% 覆蓋、總負債只有 70%;經營現金流與資本開支實際一年更新一次。

### S1 — 年報文字改動(「Lazy Prices」)

| 格 | 內容 |
|---|---|
| **假設** | 把今年的年報與去年的年報逐段比對,**文字改動大**的公司,未來回報顯著較差;文字幾乎沒改的公司較好。改動集中在管理層討論與分析章節、以及涉及高管人事與訴訟語言的那批,預測力最強。 |
| **為何存在** | 誰在犯錯:公司法務寫年報的預設做法是「照抄去年」,所以任何改動都是有人特意去改的——而人特意去改的地方,通常是壞消息(新增風險、新增訴訟、高管出事)。投資者不讀年報,更不會逐年比對,所以這批壞消息要幾個月才被定價。這條的精妙處在於:**它不需要理解內容,只需要偵測「有沒有改」**,所以完全機械化,而且不受語言模型訓練截止日污染(A-002 那個問題在這裏不存在)。 |
| **量級與來源** | Cohen, Malloy & Nguyen (2020), *Journal of Finance* 75(3), 1371-1415:做空「改動者」、做多「非改動者」,未來每月異常回報最高達 188 個基點(年化超過 22%),用餘弦相似度量度。樣本 1995–2014。**2010 年後專項衰減證據:未找到**——只有 McLean & Pontiff (2016) 的跨 97 條訊號通用結論(樣本外平均低 26%、出版後再低 58%),不是針對這條。(查證 2026-09-02) |
| **數據** | 免費但要自己抓。證監會全文索引 + 逐份申報 HTML,`https://www.sec.gov/Archives/edgar/data/{CIK}/{accession}/{filename}`,速率上限每秒 10 次。718 家 × 每年 1 份年報 × 10 年 ≈ 7,180 份(若連季報則約 28,700 份)。**單份大小未查到實測數字,起手前先抽 10–20 份量平均大小。**純下載時間在滿速下約十幾分鐘到 48 分鐘,實務上會長得多。 |
| **偷看** | 低:年報申報日就是公開日,面板已有 CIK 可直接對應。要注意的是「相似度」的計法必須在看結果之前寫死(餘弦相似度 / Jaccard / 只比 MD&A 段),否則就是在挑一個好看的計法。 |
| **倖存者** | 高(718 家),而且除牌公司的年報通常在改動最大那一年——即真實效應被低估,方向有利。 |
| **化身** | 低。文字改動與規模、動量、價值都不是同一件事。要查的是它會不會只是「小型股」化身——防法:在同一規模組內比較。 |
| **測試設計** | **先做縮小版:**抽 150–200 家、2015–2024,只下載年報、只比 MD&A 段,算逐年餘弦相似度,做橫截面排名。**存在** = 月度排名相關度中位 ≥0.02 且 t ≥2.5,**而且**十分位長短倉年化 ≥8pp。**不存在** = 排名相關度 ≤0.005,或符號與文獻相反。縮小版約 4–5 小時(抓數 2 小時 + 處理 2 小時)。 |
| **分辨力** | 中高(150–200 家 × 10 年 × 每年一次觀察;若擴到季報則觀察數乘四)。 |
| **把握** | 中高。**這是全份名單裏「文獻量級最大 × 數據免費 × 沒有反方文獻」三者同時成立的唯一一條。**扣分只在工程量(抓數是全份名單最重的一條)與「已發表訊號普遍衰減」這個通用風險。 |

### S2 — 帳目被靜默修訂本身就是訊號

| 格 | 內容 |
|---|---|
| **假設** | 公司事後把已經公布過的帳目數字改掉(尤其向下改),之後的回報較差;從不修訂的公司帳目質素較高,回報較好。這是**倉內獨有**的一格——帳目面板已經逐格記錄了 `_was_restated` 與 `_restated`,邊際成本是零。 |
| **為何存在** | 誰在犯錯:正式的財務重述會發 8-K、會上新聞、會被即時定價;但 XBRL 數字被靜靜改掉不會有任何公告——它只出現在下一份申報的比較欄裏,沒有人看。這是「有訊息但無廣播渠道」的典型情況,而這種情況正是異常回報最可能存活的地方。 |
| **量級與來源** | 未找到針對「XBRL 靜默修訂」的同儕審查量級(查證 2026-09-02)。最接近的是正式財務重述的文獻(重述公告日前後有顯著負異常回報),但那是**不同的事件**——正式重述有廣播,靜默修訂沒有。**量級未找到,這條完全靠自己量。** |
| **數據** | **倉內已有,零額外成本。**`panel_monthly.parquet` 的 `<欄>_was_restated` 與 `<欄>_restated` 兩欄,11 個財務項全部有。 |
| **偷看** | **這是本條最大的技術難點,必須做對:**面板的規則是「首版優先,最新版另存 `_restated`」,即 `_was_restated` 這一格記錄的是「站在今日回望,這一期後來被改過」——這是**前視資訊**。要用得對,必須改問法:不是「這一期後來有沒有被改」,而是「站在 t 月,過去十二個月之內我們見過幾多次修訂」(即用修訂**被申報出來**的那個日子作生效日)。這一格做錯,整條線的成績是純粹的前視偏差,而且會非常好看——這正是 A-028 那個坑的同一形狀。**跑數前必須把生效日規則獨立 commit。** |
| **倖存者** | 高(718 家),而且最愛改數的公司很可能是已經除牌那批——真實效應被低估。 |
| **化身** | 低。修訂頻率與規模、動量、價值關係遠。 |
| **測試設計** | 2009–2026,718 家。按上述「修訂申報日」規則,算每家每月的「過去 12 個月修訂次數」與「修訂方向(向下 / 向上)」。橫截面排名。**存在** = 向下修訂組與零修訂組的月度回報差 ≥0.4%(年化約 5pp)且 t ≥2.5,**而且**用洩漏診斷確認生效日規則正確(即把生效日再推遲一季,成績只應輕微下降而非崩潰)。**不存在** = 回報差 <0.1%/月,或推遲生效日後成績崩潰(即原成績來自前視)。約 2–3 小時。 |
| **分辨力** | 中(修訂本身是低頻事件,實際事件數要先數;面板 `_was_restated` 的整體比例未量過)。 |
| **把握** | 中。**這是全份名單裏最獨特的一條——別人沒有這格數據,而我們已經有了。**扣分在:沒有文獻背書、事件數未知、而且偷看風險是全份名單最高的一條(所以它的洩漏診斷要做得比其他條嚴)。 |

### S3 — 股數收縮

| 格 | 內容 |
|---|---|
| **假設** | 攤薄股數按年下降的公司,未來回報高過股數上升的公司;而且這個訊號在「行內比較」時比「全市場比較」更乾淨。 |
| **為何存在** | 誰在犯錯:回購是管理層用真錢投票說「我覺得自己家便宜」,而且它同時是**現金流真的存在**的證明(講故事的公司回購不了)。反過來,持續發股是稀釋——但稀釋不會出現在每股盈利之外的任何一個顯眼位置,所以被系統性忽略。 |
| **量級與來源** | Pontiff & Woodgate (2008), *Journal of Finance* 63(2), 921-945:1970 年後,股票發行對橫截面回報的預測力在統計顯著性上**強過規模、帳面市值比或動量各自單獨的預測力**;樣本 1970–2003。**具體月度或年化基點數字查不到——量級未找到。**Daniel & Titman (2006), *Journal of Finance* 61(4) 的複合發行量指標方向一致(高發行者未來較差)。2010 年後專項衰減數字未找到,只有 McLean & Pontiff 的通用結論。(查證 2026-09-02) |
| **數據** | **倉內已有,零額外成本。**`diluted_shares`,覆蓋率 97.21%,帶 `_filed` 知情時點。 |
| **偷看** | 低。面板規則已經保證只用 `filed ≤ 月底` 的資料。 |
| **倖存者** | 高(718 家)。要留意方向:大量發股救命的公司很多已經除牌並缺席面板,所以「發股組」的真實表現被高估,**即真實效應被低估**,方向有利。 |
| **化身** | 中風險:回購多的公司往往是大型、成熟、賺錢的公司,即可能是規模或盈利能力的化身。防法:在同一規模組與同一盈利能力組之內比較;並與 D-126 已對齊的四件套逐一算相關。 |
| **測試設計** | 2009–2026 月度,718 家。訊號 = 攤薄股數的 12 個月變化率(負值愈大愈好)。量:①月度排名相關度;②十分位長短倉;③控制規模與盈利能力後的增量。**存在** = 排名相關度中位 ≥0.015 且 t ≥2.5,**而且**控制規模與盈利能力後保留 ≥50% 的幅度。**不存在** = 排名相關度 ≤0.005,或控制後幅度剩不足 30%(判為規模/盈利能力化身)。約 1–2 小時。 |
| **分辨力** | 高(212 個月 × 約 500–700 家)。 |
| **把握** | 中高。**測試成本是全份名單最低的一條**(數據已在手、一兩小時),機制乾淨,文獻在頂級期刊。扣分在拿不到具體量級,以及它與四件套的「投資紀律」一項可能重疊(總資產增長與股數增長相關)。 |

### S4 — 內部人的「機會型」買入

| 格 | 內容 |
|---|---|
| **假設** | 公司內部人的買入不是全部有用——只有**打破自己既定節奏**那批(過去三年在不同月份買、今次又買)才有預測力;每年固定月份買那批(例如行使期權後的例行買入)完全沒有預測力。 |
| **為何存在** | 誰在犯錯:市場把所有內部人買入當同一回事看待,而事實上大部分內部人交易是流動性或稅務驅動的例行動作。分辨出「這次是因為知道了什麼才買」需要看那個人**過去幾年的買賣時間表**,這是要做功課的事。這一條的精妙處在於:它不需要新數據,只需要用舊數據問一個更聰明的問題。 |
| **量級與來源** | Cohen, Malloy & Pomorski (2012), *Journal of Finance* 67(3), 1009-1043:區分「常規」與「機會型」之後,機會型交易者組合的市值加權異常回報是**每月 82 個基點**(年化約 10%),常規交易者接近零。樣本 1986–2007。**衰減警告:**有一篇非同儕審查的碩士論文用 2008–2024 樣本複製,發現因子調整後超額回報由每月 1.2–1.6% 跌到約 0.3–0.4%,跌幅約六至七成——單一未經審查來源,只可當方向性線索。(查證 2026-09-02) |
| **數據** | 免費但要自己抓。證監會 Form 4:全文索引 `https://www.sec.gov/Archives/edgar/full-index/`(`form.idx` 可單獨篩 Form 4),XML 結構化資料 **1996-01 起完整**。全市場 Form 4 約 448 萬份、覆蓋 2.23 萬個發行人。718 家一年份粗估幾千至過萬次文件級請求(大型公司高管董事多,申報密度偏高)。速率上限每秒 10 次。 |
| **偷看** | 低:Form 4 有法定兩個工作日申報期限,用申報日生效即可。但「機會型 vs 常規」的分類要用**過去**三年的節奏,不能用全樣本。 |
| **倖存者** | 高(718 家)。 |
| **化身** | 低至中。可能與價值有關(內部人在便宜時買),防法:控制估值後看增量。 |
| **測試設計** | **先做縮小版:**抽 150 家、2015–2024,只抓開放市場買入(交易代碼 P),用「該內部人過去三年是否在同一月份買」分成機會型與常規兩組。**存在** = 機會型組在買入後 3 個月的超額回報 ≥2pp,**而且**常規組 <0.5pp(即兩組必須分得開——分不開就證明分類方法沒抓到東西)。**不存在** = 兩組差 <1pp。約 4–5 小時。 |
| **分辨力** | 中(事件數要先數;150 家十年應有數千次買入)。 |
| **把握** | 中。文獻在頂級期刊、機制清楚、數據免費;扣分在工程量不細,以及唯一的近期樣本外證據(非審查)說已衰減六七成——衰減後每月 30–40 個基點仍然值得要,但要老實寫明預期已打折。 |

### S5 — 個股短倉比率

| 格 | 內容 |
|---|---|
| **假設** | 短倉比率**低**的重倉交易股票,未來有顯著正超額回報;短倉比率高的負超額則較短暫。即這條訊號真正有用的是「多」那一邊,不是「空」那一邊——這與大部分人的直覺相反。 |
| **為何存在** | 誰在犯錯:賣空者是知情交易者。「沒有人願意做空它」是一個資訊,而且是一個大部分人不會去查的資訊(所有人都盯高短倉的股票找爆倉,沒有人盯低短倉的)。散戶做不到做空,但完全做得到「只買沒有人做空的那批」——**這條的長倉那一邊剛好是散戶做得到的那一半。** |
| **量級與來源** | Boehmer, Huszar & Jordan (2010), "The Good News in Short Interest", *Journal of Financial Economics* 96(1), 80-97(**注意:原以為的出處 RFS/Jones 有誤,查證後更正為 JFE/Jordan**):重倉交易而短倉比率低的股票,未來正異常回報在統計與經濟上都顯著,**幅度往往大過重倉高短倉股的負回報**。樣本 1988–2005,紐交所/美交所。**精確十分位利差基點未找到。**2010 年後專項衰減未找到,只有「近年幾乎所有異象的做空腿負超額都明顯收窄」這個廣泛趨勢。(查證 2026-09-02) |
| **數據** | 免費。FINRA `https://api.dapi.finra.org/api/EquityShortInterest/GetESI?settlementDate=...`,每個結算日一個請求拿全市場快照,無需認證;每月兩次結算,滯後 7–8 個工作日。納斯達克那份 2007-09 起完整。抓取成本:約 400 個請求,幾分鐘。 |
| **偷看** | 低:用公布日生效(結算日 + 8 個工作日)。 |
| **倖存者** | 高(718 家)。 |
| **化身** | 中:短倉比率與規模、流動性、動量都有關。防法:控制規模與成交量後看增量;並與 M2(總體短倉)分開——一個是橫截面、一個是時間序列,兩者可以並存。 |

### S6 — 現金流對盈利背離,只作剔除欄不作排名

| 格 | 內容 |
|---|---|
| **假設** | 應計項目異象(低應計贏高應計)作為**排名分數**已經死了,但作為**剔除欄**仍然有用:剔走「純利遠高於經營現金流」那批(帳面賺錢但收不到現金),剩下的名單質素較高。分別在於——排名要求它單調有效,剔除只要求極端那一端真的差。 |
| **為何存在** | 誰在犯錯:應計項目異象死於套利者湧入(對沖基金資金與極端應計股成交量同步上升),但套利者做的是「買最低那批、沽最高那批」的兩頭;而我們要做的只是「不要碰最差那批」。極端一端往往是最後才被套利乾淨的,而且對於一個只揸六隻的散戶,避開一隻地雷的價值高過多賺零點幾個百分點。 |
| **量級與來源** | Sloan (1996), *The Accounting Review* 71(3), 289-315:低應計做多、高應計做空的避險組合年回報約 10–13%(最常引用 12%),樣本 1962–1991。**Green, Hand & Soliman (2011), *Management Science* 57(5) 明確判定已死**——美股應計異象已衰減到平均不再穩定為正,成因是對沖基金套利活動增加。(查證 2026-09-02) |
| **數據** | **倉內已有,零額外成本。**`net_income_ttm` 與 `cfo_ttm`(覆蓋率 99.64% / 99.50%),`assets` 作分母。**但要留意 D-125 的警告:經營現金流實際一年更新一次,滾動和有 92% 靠全年數砌,最舊落後 15 個月。** |
| **偷看** | 低(面板規則保證);但那個 15 個月滯後要在報告寫明,它會令訊號變鈍而不是變假。 |
| **倖存者** | 高(718 家),而且應計最高那批很可能已經除牌——真實效應被低估。 |
| **化身** | 中:與盈利能力(D-126 已對齊的 CFO ÷ 總資產)有結構性重疊。防法:先算兩者相關,若 >0.7 就不是新訊號,直接收檔。 |
| **測試設計** | 2009–2026,718 家。訊號 = (純利 − 經營現金流) ÷ 總資產。**只量兩件事:**①作為排名分數的排名相關度(預期接近零,用來確認文獻的「已死」判詞在我們的樣本上也成立);②剔走最差十分位之後,餘下 90% 的年化回報與最大跌幅相對全樣本的改善。**存在** = 剔走最差十分位後,年化回報改善 ≥1pp **或**最大跌幅改善 ≥3pp,**而且**它與盈利能力的相關 <0.7。**不存在** = 剔除後無改善,或與盈利能力相關 ≥0.7(重疊,不是新東西)。約 1–2 小時。 |
| **分辨力** | 中高。 |
| **把握** | 中。**這條的價值不在於發現新優勢,在於花一小時關掉一個問題**——文獻說死了,我們自己量一次確認,同時撿起「剔除欄」這個仍可能有用的用途。成本極低,結論確定。 |

### T6 — 收市成交取代開市成交

| 格 | 內容 |
|---|---|
| **假設** | 換馬時用收市價成交,長期成績好過用開市價成交。理由不是預測,是**美股的長期回報幾乎全部發生在隔夜(收市到次日開市),日內(開市到收市)接近零**——所以買入應該盡量晚(收市),賣出應該盡量早(開市)。 |
| **為何存在** | 誰被迫交易:套利者為避開隔夜保證金與借券費,收市前平倉,所以做多錯價因子的部位由隔夜那一段承接(Lou, Polk & Skouras 的解釋)。換句話說,隔夜那段回報是**專業投資者不願意持有的風險的補償**——而散戶完全沒有這些約束。**這是散戶結構性優勢的最乾淨一例。** |
| **量級與來源** | 以 SPY 1993 年至近年:隔夜累計報酬約 1,106%、日內僅約 27%;年化計日內平均僅約 1%。現象最早由 Cliff, Cooper & Gulen (2008) 記錄,Lou, Polk & Skouras 及 Bogousslavsky (2021, *Journal of Financial Economics*) 確認並分析成因。**反方:**有分析指扣除交易成本後隔夜異常收益被吃掉——但那是針對「每日進出」的主動策略;作為**被動的成交時點選擇**(本來就要換馬,只是選幾點鐘成交),交易成本不增加。(查證 2026-09-02) |
| **數據** | 需要開市價。倉內只有收市價;`data/snapshots/` 那批有 OHLC 但只 2015 年起。要全樣本用 yfinance 重抓(免費)。 |
| **偷看** | 零。 |
| **倖存者** | 繼承底層,兩臂共用同一批股票。 |
| **化身** | 低。 |
| **測試設計** | 同一個底層訊號,四臂:①開市買開市賣;②收市買收市賣;③收市買開市賣(理論最佳);④開市買收市賣(理論最差)。**存在** = 第三臂與第四臂的年化差 ≥2pp,**而且**次序與理論預測一致(③ > ② ≈ ① > ④)。**不存在** = 四臂年化差 <0.5pp,或次序與理論相反。約 2–3 小時(含抓 OHLC)。 |
| **分辨力** | 中高(每次換馬都是一次觀察,而且次序預測是一個很強的判別式——四臂全部排對的機會只有 1/24)。 |
| **把握** | 中。現象本身在文獻上非常穩固(不是有沒有爭議的問題,是量得到的事實);問題在於對一個每季換馬一次的組合,一年只有四次成交,幅度可能微不足道。**價值取決於換馬頻率——若採用 T1 的分批換馬(每月動三分一),成交次數乘三,這條的價值也乘三。** |

## 第六節:前八條——優先次序、理由與依賴關係

排序準則:若存在的價值 × 存在的機會 × 測試便宜程度。

---

**第一 — 鏈層存在性(KARST-152 主體 + 本報告 V1 對照,本報告部分約 2–3 小時)**

**為何第一:**這是唯一一條「無論答案是什麼都極有價值」的測試。過去兩星期判死的十一條線,全部死在同一個場地(九隻板塊,1.6 隻有效資訊)。這一條問的是:換一個由「故事」而不是由「賣什麼」劃出來的場地,量得出東西嗎?通過就開了我們唯一一個從未量過的新戰場;不通過就一次過封死整個價值鏈層,省下十幾張票。

**分工(D-130 之後):**主體那一格——按申報日定格的文本機器分層,同層殘餘回報相關度是否高過同 GICS 子行業——已經另開 **KARST-152**,本報告不重複,一律當作待驗證假設 **A-037**。本報告只補仍未有人做的那半:**機器分層與舊倉那張人手凍結表哪一個更準**(V1)。人手表 33 條鏈位、138 個代碼,在無人量過反應相似度之前已凍結,所以它是一張難得乾淨的對照尺。

**兩個要先講明的預告:**①**光是「切得更細」不會成功**——同一條等效獨立數的算式代入七十個 GICS 行業、平均相關 0.45,只得 2.18 隻,比九隻板塊的 1.60 好不了多少。鏈層若有價值,價值必須來自「它抓到 GICS 抓不到的共同反應」,不是來自「格子多了」。②**33 條鏈位不等於 33 個可用單位**——平均每條只有 4 個代表,成員一兩隻的算不出相關,實際大概只有二十來條用得着,而配得成上下游對的更少。開票時要先數清楚。

---

**第二 — S1 年報文字改動(縮小版約 4–5 小時)**

**為何第二:**這是全份名單裏唯一一條同時滿足「文獻量級最大(每月 188 個基點)× 數據完全免費 × 沒有查到反方文獻」的假設。它也是最符合用戶「跳出框框」要求的一條——它不是任何一個傳統因子,它甚至不讀年報的內容,只數改動。而且它有一個獨特的性質:**它不受語言模型訓練截止日污染**(A-002 那個一直未解決的問題),因為餘弦相似度是純機械運算。

扣分在工程量:抓數是全份名單最重的一條。所以先做 150–200 家的縮小版,過了關才擴。

---

**第三 — T1 + T4 分批換馬與等風險注碼(兩條合跑,約 3 小時)**

**為何第三:**這兩條是全份名單裏唯一直接攻擊「我們已經量出來的那筆最大開支」的假設。D-121 量出:揸六隻的拖累等於持倉自己的月度半方差,動能組 3.80pp、深度價值組 5.61pp。若分批換馬加等風險注碼合共削掉一半,那就是每年 1.9–2.8 個百分點——這個量級大過本名單上大部分訊號假設的預期值,而且**存在的機會遠高**(組合數學保證它一定會削一點,問題只在夠不夠多)。

兩條共用同一套對照臂,合跑比分開跑省一半時間。

---

**第四 — S3 股數收縮(約 1–2 小時)**

**為何第四:**測試成本是全份名單最低的一條——資料已經在帳目面板裏,一兩小時出結果。文獻在頂級期刊(Pontiff & Woodgate 2008),機制乾淨(管理層用真錢投票),而且它是四件套之外的第五個候選因子。**這一條的角色是「便宜的資訊」:一兩小時就知道我們手上這個面板還有沒有第五條有用的欄。**

---

**第五 — M2 + S5 短倉比率兩條(合跑約 4 小時)**

**為何第五:**兩條共用同一次抓數(FINRA 一個免費端點、約 400 個請求、幾分鐘),但問的是兩個完全不同層次的問題——M2 問「總體短倉能不能預測大市」(時間序列,市況層),S5 問「個股短倉能不能排名」(橫截面,個股層)。M2 的文獻證據是全份名單最硬的一條:Rapach, Ringgenberg & Zhou (2016, *JFE*) 報的是**樣本外** R² 13.24%,而且是頂級期刊。S5 那條的長倉那一半剛好是散戶做得到的一半。

一次抓數、兩層答案、四小時——性價比全份最高。

---

**第六 — M1 宏觀狀態開關(約 2 小時)**

**為何第六:**D-049 判死的是**四個價格系**開關,明文如此。非價格的宏觀狀態開關是市況層最大的一整族未測空白,而且數據免費、歷史七十六年(把偵測地板由 3.7pp 壓到 2.0pp)。它的職能設計也與已死那四個不同——它不發起,只否決,即用來濾走價格開關的假警報。

扣分在沒有文獻量級撐腰,以及七十六年只轉向十幾次,樣本事件少。

---

**第七 — S2 帳目靜默修訂(約 2–3 小時)**

**為何第七:**這是**倉內獨有**的一格——`_was_restated` 與 `_restated` 兩欄已經逐格建好,邊際成本是零,而且我沒有查到任何人做過這件事(正式財務重述有大量文獻,XBRL 靜默修訂沒有)。若它存在,那是一條別人沒有的優勢。

排第七而不是更前,是因為它的偷看風險是全份名單最高的一條:面板的 `_was_restated` 本身是前視資訊(站在今日回望),必須改用「修訂被申報出來那一日」作生效日。這一格做錯會產生一個非常好看的假結果——與 A-028 那個坑完全同形。所以它要在洩漏診斷做好之後才跑。

---

**第八 — T2 事件時鐘取代日曆時鐘(約 2 小時)**

**為何第八:**D-112 已經把事件時鐘寫進憲法,但從未實測。資料完全在手(面板的 `net_income_filed` 就是公布日,四萬多個事件),兩小時就有答案。**無論結果如何都要知道**——若事件時鐘沒有優勢,憲法那一條應該撤回;若有,那是所有個股層策略的免費升級。

扣分在文獻已說大型股的盈利公布後漂移在 2006 年前後已接近零,所以預期幅度不大。

---

**D-130 追加 — V8 層級敘事轉折(約 3 小時),實際應排第三**

用戶稍後補的 D-130 明講「敘事分組應該是所有優勢的起點」,並點名層級敘事轉折這一類值得多押。按同一套排序準則(存在的價值 × 存在的機會 × 測試便宜程度)重新過一次,V8 應該排在 T1+T4 之前、S1 之後,即**實際的第三位**;上面第三至第八順次後移一格,T2 由第八跌出前八。

**為何第三:**它是全份名單唯一一條**以「層」而不是以「公司」為單位**的文本假設——市場上沒有一個現成的觀察者在看「整層同時開始講產能不夠」這件事,因為每一份年報只講自己一家。測試成本低(文本與分層都是免費、且 KARST-152 會交出分層)。

**為何不是第一:**它硬依賴 A-037(層是不是真的)未驗,而且沒有任何文獻量級可以參照,事件數也可能太少——「多過一半成員同時轉向」這件事本身罕見,開票前必須先數,少過三十次就不值得跑。**還有一個必須寫死的防線:事後命名的故事不准回頭分組**——名字可以是今日才有的,成員名單必須由當年那批文字決定。

### 依賴關係圖

**硬依賴(前者不成,後者不能測):**
- **A-037(KARST-152 在測)→ V1、V2、V3、V4、V5、V6、V7、V8**:整個價值鏈層建基於「鏈層是真的」,而這一格由 KARST-152 承接,本報告一律當它待驗。A-037 不成立(即鏈層贏不過 GICS 子行業),八條全部要改成別的單位,或者整層押後。**這是本名單最大的一個單點依賴,而且依賴的對象不在本票之內。**
- **KARST-152 的機器分層 → V1、V8**:這兩條要用 KARST-152 產出的逐年層籍作輸入,它未交數之前跑不了。
- **上下游方向 → V2、V6、V7**:文本分群給得出「同層」,**給不出「誰在誰上游」**;`chain_membership_v0.csv` 同樣只有鏈位沒有方向欄(README 自認:多數鏈位本身即一層,只有石油鏈有子層)。要另補一份上下游關係表,而且必須在跑數之前獨立 commit,否則就是看着結果排上下游。
- **成員數 → V2、V4**:33 條鏈位平均只有 4 個代表,V4 的「同層中位」要成員 ≥5 才算得準,V2 的上下游配對可能只得十對八對。開票前先數,數出來太少就要先擴成員名單(用 3.2 節第一步那三個來源),那是另一張票。
- **具名客戶鏈 → 已知是死路**:ASC 280 不強制具名 + 證監會 2020-11 修訂,免費自動砌具名鏈一定會斷。V5 是唯一走得通的一格(它只需要百分比不需要名字)。**不要開「自砌具名客戶鏈」的票。**
- **S1 縮小版 → S1 全量**:150–200 家過關才值得抓 718 家十年的年報。
- **T2 → 個股層的排名設計**:事件時鐘不成立,D-112 憲法那一條要撤回。

**軟依賴(前者影響後者的價值,不影響能否測):**
- **T1、T4、T3、T5、T6 五條執行層假設 → 個股層有沒有訊號**:省下來的錢與改善的執行,只有在底層有訊號時才有用武之地。**但反過來不成立**——執行層的改善可以在任何底層訊號上疊加,所以它們應該與個股層測試並行,不應該等。
- **M4 ↔ T3**:是同一個效應在兩層的應用,一次跑數同時答兩條,不要分開做。
- **M2 ↔ S5**:共用同一次抓數,一次做完。
- **S1 ↔ S2**:兩條都是「公司申報行為」族,若兩條都成立,要查它們是不是同一件事(改年報文字的公司會不會就是改帳目數字的公司)。
- **V3 ↔ V4**:同一枚硬幣的兩面——V3 說層內沒有可揀的東西,V4 說有一種特定的層內錯配可以揀。**必須一齊做**,兩條的答案合起來才完整,單獨看任何一條都會誤導。
