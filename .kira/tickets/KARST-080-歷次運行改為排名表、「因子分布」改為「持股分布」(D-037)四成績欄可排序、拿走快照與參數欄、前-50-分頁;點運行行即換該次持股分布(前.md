## 工作內容

依 D-037(用戶 2026-08-29 裁決)。完成後:(1) 策略詳情的歷次運行表欄位為運行編號、版本、年化、Sortino、最大回撤、勝率(同格細字附交易次數);四個成績欄可點欄頭升降排序,預設按年化由高至低;快照、參數兩欄不再顯示;幾千條時只列前 50,底下「載入更多」;失敗運行照 D-034 預設隱藏。(2) 原「因子分布」段改名「持股分布」,與運行表配對:頁面載入時顯示表中第一行(排名最高)那次運行的持股分布,點任一行即換成該次;內容為該次運行整段期間最常持有的前十隻股票(以持有日數或平均權重計,票內講明用哪個並寫入詞彙表)、每隻在該次運行內的累計報酬(該股票在此運行所有交易的合計損益,以該次起始資金為分母)、行業佔比;行業資料以現有實體登記冊或宇宙檔的行業欄為準,若無此欄,先做前十股票與累計報酬,行業佔比在票上舉手不自行找來源。(3) 因子敞口與因子版本兩塊搬到運行詳情頁,策略頁不再顯示。(4) 後端補一個每次運行持股彙總 API,結果落實體 DB 讀取即可,不另建快取表。(5) 策略頁的「檢視中」區塊(該次運行的參數清單、運行編號、快照、視窗)整個拿走——用戶 2026-08-29 原話「Is not need to show in the strategy page」;這些資料只在運行詳情頁顯示,策略頁頂只留策略名、版本與門面成績。不加參數預設值;只跑所涉測試檔;瀏覽器實開核對排序、分頁、點行換持股分布,用臨時埠(如 8767/8768,用完關閉;不可用 8765),結果文字落 experiments/2026-08-29-run-ranking-holdings/README.md。

## 驗收條件

- [ ] 運行表六欄如上,四成績欄可排序、預設年化降序、前 50 分頁;快照與參數欄不見;失敗運行預設隱藏
- [ ] 持股分布段顯示前十股票、各股累計報酬、行業佔比(或已舉手說明無行業來源);點運行行即換;因子兩塊已在運行詳情頁
- [ ] 持股彙總 API 有測試(至少:兩隻股票各一筆交易的累計報酬算對);瀏覽器核對落檔;只跑所涉測試檔
