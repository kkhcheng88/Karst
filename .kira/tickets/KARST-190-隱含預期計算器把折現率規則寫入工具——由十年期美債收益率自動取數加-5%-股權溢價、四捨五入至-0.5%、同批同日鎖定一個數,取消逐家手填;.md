## 工作內容

工具在 strategy/tools/implied_expectations.py,說明在 strategy/tools/README.md。現況:每家公司在檔內有一格固定假設含折現率,可逐家手填(SNOW 10%、AXTI 12% 就是這樣來的)。改法:(一)新增取數函數,由 FRED 系列 DGS10(https://fred.stlouisfed.org/graph/fredgraph.csv?id=DGS10)或 yfinance ^TNX 取最近收市的十年期美債收益率,兩個來源都試,記錄來源與日期;(二)折現率 = 收益率 + 5.0 個百分點,四捨五入至最近 0.5%;(三)每次跑一批候選時只取一次,寫入該批的輸出 JSON 頭部(rate、來源、取數日期),所有公司共用;(四)公司層的折現率欄改為只讀,若檔內仍有手填值則印警告並忽略,除非命令列明確傳 --override-discount-rate 並在輸出標明「手動覆寫」;(五)敏感度自動多跑 ±1 個百分點兩組並輸出;(六)README 改寫折現率一節,刪去「新增一家公司要在檔內加折現率」的說法,寫明規則、來源、覆寫方式與代價。改完對 SNOW、AXTI、LULU 三家重跑一次,確認三家共用同一個折現率並把前後差異(基準每股值)列在 README 末的更正紀錄。
