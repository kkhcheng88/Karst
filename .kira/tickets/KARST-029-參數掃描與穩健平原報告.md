## 工作內容

掃一格參數自此交得出一份判得出真假的報告:熱力圖畫得出,平原與孤峰分得開,成交太少的格判無效。判準是參數穩健平原(parameter robustness plateau)——最優參數的鄰域表現皆佳才算穩健,孤峰視為擬合噪音(D-016 第 3 條、規格 6.5)。範圍是掃描的執行與報告產出;KARST-013 已實跑過一次 144 組示範(單點最優夏普 1.61 但 3×3 鄰域平均只有 1.16,按此判為孤峰),本票是把那次一次性的示範做成可重複使用的能力。本票不裁定哪組參數該用,那是用戶的領域(D-008)。

## 驗收條件

- [x] 一次掃描交得出熱力圖,而且單點最優與其 3×3 鄰域平均兩個數同時列出(規格 6.5)
- [x] 峰值明顯高於鄰域平均的格被明文標為孤峰、判為擬合噪音(D-016 第 3 條)
- [x] 成交筆數低於門檻的格判為無效並在圖上區分得到,門檻值寫得出(規格 6.5)
- [x] 報告指得回它掃的是哪一次運行設定:策略版本 × 期間 × 數據快照(規格 7.4)

## 結果

· 2026-08-28 01:32 通用掃描能力落 `karst/sweep/`(四層:掃描格 `grid.py`、逐格跑並落痕 `runner.py`、平原/孤峰/無效格判讀 `verdict.py`、熱力圖與報告 `report.py`;因子混合的接法 `factor_mix.py`),掃描本體不認得任何一套策略,趨勢波段等日後接同一套。首個實跑是因子混合四隻因子 ETF 的權重單純形格,分兩輪:粗掃步長 10%,286 個權重 × 2 種換倉節奏 = **572 格**,552 格今次跑、20 格讀回,耗時 107.2 秒;細掃步長 5%,1,771 × 2 = **3,542 格**,2,920 格今次跑、622 格讀回(粗掃那批一格都沒有重跑),耗時 640.1 秒。收尾以加了回撤軸的腳本重跑兩輪核對,**兩輪皆 0 格動過引擎、全部讀回**(572 格 29.4 秒、3,542 格 144.4 秒)——「同一格重掃不重跑」由頭到尾行得通。

判讀門檻(寫在命令列、印在每份報告):無效格 = 成交少於 30 筆;孤峰 = 高出鄰域平均 0.005 以上;平原高地 = 目標值排前 10%。相鄰的定義(單純形格):把一步的權重由其中一格移去另一格(一個 +一步、一個 −一步,其餘不動);節奏那一維再各自移一步或不動。這條定義印在每一份報告的頂頭。

細掃(5%)以**對 SPY 年化超額**為主軸:平原 337 格、普通 3,197 格、**孤峰 0 格**、無效 8 格。單點最優 = 鄰域平均最高格皆為 weight_quality=0、weight_value=0.05、weight_momentum=0.95、weight_low_vol=0、季度換倉:年化超額 **+0.012075**,鄰域平均 +0.011250(不含自己 +0.011175,落差 +0.000825,倍數 1.073),裁決平原,成交 94 筆,年化回報 15.06%,最大回撤 −34.30%,對 QQQ 年化超額 −0.0391,運行編號 `run-6e68b8aed4e4b8f1`。頭五格:①0/5%/95%/0 季度 +0.012075(鄰域 +0.011250,94 筆,`run-6e68b8aed4e4b8f1`)②5%/0/95%/0 季度 +0.012066(+0.011248,94 筆,`run-a9ae38e9fe77889c`)③0/5%/95%/0 月度 +0.012054(+0.011250,280 筆,`run-496f5fac69c3bf01`)④5%/0/95%/0 月度 +0.012040(+0.011248,280 筆,`run-fd21df736d474959`)⑤5%/5%/90%/0 季度 +0.011412(+0.010884,141 筆,`run-c876d3a19f4cc43c`)。固定各 25% 對照格:月度 **−0.007153**(年化 13.14%、回撤 −34.99%,`run-bc650a4f67fceb9f`)、季度 **−0.006627**(年化 13.19%、回撤 −34.93%,`run-5110658680fb21c8`),全格排名第 2044 / 1972 位。粗掃(10%)同一結構,最優為 10%/0/90%/0 季度 +0.011400(鄰域 +0.009714,`run-3dcd422c806b8499`),平原 47、孤峰 0、無效 8。

同一批運行只換一個目標指標重判一次(一格都沒有重跑),得出**第二條主軸最大回撤**的報告:細掃平原 312、無效 8,單點最優 0/0/5%/95% 月度,回撤 −33.14%(鄰域 −33.24%,平原,280 筆,`run-f1db949aa847cc46`)。兩條主軸的最優格剛好相反——超額靠動能,回撤靠低波。

報告路徑:`experiments/2026-08-28-factor-mix-weight-grid/`,內有 `README.md` 與 `results-10pct/`、`results-5pct/` 兩輪,每輪各有 `報告.md`(超額主軸)、`報告-最大回撤.md`、`掃描表.csv`(逐格八項指標 + 對 QQQ/SPY 超額 + 運行編號 + 成交筆數)、`判讀表.csv`、`summary.json`,以及 28 張投影圖(四個權重每一對一張 × 月度/季度 × 兩個指標,另加節奏 × 各權重)。驗收測試 `tests/test_sweep.py` 六項全過(55.5 秒)。`pyproject.toml` packages 加了 `karst.sweep`。

三件要講清楚的事:(一)**孤峰 0 格不是量度壞了**——權重格本質平滑,相鄰兩格只差一步權重,兩個組合幾乎一模一樣,所以不會出現一格獨高。孤峰那道檢查是留給規則型參數格的(KARST-013 那次持倉數 × 賺蝕比就咬得住,單點夏普 1.61 對鄰域 1.16)。(二)**這幅地形是一道單調斜坡,不是一個山頂**:對 SPY 年化超額隨動能權重單調上升,由動能 0% 的平均 −0.0152 一路升到 100% 的 +0.0127,中間沒有內部高點;排第一那格是動能 95% 而非 100%,只因為純動能那一角成交 1 筆判無效(八格無效全部就是四個角 × 兩種節奏)。四隻之中只有動能(單調升)與低波(單調跌,由 +0.0011 跌到 −0.0361)推得動盤數,質素與價值兩條線幾乎貼住 −0.007 橫行。(三)**勝率(0.978–1.0)、賺蝕比(高見 1677)、平均持倉日數(約 1300–1600 日)這三項在這裡近乎沒有意義**——長揸加定期再平衡,平掉的來回買賣極少。要看的是年化超額與最大回撤。

本票不裁定哪一組權重該用(D-008),掃出來的最優**不是現役設定**:整個 experiments 目錄一句 `set_active_setup` 都沒有。
