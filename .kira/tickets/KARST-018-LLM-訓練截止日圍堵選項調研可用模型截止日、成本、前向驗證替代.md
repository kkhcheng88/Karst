## 工作內容

要答的事實問題:人物判官在回測期出判斷時,如何避免模型「已知結局」(A-002)。要查:(1) 現時可經 API 取用的主要 LLM(Anthropic、OpenAI、Google、開源)各自的訓練截止日與是否仍可調用,列表附出處;(2) 截止日最早而仍可用的模型有哪些,能否覆蓋 2023–2025 各段回測期;(3) 學界/業界對「LLM 回測前視偏差」的既有做法(遮蔽實體名、只餵時點前文本、用早期模型、只做前向)各自的效果與局限,附文獻或實作出處;(4) 每次判斷的粗略成本量級(以典型 3–5k token 輸入估),供 KARST-017 定成本上限。只查事實不代拍板。

· 2026-08-27 15:30 報告已落檔 `research/2026-08-27-llm-cutoff-containment.md`(全份查證日期 2026-08-27)。摘要:

  - 現時可經官方 API 取用的模型當中,能覆蓋 2023 年全年的只有 OpenAI `gpt-3.5-turbo`(訓練截止 2021-09),而它已列明 2026-10-23 停用;該日之後四家主要廠商官方 API 對 2023 年 1–10 月將無任何模型可用,僅剩自行部署 Llama 2 base 一條路。
  - Anthropic 與 Google 現役全線模型完全覆蓋不到 2023 與 2024 年(最早訓練截止日分別為 2025-07 與 2025-01);Anthropic 亦覆蓋不到 2025 年 1–7 月。
  - 四種圍堵做法各有文獻量度的效果與局限(遮蔽實體名有分心效應但資訊損失可能更大;只餵時點前文本管不到模型參數層記憶,搜尋引擎日期過濾器洩漏率達 71–81%;用舊模型是唯一直接消除參數層污染的做法但能力較弱、名義截止日與實際截止日有落差;前向驗證結構最乾淨但樣本期短、隨換模型重設時鐘),另補列四款現成量測/緩解工具。
