## 工作內容

訊號/判準類考試(KARST-119/120/122 一型)而家靠每張派工指令重覆交代紀律,冇正本——下一個 session 好易漏。本票把規矩收成 docs/考試協議.md 一頁,寫成可照做的清單,不是告誡文。要收齊六節,每節指回出處(決策編號或先例票):(1) 判準預先寫死——判準文本連全部參數先落檔先 git commit 先接觸結果數據,commit 時序即證據(D-049/D-053;三票先例);(2) 參數組數上限——每個判準族最多主+副兩組,寫死後不准加組不准調參重跑,參數穩健性掃描係另一種票(D-072 護欄);(3) 基準與打和線——對照無條件基礎率,開關類另配打和精確度/打和準繩度型基準(CONTEXT.md 詞條;KARST-119);(4) 值博線與知情聲明——及格要贏過基準幾多要事前寫死;任何受先前結果知情的選擇(窗長、門檻形態)必須明寫聲明並令值博線從嚴,雙重值博線(幅度+訊噪 ≥2 倍標準誤)照 KARST-122 先例;(5) 樣本外紀律——同一批數據唔准做唯一考場:判準一節須事前寫死樣本外對象(另一市場/資產/時段),SPDR 日線已被四票重用係現成反例(D-083);(6) 評分與報告格式——五熊窗逐次+全樣本誤報、多判準/兩半分開評分不合總分、報告業務語言結論先行、不及格照樣落檔(D-076 先例)。多重測試門檻(Harvey/Liu/Zhu t≈3.0 定 Bailey 縮減夏普)兩路取捨要有一段並選定一路連算式範例,呢節係舊 KARST-100 唯一仍要做的貨。文件寫完 CONTEXT.md 加「考試協議」詞條。不改任何程式;含中文檔案只用 Read/Write/Edit;不 commit 數據。
