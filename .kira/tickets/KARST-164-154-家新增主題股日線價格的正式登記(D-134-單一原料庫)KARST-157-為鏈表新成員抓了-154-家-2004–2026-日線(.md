## 工作內容

背景:D-134 用戶原話「Make sure we keep only single copy. Still the golden principle is governance on data」。KARST-157(experiments/2026-09-02-narrative-layers-v2/)為鏈表新成員抓了 154 家日線(out/new_price_meta.json:priced_ok 154、2004-01-02 至 2026-09-01、5,702 行、auto_adjust=True),KARST-160 也用了這批(154 家五年十倍率 33.1%)。它們沒有登記進任何原料庫,下一張票要用就會再抓一次——正是 D-134 要防的事。做法:①盤點:這 154 家的價格檔實際存在哪個路徑、格式、大小、抓取日期、來源參數;生產庫 C:\projects\Karst\karst.sqlite(只讀)的價格表結構、復權口徑、來源、日期範圍;data/snapshots 與 data/runs 的角色(讀 README 或 AGENTS.md);②口徑差異表:同一家既有公司(從 574 家挑五家)用兩個來源比對同日收市價,量化復權差異;③提出路線選項(至少兩個:例如 data/prices/ 新建單一 parquet 原料庫連 manifest,由生產庫與實驗共同讀;或經現有 snapshot 機制入庫),每個選項寫清楚改動範圍、誰要改讀、與生產庫雜湊守則的關係;④不執行搬移、不寫入生產庫;結論與選項在票上 raise(docs 指向本票報告 experiments/2026-09-03-price-registry-study/REPORT.md)。
