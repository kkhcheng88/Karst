## 工作內容

完成之後,用戶可以打開一頁 AXTI 的股票頁:首屏六行(目前建議、主要理由、關鍵假設、最強反證、改變行動的條件、與上次相比),展開見六層各自的判斷與所用證據(可點開到段落)、估值面板(正向三情境與現價反推要求、可調參數)、技術結構(關鍵支撐阻力區、200 日 SMA、日週月切換、通道與突破回踩狀態)、投資計劃(持有期、行動、入場、失效與退出、目標、部位示例、風險回報、更新條件);每格附證據版本與資料截至時間。之前做不到的:任何一隻股票都沒有一頁把六層、估值、技術與計劃接起來的輸出。最低基建只建三樣:證據快照目錄與清單(每份帶來源、公開時間、取得時間、內容指紋;不入 git)、卡與計劃的 Markdown 加卡頭(入 git)、一份 run 紀錄(投資委託版本、提示詞版本、模型、證據清單、各層讀取紀錄)。不建 SQLite 索引、不建訂閱路由、不建每日增量——那是觀察名單那一段的事。角色由 Opus 直讀原文;程式算數列、均線、區域、ATR、相對強弱、估值算式與風險回報;頁面為單檔 HTML,資料內嵌。

## 驗收條件

- [ ] AXTI 股票頁一份(單檔 HTML)與公司卡一張(Markdown 加結構化卡頭)落檔;首屏六行齊,每行有內容或按六層紀律第二節的缺資料寫法;反例:任何一行留白或寫籠統的「未量度」,即不合格
- [ ] 六層各有輸出並附所用證據編號與原文定位(段落或表格)及資料截至時間;反方獨立進程的最強反證與綜合的正面回應都在卡上;反例:任何一層的判斷句無證據編號,或反方讀過綜合,即不合格
- [ ] 取證包含:EDGAR 最新 10-K、最近兩份 10-Q、最近四份 8-K 業績稿、DefeatBeta 最新兩份逐字稿(含問答)、富途或 Longbridge 的現時共識與評級目標價、內部人與機構持股、淡倉、Longbridge 申報清單、日線至最近收市;每份在證據清單有來源、公開時間、取得時間、內容指紋;反例:任何一份只有連結沒有快照,或缺逐字稿而卡上未標原因,即不合格
- [ ] 估值面板有正向三情境每股價值與現價反推要求,算式與輸入可核(記在 run 紀錄);技術結構由程式按六層紀律 L5 的固定定義算出,角色只判影響;風險回報按第三節算法,1% 只作示例;反例:目標價無依據、或用現價反推的條件回頭證明現價合理,即不合格
- [ ] run 紀錄齊:投資委託版本、六層紀律版本、各角色提示詞版本、模型、證據清單、各層 assessed_at 與 data_as_of、模型費用與耗時;換股試跑:同一套程式與提示詞對第二隻代號(由主 agent 指定)能跑到取證包與 L3 而不改碼;反例:提示詞內寫死 AXTI 專屬內容,即不合格
